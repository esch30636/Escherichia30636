### 1.5 临界稳定采样周期的理论推导 ★

**① 连续对象与解析解。** 单位阶跃输入下（u 由零阶保持器施加），

```
G₀(s) = K/(Tᵢ s) · 1/(T₁ s + 1)                   教材式(4-5-2-7)
y(t)  = (K/Tᵢ)[ t − T₁(1 − e^(−t/T₁)) ]           ← 反拉氏变换
y[k]  = (K/Tᵢ)[ kT − T₁(1 − p^k) ] ,  p = e^(−T/T₁)
```

**② 精确 ZOH 离散模型**（由 y[k] 反解，已与解析解逐点核对，偏差 ~1e-14）：

```
┌──────────────────────────────────────────────────────────────────┐
│  G₀(z) = [ b₁ z⁻¹ + b₂ z⁻² ] / [ (1 − z⁻¹)(1 − p z⁻¹) ]        │
│    b₁ = y[1] = (K/Tᵢ)(T − T₁(1−p))                               │
│    b₂ = y[2] − (1+p)y[1] − y[1]                                   │
│  极点：z = 1（积分环节）、z = p（惯性环节）；分子含一个采样滞后   │
└──────────────────────────────────────────────────────────────────┘
```

**③ 闭环特征方程与临界条件**。由 `1 + G₀(z) = 0`：

```
(1 − z⁻¹)(1 − p z⁻¹) + b₁ z⁻¹ + b₂ z⁻² = 0
整理成 z² + c₁ z + c₀ = 0 ：
     c₁ = −(1 + p − b₁)         c₀ = p + b₂
```

用 **Jury 判据**（二阶系统稳定的充要条件）：

```
┌──────────────────────────────────────────────────────────────┐
│   | c₀ | < 1        即     | p + b₂ | < 1                    │
│   | c₁ | < 1 + c₀                                            │
└──────────────────────────────────────────────────────────────┘
```

**物理含义**：T → 0 时 b₂ → 0、p → 1，c₀ → 1（趋临界）；T 增大使 b₂ 增大，c₀ 越过 1 即发散。
所以系统在**小 T 段稳定**、T 增大到某值后失稳 —— 这个跨越点就是**临界稳定采样周期 T\***，
可由 `|p + b₂| = 1` 数值求解（`exp78_toolkit.py` 的 `T_crit()`）。

**④ 三组数据的计算结果**（严格 Jury 判据，已核对 T\* 处 |z|max = 1.00000000）

| # | Tᵢ | K | T₁ | **T\* (临界)** | 近似式 Tᵢ/K | T=0.015 | T=0.03 | T=0.09 |
|---|---|---|---|---|---|---|---|---|
| 1 | 0.2 | 5 | 0.5 | **0.0823 s** | 0.040 s | 稳 | 稳 | **不稳** |
| 2 | 0.2 | 3 | 0.5 | **0.1398 s** | 0.067 s | 稳 | 稳 | 稳 |
| 3 | 0.1 | 2 | 0.2 | **0.1100 s** | 0.050 s | 稳 | 稳 | 稳 |

> **读取要点**：第 1 组的临界周期 0.0823 s 恰好落在实测三点 0.03 s 与 0.09 s 之间，
> 即**第 1 组在 0.09 s 时应看到等幅/发散振荡**，而 0.015、0.03 s 稳定 —— 这与"改变采样周期观察稳定性变化"的实验设计完全对上。
> 第 2、3 组的临界点（0.14 s、0.11 s）都超出 0.09 s，所以三个实测点都稳定。
> 报告里可以把这三行作为**理论预测**，与自己的实测波形逐点对照；若不一致，用 `T_crit()` 反推实际 K/Tᵢ。

> **注意**：近似式 `T* ≈ Tᵢ/K` 只在 K/Tᵢ 较小、T₁ 相对较大时成立（本实验条件下偏小 2 倍左右），
> **报告请以 Jury 判据的数值解 T\* 为准**，近似式仅作数量级估算。

**思考题参考答案**
- **为什么 T 越小越稳定？** 离散化相当于给回路串入 T/2 的等效延时；T→0 时 b₁≈(K/Tᵢ)T→0，回路增益趋零，极点趋原点，故一定稳定。T 增大使回路增益上升、特征根沿实轴右移，越过 z=1 即发散。
- **T 一定时谁决定稳定性？** 是 **K·T/Tᵢ** 这个乘积（不是 K、T 单独）。所以增大 Tᵢ 或在 A2 降低增益 K 都能把系统拉回稳定。
- **临界判据**：等幅振荡 = 临界；幅度递增 = 不稳定；衰减 = 稳定。

### 2.4 最少拍无纹波设计的完整推导 ★

**第 1 步：广义对象（含零阶保持器）**

```
G₀(s) = K/(Tᵢ s) · 1/(T₁ s + 1)                     ……(1)  教材式(4-5-2-7)
G₀(z) = Z[ (1−e^(−Ts))/s · G₀(s) ]                  ……(2)  教材式(4-5-2-1)
```

**第 2 步：求出离散对象**（与 §1.5 ② 同一结果）

```
G₀(z) = [ b₁ z⁻¹ + b₂ z⁻² ] / [ (1 − z⁻¹)(1 − p z⁻¹) ]
   p = e^(−T/T₁)，b₁ = (K/Tᵢ)(T − T₁(1−p))，b₂ = y[2] − (1+p)y[1] − y[1]
记 a₂ = b₂/b₁，则 G₀(z) = b₁ z⁻¹(1 + a₂ z⁻¹) / [ (1 − z⁻¹)(1 − p z⁻¹) ]
```

**第 3 步：规定闭环脉冲传递函数**

```
φ(z) = z⁻¹                                          ……(3)  教材式(4-5-2-4)
```

**第 4 步：反解数字调节器**

```
D(z) = φ(z) / ( G₀(z)·[1 − φ(z)] )                  ……(4)  教材式(4-5-2-3)
     = z⁻¹ · (1 − p z⁻¹)(1 − z⁻¹) / [ b₁ z⁻¹(1 + a₂ z⁻¹)(1 − z⁻¹) ]
     = (1 − p z⁻¹) / [ b₁(1 + a₂ z⁻¹) ]
```

**第 5 步：化成教材式(4-5-2-10) 标准解析式**

```
┌──────────────────────────────────────────────────────────────────────┐
│  D(z) = (K₀ + K₁ z⁻¹) / (1 + P₁ z⁻¹)                                │
│                                                                       │
│    K₀ = 1/b₁ = 1/[ (K/Tᵢ)(T − T₁(1−p)) ]     ← 决定首拍控制量（能量）  │
│    K₁ = −p/b₁ = −p·K₀                        ← 补偿对象惯性极点       │
│    P₁ = a₂ = b₂/b₁                            ← 抵消对象分子零点       │
│    K₂=K₃=K₄=P₂=P₃=0                                                   │
└──────────────────────────────────────────────────────────────────────┘
```

**第 6 步：后向差分方程（教材式 4-5-2-11）**

```
U(k) = K₀·E_K + K₁·E_{K−1} − P₁·U_{K−1}
```

**第 7 步：闭环验证（关键，建议写进报告）**

由 sympy 化简得 `D(z)G₀(z) = z⁻¹/(1−z⁻¹)`，于是

```
φ(z) = D G₀/(1 + D G₀) = z⁻¹
```

数值验证（图 8-1 硬件，K=1，Tᵢ=0.2 s，T₁=1 s，T=1 s，取整后）：

| 系数 | 理论值 | 教材表 8-1 第 1 组 | 是否吻合 |
|---|---|---|---|
| K₀ | **0.5437** | 0.54 | ✔ |
| K₁ | **−0.2000** | −0.2 | ✔ |
| P₁ | **0.7183** | 0.72 | ✔ |

```
控制量 u(k) = [0.544, −0.591, 0.424, −0.305, 0.219, …]   （按 p 速率衰减，很快归零）
采样输出 y(k) = [0, 1, 1, 1, 1, 1, …]                    ← 一拍到位
误差 e(k)   = [1, 0, 0, 0, 0, 0, …]                       ← 采样点误差恒为 0
```

**这就是"无纹波"的含义**：控制量在有限拍内迅速衰减到 0（不再激励被控对象），因此采样点之间不再产生新的纹波。

### 2.5 报告要求 3 的答案：「控制器脉冲传递函数与 Kᵢ、Pᵢ 的关系」

| 系数 | 表达式 | 物理意义 |
|---|---|---|
| **K₀** | `1/b₁ = 1/[(K/Tᵢ)(T − T₁(1−e^(−T/T₁)))]` | 首拍控制量（能量）。T 越小、K 越大 → K₀ 越大 |
| **K₁** | `−p/b₁ = −p·K₀` | 提供**对象惯性极点的补偿**：D(z) 零点 z=p 抵消 G₀(z) 极点 p |
| **P₁** | `a₂ = b₂/b₁` | 抵消 G₀(z) 分子的采样零点，使闭环退化为一拍 |
| **K₁/K₀** | `−p = −e^(−T/T₁)` | 与 K 无关的"指纹"：可直接反推对象极点/时间常数 |

| 出处 | K₀ | K₁ | P₁ | −K₁/K₀ = p | 反推 T₁ = T/(−ln p) |

| 表 8-1 第 2 组 | 0.32 | −0.12 | 0.42 | 0.3750 | 1.020 s |
| 图 8-1 框内 | 0.316 | — | 0.418 | — | （0.3164 = b₁，是对象的采样增益，不是 K₀） |

**结论**：
1. **(K₀, K₁) = (0.54, −0.2) 与本笔记的理论推导完全一致**，说明教材这两组参数就是按

2. `−K₁/K₀ = p` 这一关系把**调节器系数与对象极点**直接绑定：只要读出 K₀、K₁，
   就能反推 p = e^(−T/T₁)，进而得到惯性时间常数 T₁ —— 这正是实验报告里应该写出的"关系"。
3. P₁ 的作用是抵消对象分子零点；若软件的 P₁ 与理论值不符（如填 0.418 而非 0.718），

### 2.6 采样周期的选择（"T 等于或略小于惯性时间常数"的定量依据）

两个约束同时成立：

1. **软件系数可设范围** ±(0.001~4.999)：要求 K₀ = 1/b₁ ≤ 4.999；
2. **D/A 输出范围** −5 V~+5 V：首拍控制量 u(0) = K₀·e(0) 不能饱和。

因 K₀ ∝ 1/T（T 小时 b₁ 小、K₀ 大），⇒ **T 不能太小**（K₀ 迅速超限、u(0) 饱和）；
因 p = e^(−T/T₁) 随 T 增大而减小、响应变慢，⇒ **T 也不能太大**。
本实验（Tᵢ=0.2 s、T₁=1 s、K=1）的可用区间约为 **T ≳ 0.25 s**，教材取 **T = 1 s ≈ T₁** 正落在中部。

## 3. 课后作业：s 平面 ↔ z 平面映射

**映射关系**：`z = e^{sT}`，s = σ + jω ⇒ **|z| = e^{σT}，∠z = ωT**。
- **稳定域**：σ<0（s 左半平面）⇔ |z|<1（z 平面单位圆内）—— 这就是离散系统稳定的充要条件。
- **周期性**：z 是 s 的周期函数，周期 jωₛ（ωₛ = 2π/T）。故 s 平面宽 ωₛ 的横带映射满整个 z 平面。
- **主带**：`−ωₛ/2 ≤ ω ≤ ωₛ/2`（见 `exp78_fig1_s2z_mapping.png` 绿带）即可覆盖整个 z 平面，其他带是重复镜像。

| # | s 平面上的轨迹/区域 | 映射到 z 平面 |
|---|---|---|
| 1 | 带状区域 `[j(2k+1)/2·ωₛ, j(2(k+1)+1)/2·ωₛ]`（宽 ωₛ） | 整个 z 平面 |
| 2 | 恒定频率 `s = σ + jω₀`（水平线） | 辐角恒为 ω₀T 的**过原点射线** |
| 3 | 恒定阻尼比 ζ（`s = ωₙ(−ζ + j√(1−ζ²))`） | **对数螺线**（与单位圆交于 ζ=0 处） |
| 4 | `ω₁ ≤ ω ≤ ω₃` 的轨迹 | 辐角介于 ω₁T 与 ω₃T 之间的**扇形** |
| 5 | `ζ > ζ₁`（阻尼比下限） | 单位圆内、对数螺线**以内**（更靠近原点）的区域 |
| 6 | 恒定实部 σ₀（垂直线） | 以原点为圆心、半径 **e^(σ₀T)** 的圆 |
| 7 | 虚轴 `s = jω`（σ=0） | **单位圆**本身（临界稳定边界） |

## 5. 验证方法与踩坑清单

### 5.1 模型是怎么验证的（可写进报告的"理论依据"）
1. **连续解析解**：`y(t) = (K/Tᵢ)[t − T₁(1−e^(−t/T₁))]`（单位阶跃）；
2. **高精度数值仿真**：对 `G₀(s)=K/(Tᵢs)·1/(T₁s+1)` 用 RK4（每采样周期 2~4 万步）积分，取输出采样序列；
3. **离散模型反解与校验**：由 y[k] 反推 `b₁, b₂`，重建的阶跃序列与解析解偏差 **~1e-14**；
4. **设计校验**：sympy 化简 `D·G₀ = z⁻¹/(1−z⁻¹)`，闭环 φ(z) ≡ z⁻¹；数值上 y(k)=[0,1,1,1,…]、e(k)=[1,0,0,…]；
5. **与教材实测值对表**：理论 K₀=0.5437、K₁=−0.2000 ⇔ 表 8-1 的 0.54、−0.2 ✔。

### 5.2 踩坑清单
1. **p.17 与 p.18 元件值不同**：p.17 是 `R3=500K ∥ C2=1µF`（T=0.5 s）；p.18 图 8-1 是 `R2=500K ∥ C1=2µF`、`R3=500K`、`C2=2µF`（T₁=1.0 s）。**别混用**。
2. **`B3 xOUT2 → CH2` 必须接**：CH2 看控制器输出（控制量），CH1 看系统输出。看不到控制量的"脉冲后归零"就说明没接对。
3. **实验前先算**：用 `exp78_toolkit.py` 的 `deadbeat_D(K,Ti,T1,T)` 先算出 K₀、K₁、P₁ 与目标波形，实验时直接对照，能省一半时间。
4. **不要把 K₀ 与 b₁ 弄混**：图 8-1 框内的 0.316 其实是对象采样增益 b₁（≈1/K₀），不是调节器系数 K₀=0.54。
5. **软件系数上限 ±4.999**：T 取太小会让 K₀ 超限甚至 u(0)>5 V 饱和，波形完全变样。
6. **"无纹波"的准确含义**：φ(z)=z⁻¹ 保证**采样点**误差恒为 0；但控制量 u(k) 会以 p 的速率缓慢衰减，采样点之间 y(t) 仍有小幅起伏（本实验 T=1 s 时约 0.19）。若要连采样间纹波也消除，需采用教材 p.159 末尾所述"φ(z) 含 G(z) 全部零点"的更严格设计。
7. **参数失配很敏感**：最少拍设计靠 D(z) 零点精确抵消对象极点，T₁ 偏差 5% 就会看到明显衰减振荡。请把实测参数回代工具函数重算。
8. **教材 PDF 第 6 页有坏的 CropBox**（`/CropBox [0.038 385.45 595.31 841.89]` ≠ `/MediaBox`），正常阅读/打印会**丢掉 p.159 下半页的"图 4-5-2-1 最少拍有纹波控制构成"**。需要时用 PyMuPDF `set_cropbox(mediabox)` 重新导出。
