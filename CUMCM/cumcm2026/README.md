# A 题 · 药材烘干

**核心建模决策**：柱形药材（长 25 cm、半径 R(t) 初始 2.0 cm）轴向远大于径向、热风
周向均匀 → 取**轴对称一维径向模型**，状态变量为温度 `T` 与干基含水率 `C`，控制方程为
径向热传导 + 水分扩散；边界为对流传热/传质（`h=25 W/(m²·K)`、`h_m=8×10⁻⁷ m/s`，
烘房条件来自附件1）。问题1 用附录2 常数物性，问题2/3 用附录3，问题4 用附录4
（含收缩半径 R(t)：2.0 → 1.198 cm）。

## A-1 问题1：建立模型，输出 30 min 干燥过程（result1.xlsx，1 s 间隔）

**解决思路**
1. **几何简化**：轴对称一维（径向）模型，ρc_p ∂T/∂t = (1/r)∂/∂r(kr∂T/∂r)，
   ∂C/∂t = (1/r)∂/∂r(Dr∂C/∂r)。
2. **曲线坐标 ξ = r/R(t)**：即使问题1 无收缩也统一用 ξ 坐标（R 固定），保证四个
   问题共用同一套代码路径；ξ ∈ [0,1]，ξ=1 为表面。
3. **边界条件**：ξ=0 轴对称；ξ=1 处 `-k/R·∂T/∂ξ = h(T_s − T_air)`、
   `-D/R·∂C/∂ξ = h_m(C_s − C_air)`，烘房温度/湿度取自附件1 时间序列。

**算法**
1. **单元中心有限体积法**（N=400 单元），界面扩散系数取**调和平均**。
2. **表面通量精确处理**：由单元中心到表面的串联热阻为 ∫dξ/(ξk) = ln(1/ξ_c)/k，
   表面传导度取 `G_N = 1/[ln(1/ξ_c)/k_N + 1/(hR)]`（比常用近似 (Δξ/2)/(ξ_c k)
   精确 ~10 个数量级，是 4 位小数精度的前提）。
3. **时间推进**：`scipy.solve_ivp(method='BDF')`，rtol=1e-8/atol=1e-10，按
   `[T₀,C₀,T₁,C₁,…]` 交错排列并提供 `jac_sparsity`（半带宽 3）。
4. **输出采样**：内部点 ξ 线性插值；表面值由边界条件**反解** `T_s = T_air + Φ_N/(hR)`
   （比线性外推精度高约一个数量级）。

**结果**：30 min 内中心 28 → 33.5753 °C，表面 28 → 36.7856 °C；水分只在表层下降
（表面 2.5500 → 1.5102，中心仍 2.5500）——典型**干壳湿芯**分布。

## A-2 问题2：3 h 干燥过程模拟（result2.xlsx，1 s 间隔）

**解决思路**：模型同 A-1，物性换附录3（D 含 Arrhenius 因子 `exp(−3850/T)` 与浓度依赖
`exp(−0.45/C)`）；烘房条件用附件1 前 4 h 段。3 h 内温度场快速趋近烘房（热平衡特征
时间 ~1 h），水分扩散缓慢启动。

**算法**：与 A-1 完全一致（同一 `a_model.py`，仅物性/时长参数不同）。

**结果**：3 h 时表面温度升至 49.9664 °C（烘房 50.165 °C）；最大水分浓度（中心）
降到 1.7662 kg/kg。result2 输出范围按两种理解双产出：默认 `out/result2.xlsx`
（t = 1…10800 s，1 s 间隔，"3 h 内"读法）；变体 `result2_full_1s/`（全流程 1 s 间隔，
20.6 万行/26.2 MB，超压缩包上限，不进默认交付集）。

## A-3 问题3：不考虑收缩的烘干时间（result3.xlsx，60 s 间隔）

**解决思路**：半径恒为 R₀=2.0 cm，附录3 物性；烘干完成判据为**全体干基含水率
max C < 0.15 kg/kg**（表面先干、中心最后干，max C 始终在中心）。求解器推进至判据
满足，全流程按 60 s 采样。

**算法**：同一 ξ-FVM 模型推进至 t*，网格收敛性验证（N=100/200/400/800：
206263.1 → 205971.7 → 205862.4 → 205825.4 s，Richardson 极限 ≈ 205813 s）。

**结果**：**烘干时间 205862.4 s = 57.1840 h = 2.3827 天**（落在题面"2–3 天"内）。

## A-4 问题4：考虑收缩的烘干时间（result4.xlsx，60 s 间隔）

**解决思路**
1. **移动边界**：半径按附件2 由 2.0 cm 收缩到 1.198 cm；ξ = r/R(t) 曲线坐标下
   材料点固定在自身 ξ 上（仿射收缩假设）。
2. **关键推导**：干物质守恒给出 ρ_d R² = const，代入守恒律后 ρ_d 完全约去；
   仿射收缩下**不出现对流项**；收缩的全部影响体现为有效扩散系数 **D/R(t)² 随 R
   减小而增大**（最大 (2/1.198)² = 2.79 倍）。
3. 附录4 物性的前置因子在 C=2.55 时比附录3 小 5.4 倍、浓度依赖 exp(−0.30/C) 更弱。

**算法**：同一 ξ-FVM（R(t) 时变），输出采样时按物理半径 r = ξ·R(t) 映射到固定距离列
（0, 0.1, …, 1.1 cm + 末列"药材表面"——只有 ≤1.1 cm 的 0.1 cm 网格全程位于收缩后的
药材内部）。

**结果**：**烘干时间 182974.1 s = 50.8261 h = 2.1178 天**（比问题3 提前 6.4 h）。
**交叉现象**（值得在论文讨论）：问题4 前期更慢（前置因子小 5.4 倍）、后期更快
（1/R² 放大 + 弱浓度依赖），中心水分曲线在约 33 h 处相交。

## A 支撑：验证与敏感性（贯穿四个小题）

1. **RHS 恒等性**：ξ 形式右端与独立实现的物理 r 坐标右端逐分量比较（三种状态、
   三个时刻），偏差 10⁻¹⁴~10⁻¹⁵ → 移动边界变换与通量装配正确。
2. **守恒性**：能量/水分残差 ~2×10⁻⁹。
3. **网格收敛**：N=400 相对 N=1600 基准的各列误差 ≤1.3×10⁻⁵，干净 2 阶，保证 4 位小数。
4. **敏感性**（OAT 弹性系数 S）：烘干时间几乎完全由 D 决定（S = −0.73/−1.11），
   h_m 弱（−0.09），传热参数 h、k、ρ、c_p 可忽略（|S| < 0.003）→ 过程为水分扩散控制。
5. **最大不确定度**：附件1 只给 4 h 烘房条件，"恒温干燥阶段维持末值"假设下，
   烘房 ±5 °C → 烘干时间 −14.6%/+18.2%（因 D 中 exp(−3850/T)）。
6. **拉丁超立方 MC（N=1000）**：问题3 57.69±4.53 h（P05–P95：51.1–65.2 h），
   问题4 51.22±3.95 h；与 D 的相关系数 −0.98。
7. **GAN 情景传播**：WGAN-GP 学习附件1 恒温段（后 2 h）温湿度偏差分布，
   生成 200 条 61 h 随机情景 + 块自助/参数化两基线，经 FVM 传播（1202 个求解）。
   结果：随机波动引起的干时分布 std ≈ 0.01 h、均值偏置 ≤ 0.11%，比参数不确定性
   （4.5 h）小两个数量级以上 →「维持末值」假设的真实风险是**系统性设定值偏移**
   （±5 °C 情景已给出界），随机波动可忽略。详见 A/成果汇总.md §5.4。

# B 题 · 无线电干扰源的快速自动定位与清除

**题目机制**：机器狗从 (0,0) 出发（初始频道 1）；10–16 个干扰源，频道互异取自 1–20，
均匀分布于半径 1800 m 圆盘；接收半径 r_G ~ U[1000,1500] m；示向度误差 ∈ [−1°,1°]
且**同一检测点误差固定**（不同检测点独立）；全向源覆盖整圆，**定向源仅覆盖其方向
±90° 扇区且方向未知**；/measure 返回 no_signal / near(≤5 m 且在覆盖内) / direction
+svd_deg(两位小数)；清除半径 20 m（与朝向无关）；计时：移动 = 距离/5 s、切换频道 1 s、
检测 5 s、清除 5 s(成功)/3 s(未发现)；虚拟时限 360000 s，现实时限 1200 s。

## B-1 问题1：定位区域的构造算法与覆盖圆判定

**解决思路**：检测点 Sᵢ 测出示向度 θᵢ（±1° 误差）→ 源位于楔形 [θᵢ−1°, θᵢ+1°] 内。
k 个检测点 → **2k 个半平面约束**，交集即定位区域（凸多边形）。"能否被半径 r 的圆
覆盖" ⇔ 定位区域的最小覆盖圆半径 r_min ≤ r；区域直径 D ≤ 2r 是充分条件，
Jung 定理保证 r_min ≤ D/√3（比值 ≤ 2/√3 ≈ 1.1547，等边三角形取等）。

**算法**
1. **区域构造**：从边长 2×10⁶ m 的大方框出发，用 Sutherland-Hodgman 算法逐半平面
   裁剪（每个楔形的两条边是过 Sᵢ 的两条直线，法向取楔形内侧）；裁空 = 示向度矛盾，
   未裁剪完 = 无界（k=1 或平行楔形）。
2. **直径**：凸多边形顶点对的最大距离（对径点对，O(m²)）。
3. **最小覆盖圆**：最优圆必由 2 点（直径圆）或 3 点（外接圆）确定 → 穷举全部
   2/3 点组合取最小合法圆。
4. **覆盖判定**：r_min ≤ r（精确）；D ≤ 2r（充分）；D ≤ (2/√3)r（Jung 严格保证）。

**结果**（MC 20000 组/每 k）：k=2 时 r_min/(D/2) 最大值 **1.000581**（p99 = 1.000000）
——直径判定几乎处处精确；k=3~6 最大比值 1.13–1.14，即 D≤2r 最多保守 ~14%。
反例构造：两检测点与源**共线同侧**时区域沿共线方向延伸，D 达上界 2εd
（ε=1°，1000 m 处 ≈ 35 m）——这正是问题2 "不能在示向度方向取第二检测点"的定量依据。

## B-2 问题2：已知一个示向度时第二检测点的选择策略

**解决思路**
1. 设 S₁=(0,0) 测示向度 0°（旋转平移不变），真实源 G=(d₁,0)，第二检测点
   S₂ = L·(cos ψ, sin ψ)（相对示向度偏转 ψ，两侧对称）。
2. **条件化先验（关键）**：S₁ 已接收到信号 → r_G ≥ d₁ 已知信息，先验须取
   f(d₁ | S₁收到) ∝ d₁ · P(r_G ≥ d₁ | d₁)（d₁>1000 时因子为 (1500−d₁)/500）。
   忽略此条件化会系统性高估 P_s（例：L=400, ψ=90° 未条件化 0.769 vs 正确 0.899）。
3. 度量：成功概率 P_s = P(|S₂−G| ≤ r_G | S₁收到)，精度 E[D | S₂收到]（D 用 B-1
   的区域直径算法精确计算）。

**算法**
1. **P_s 解析积分**：r_G 条件分布分段显式（d₁≤1000 时 U[1000,1500]；d₁>1000 时
   U[d₁,1500]），4001 点网格数值积分，规避小样本尾部误差。
2. **E[D] 蒙特卡洛**：采样 d₁∝d₁、r_G 条件采样、两检测点误差独立 U(−1°,1°)，
   用 B-1 算法构造区域取直径，在成功样本上取均值。
3. **理论近似验证**（窄楔形 → 平行四边形）：
   D ≈ (2ε/sin φ)·√(d₁²+d₂²+2d₁d₂cos φ)，sin φ = L sin ψ/d₂ —— 与 MC 偏差 ≤4%，
   用于解析解释。
4. **网格寻优**：L×ψ 网格（L=700…1600 m，ψ=15°…70°），约束 P_s≥0.90 最小化 E[D]。

**结果**：**L\* = 1100 m，ψ\* = 35°，P_s = 0.9994，E[D|成功] = 50.0 m**；
候选区域（P_s≥0.90 且 E[D]≤1.15×最优）：L ∈ [850,1450] m，ψ ∈ [20°,50°]。
朴素策略对照：沿示向度前进 500 m → D=500 m（无横向约束）；垂直 500 m → P_s 仅 0.842
（D=121 m）；反向 500 m → 区域无界。前进-偏转组合以近乎必然的成功率换取 50 m 精度。

## B-3 问题3：全向源的自动搜索-定位-清除策略（演练统计）

**解决思路：分两阶段——覆盖扫描保证"必然发现"，交会归航保证"必然清除"。**

**算法**
1. **覆盖扫描站集（7 站）**：原点 + 半径 1200 m 正六边形 6 站。
   **覆盖定理**：盘内任一点距 7 站最近距离 ≤ 969 m < 1000 ≤ r_G →
   逐站扫描 20 个频道**每个源必被至少一站检测到**（纯检测时间 7×20×5 = 700 s）。
2. **扫描**：逐站×频道（跳过已清除频道），near → 立即 /clear（near ≤5 m 必在
   20 m 清除半径内）；direction → 记录 (站, svd)。
3. **交会定位**：≥2 条示向度 → 用 B-1 半平面交构造区域，取**区域形心**为归航起点
   （全向源无方向约束，形心处必在接收半径内）；1 条示向度 → 从该站出发。
4. **归航（有收敛保证）**：从起点沿示向度 100 m/步行进，**每步重新 /measure 校正**；
   新示向度与行进方向点积 <0（已越过源）→ 步长减半回头（最小 2 m）；near → 清除。
   行走方向始终指向源 ⇒ 距离单调下降 ⇒ 全程在接收半径内（cos 1°>0），必收敛。

**结果**（MC N=400，seed=2026，自研环境）：**清除比例 100%（400/400）**；
平均定位清除时间（总虚拟时间/清除数，含移动/切换/检测/清除全部耗时）**507±50 s**
（P95 590 s）；总虚拟时间均值 6595 s（P95 7829 s，扫描占 35.0%）——仅为 360000 s
时限的 1.8%。

## B-4 问题4：含定向干扰源的检测清除策略（演练统计）

**解决思路**
1. **可检测性刻画**：定向源仅覆盖方向 ±90° 扇区（方向未知）→ 检测点 P 能测到 G
   ⇔ P ∈ disk(G,1000) 且在 G 的某 180° 方向窗内。**充要判据**：disk(G,1000) 内站点的
   方向角（从 G 看）最大间隙 ≤ 180° ⇔ 任意 180° 窗内必有站。
2. **站集（49 站）**：原点 + 600 m×12 + 1200 m×12 + **2100 m×24**。
   数值验证（6 万样本）：方向角**最大间隙 158.42° < 180°，0 失败**。
   外环半径临界性：R=2150 即出现 180.7° 边际失败，R=2200 失败（206.0°）——径向
   站距 R−1200 需 ≤1000 且角向间隙需 ≤180°，R=2100 恰好留 21.6° 裕量。
3. **归航从示向站出发**（不用形心）：定向源若形心恰在扇区外会立即丢失方向；
   从示向站出发保证起点在扇区内。
4. **越出扇区兜底（定向源特有风险）**：行进越过源后 P 越出 ±90° 扇区，
   /measure 变 no_signal 且**不再返回示向度**（与全向源的"示向度翻转"不同）→
   先直接 /clear 试探（20 m 清除半径与朝向无关），失败则**向上一检测点二分回退**；
   二分区间收敛于扇区边界（即源附近），2~3 次迭代内必进入 20 m 清除半径。

**算法**：扫描/交会同 B-3；归航每步 100 m 重测校正、越过源翻转减半（全向源）、
no_signal → clear 试探 + 二分回退（定向源）。

**结果**（MC N=400，seed=2026，定向源概率 0.5）：**清除比例 100%（400/400）**；
平均定位清除时间 **1247±148 s**（P95 1503 s）；总虚拟时间均值 16094 s（P95 17564 s，
扫描占 68.3%）——为时限的 4.5%。现实时限核算：单案例约 1600 次 HTTP 请求
（<10 ms/次）→ 墙钟 <30 s ≪ 1200 s。

### 注意

- 本机 `defaults` 频道 repodata 极慢（会卡死），建环境走清华镜像：
  `conda create -n X python=3.11 -y --override-channels -c https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main`，
  pip 同理加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。
- `tidn` 环境内有 DQN 训练任务常驻，操作时勿杀非本项目进程。
- B 题**未安装官方模拟器**（队内决定，见正文约定）；早期工作区评估中"需下载模拟器、
  联网登录、3 次正式测试"的方案已废弃，以本文档为准。
