## 0. 结论速览（先看这里）

1. **潜热项在题面参数下不是小量**。按与模型自洽的质量通量口径（换算密度
   `ρ_d = 275.04 kg/m³`），3 h 窗口内潜热流为 **503–847 W/m²**，是同期对流供热能力的
   **5.5–88 倍**；且在 t = 0.5 h 已达 847 W/m²，**超过烘房可能提供的最大热流
   `h(T_air − T₀) = 25 × 22.17 = 554 W/m²`**。
2. **因此潜热项无法与题面参数自洽共存**。把它加进模型后，模型预测早期表面/中心温度
   跌到 **11–12 °C / 9.6 °C**（低于初始 28 °C），这是热风干燥中不可能出现的（真实表面温度
   受湿球温度约束）。原因：题面的 `h_m = 8×10⁻⁷ m/s` 比热质类比式
   `h_m ≈ h/(ρ_a c_{p,a} Le^{2/3}) = 2.45×10⁻² m/s` **小 3.07×10⁴ 倍**（[29]）——
   题面参数是按"潜热并入有效参数"的简化口径标定的，这正是题面"**为简化问题**"的含义。
3. **但对本题结论（烘干时间）影响有限**：含潜热重解得 **60.18–61.09 h**，相对基线
   **57.1840 h 仅长 +5.2% ~ +6.8%**，仍落在题面"2–3 天"内；"浓度型"下界口径仅 +0.02%。
   ⇒ 论文可据此声明：**基线简化对本题结论的影响 ≤ 7%，属可接受简化**，同时把潜热项列为
   **已量化**的模型局限（这正是 §5 第 12 句要的写法）。

## 1. 文献依据与模型写法

### 1.1 两种等价写法

| 写法 | 方程 | 出处 |
|---|---|---|
| **vol**（体积汇） | `ρ·c_p·∂T/∂t = (1/r)∂/∂r(k r ∂T/∂r) + L_v·ρ_c·∂C/∂t` | Luikov 型相变汇项，[31] 的严谨处理、[30][32] 的 THM 耦合 |
| **surf**（表面通量） | 表面能量边界加潜热流 `L_v·J_s`，`J_s = ρ_c·h_m(C_s − C_air)` | 恒速段/表面蒸发图像 [10][52] |

两者**能量总量等价**（潜热总量 = `L_v × 总失水量`），差别只在潜热在空间上"在哪里被吸收"。
`vol` 下潜热按局部失水率分布；`surf` 下全部在表面扣掉。

**surf 的表面反解推导**（实现见 `a_model.py` 的 `rhs` / `surface_bc_vec`）：
表面能流平衡 `(T_{N−1} − T_s)/R_c = hR(T_s − T_air) + Λ`，其中导热段
`R_c = ln(1/ξ_c)/k`、`Λ = L_v ρ_c Φ_C[N]`（约化潜热流）；消元得

```
Φ_T[N] = G_t,s (T_{N−1} − T_air) + Λ/(1 + R_c·hR)
T_s    = T_air + (Φ_T[N] − Λ)/(hR)
```

### 1.2 换算密度 ρ_c 的口径（关键）

模型的 C 场是**约化**的：物理水分质量 `= 2πH·∫ρ_d C r dr = 2πH ρ_d R² ∫C ξ dξ`。
所以模型里 `Φ_C` 的路"通量"要乘上 ρ_d 才是水的质量通量 [kg/(m²s)]：

```
J_s = ρ_d · h_m (C_s − C_air)     [kg/(m²s)]
```

干物质守恒（仿射收缩）给出 `ρ_d R² = const`；问题 2/3 中 R 恒为 2 cm ⇒ **ρ_d 为常数**，
由初值锚定：

```
ρ_d = ρ(C₀)/(1+C₀) = (650 + 128×2.55)/3.55 = 275.04 kg/m³      ← 推荐口径
```

对照口径（用作上下界，见 `fig01(b)` 与 `fig06`）：

| 口径 | ρ_c | 说明 |
|---|---|---|
| `dry0` | 275.04 | **推荐**：模型自洽（干物质守恒） |
| `dry` | ρ(C)/(1+C) | 随含水率变化（275 → 582） |
| `bulk` | ρ(C) | 直接用附录 3 密度（650 → 976） |
| `unit` | 1 | "浓度型"下界口径（把模型约化通量直接当质量通量） |

> 口径差异达 **10³ 量级**（1 vs 976），这是本问题"潜热项量级"唯一的不确定来源；
> 本包把四种口径全部算出来给界，推荐口径的推导见上。

## 2. 量级诊断（`python p2_lit.py diag`）

```
干物质密度锚定值 ρ_d = ρ(C0)/(1+C0) = 275.04 kg/m3
汽化潜热 L_v = 2383 kJ/kg（50 °C 蒸汽表值；28~50 °C 内 2435→2383，变化 2.2%）
热质类比[29]: Le = 0.849, Le^(2/3) = 0.896
  h_m(类比) = h/(ρ_a c_p,a Le^(2/3)) = 2.4531e-02 m/s
  h_m(题面) = 8.0e-07 m/s   -> 相差 3.066e+04 倍

 t/h   T_s/°C     C_s     h(T_air−T_s)   L_v·J_s    L_v·J_s : 对流
 0.5   35.4130   1.6486     152.499      847.097        5.55
 1.0   42.9975   1.4711     112.188      748.954        6.68
 2.0   49.0034   1.2311      21.215      619.851       29.22
 3.0   49.9664   1.0081       5.715      502.503       87.93

 t = 1 h: 潜热流 749.0 W/m² —— 若主要由对流供给, 表面需比烘房低 29.96 K
 t = 3 h: 潜热流 502.5 W/m² —— 若主要由对流供给, 表面需比烘房低 20.10 K
（烘房可动用的最大温差 = 50.165 − 28 = 22.17 K ⇒ 所需降温已超过上限）
```

**读法**：潜热流始终与"最大可供给热流 554 W/m²"同量级或更大，而题面对流供热能力不足以
在保持表面接近烘房温度的同时供上潜热 —— 要么表面大幅降温（模型给出的 11–12 °C），
要么题面参数本就按"潜热可略"标定。二者取其一，实测结果是前者。

## 4. 验证（`python p2_lit.py verify`）

1. **基线复现**：重构后的模型/输出层与冻结版 `02/tables2.json` **逐位一致**
   （表 3 最大偏差 `0.000e+00` °C，表 4 `0.000e+00` kg/kg）⇒ 新增的潜热能力**没有改动基线路径**。
2. **含潜热右端项的积分恒等性**：`Σ(ρ·c_p·ξ·dξ·dT/dt) = (q_conv − q_lat)/R`
   （q_conv = h(T_air − T_s)，q_lat = L_v ρ_c h_m (C_s − C_air)）在 t = 1800/3600/7200 s 三个
   状态上相对残差 **4.9×10⁻¹⁴ ~ 3.8×10⁻¹⁶**（基线 4.4×10⁻¹⁵ ~ 8.1×10⁻¹⁶）
   ⇒ 潜热的能量记账与质量守恒严格一致。该恒等式只对 ρ_c 为常数的口径（`dry0`）严格成立。

## 5. 论文里怎么写（可直接用）

> 能量方程是否包含蒸发潜热汇项是干燥模型与文献模型的主要差异 [31][30][32][52]。本题
> 附录 2/3/4 未给出汽化潜热，且题面对流传质系数 `h_m = 8×10⁻⁷ m/s` 比热质类比式
> `h_m ≈ h/(ρ_a c_{p,a} Le^{2/3})`（[29]）小 3.07×10⁴ 倍，说明题面参数体系按"潜热并入
> 有效参数"的简化口径给定。为量化该简化对结论的影响，本文按文献补全能量方程中的蒸发
> 潜热汇项（`L_v = 2383 kJ/kg`，与模型自洽的质量通量换算密度 `ρ_d = 275.04 kg/m³`），
> 以体积汇与表面通量两种等价写法重解问题 2：**烘干时间为 60.18–61.09 h，相对基线的
> 57.18 h 仅长 5.2%–6.8%，仍满足题面"2–3 天"**；在"浓度型"换算口径下差异仅 0.02%。
> 因此本文采用不含潜热的简化模型作为正式答案，该简化对本题关心的结论影响 ≤7%。
> 需要说明的是，含潜热版本预测的早期料温（表面 11–12 °C）低于实际干燥中受湿球温度约束
> 的表面温度下限，这反映了题面参数未按完整相变模型标定 [10][59]。

引用编号对应 `../文献库.md`：[29] Defraeye 2012（h/h_m 关联式）、[31] Purlis 2019（潜热汇项）、
[30] Zhu 2021、[32] Lu 2015（THM 耦合）、[52] LBM 综述（相变潜热反馈）、[10] Berger & Pei 1973（恒速段）。
