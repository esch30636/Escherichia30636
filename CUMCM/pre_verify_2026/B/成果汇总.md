## 1. 问题1：定位区域与覆盖圆判定

### 1.1 模型
检测点 Sᵢ 测得示向度 θᵢ（真值 ± ε，ε = 1°）。真实方位角 βᵢ ∈ [θᵢ−ε, θᵢ+ε]，即源 G 位于
**楔形** β ∈ [θᵢ−ε, θᵢ+ε] 内。k 个检测点给出 2k 个半平面约束，其交集即为定位区域
（凸多边形；k=1 时为无界楔形）。

**定位区域 = 2k 半平面交**：以检测点 Sᵢ、示向线两侧各偏转 ε 的半平面
`n·(x−Sᵢ) ≥ 0`（n 为边界法向）逐一裁剪。实现上用 Sutherland-Hodgman 算法从一个
边长 2×10⁶ m 的大方框开始逐半平面裁剪，若裁空则区域为空（示向度矛盾，说明误差假设
外有扰动），未裁剪完即无界（k=1 或平行楔形）。

### 1.2 区域直径与最小覆盖圆
- **直径** D = 凸多边形顶点对的最大距离（对径点对，O(m²) 顶点枚举）。
- **最小覆盖圆**（MEC）：最优圆必由 2 个顶点（直径圆）或 3 个顶点（外接圆）确定，
  遍历全部 2 点/3 点组合取最小合法圆即可（点数 ≤ 2k+8，穷举可行）。
- **覆盖判定**：源被半径 r 的探测手段"覆盖" ⇔ 存在以 G 为圆心半径 r 的圆含整个
  定位区域 ⇔ 定位区域的最小覆盖圆半径 r_min ≤ r。若区域直径 D 已知，则
  **D ≤ 2r 是覆盖的充分条件**。

### 1.3 Jung 界与数值结论
Jung 定理给出 r_min ≤ D/√3（比值 ≤ 2/√3 ≈ 1.1547，等边三角形取等），即"直径判定"
最多比精确判定保守 15.5%。蒙特卡洛（每 k 取 20000 组随机检测点/源）：

| k | 区域有界率 | max(r_min/(D/2)) | 覆盖判定保守度 |
|---|---|---|---|
| 2 | 97.7% | **1.000581** | 几乎处处精确（p99 = 1.000000）|
| 3 | 87.6% | 1.144377 | ≤ 14.4% |
| 4 | 80.2% | 1.129471 | ≤ 12.9% |
| 5 | 75.1% | 1.140348 | ≤ 14.0% |
| 6 | 70.8% | 1.141400 | ≤ 14.1% |

**结论**：k=2 时两楔形交点处区域形状极接近"两端尖的窄条"，直径判定 D ≤ 2r 几乎
无损（比值 >1 的概率 <1% 且最大偏差 0.06%）；k≥3 时用 D ≤ 2r 判定最多损失 ~14%。
论文中可直接陈述：**覆盖判定的实用形式为 D ≤ 2r**，并用 Jung 界 r_min ≤ D/√3 给出
严格保证：D ≤ (2/√3)·r 时必覆盖。

**反例（D ≤ 2r 不可逆）**：区域为正三角形时 D/2 判定不足 15.5%；等边三角形
三顶点处检测点（每点两个楔形边）可达该极值。

### 1.4 直径的解析上界与反例
两检测点与源共线且位于源同侧时，楔形在共线方向无约束、横向收缩，区域沿共线方向
延伸，直径上界为 **2ε·d**（d 为距源较近的检测点到源的距离）——1° 误差在 1000 m
处即产生 ±17.5 m 横向条宽。此即"在示向度方向上取第二检测点无定位价值"的定量依据
（问题2 直接使用）。

## 2. 问题2：第二检测点的选择策略

### 2.1 设定与建模
S₁ = (0,0) 测得示向度 0°（旋转平移不变）。真实源 G = (d₁, 0)；第二检测点
S₂ = L·(cos ψ, sin ψ)（ψ 相对示向度方向偏转，两侧对称）。

**关键建模点（观测携带信息）**：S₁ 已接收到信号 → 不仅 G 在盘内，且接收半径
r_G ≥ d₁。故先验须条件化：f(d₁ | S₁收到) ∝ d₁ · P(r_G ≥ d₁ | d₁)，其中
P(r_G≥d₁|d₁) = 1（d₁≤1000）或 (1500−d₁)/500（d₁>1000，r_G~U[1000,1500]）。
忽略该条件化会显著高估 S₂ 的接收概率（例：L=400, ψ=90° 时未条件化 P_s=0.769
vs 正确值 0.899）。

### 2.2 度量与计算
- **成功概率 P_s** = P(|S₂−G| ≤ r_G | S₁ 收到)：解析积分（4001 点网格），r_G 的条件
  分布分段显式。
- **定位精度 E[D | S₂ 收到]**：蒙特卡洛——采样 d₁∝d₁、r_G~U[1000,1500] 条件 r_G≥d₁、
  两检测点误差独立 ~U(−1°,1°)，用 §1.1 算法构造区域取直径，对成功样本求均值。
- **理论近似（窄楔形）**：定位区域近似平行四边形，直径 = 长对角线
  D ≈ (2ε/sin φ)·√(d₁² + d₂² + 2d₁d₂cos φ)，φ 为两示向线在 G 处夹角，
  sin φ = L sin ψ / d₂，cos φ = |d₁ − L cos ψ| / d₂。
  与 MC 对照（成功样本）：147.6 vs 150.4 / 78.4 vs 79.7 / 50.2 vs 50.3 / 53.2 vs 53.1 m
  —— 理论公式可用于解析解释与敏感性。

### 2.3 结果
- **最优**（P_s ≥ 0.90 约束下最小 E[D]）：**L\* = 1100 m，ψ\* = 35°**，
  P_s = 0.9994，**E[D|成功] = 50.0 m**。
- **候选区域**（P_s≥0.90 且 E[D] ≤ 1.15×最优，两侧对称）：**L ∈ [850, 1450] m，
  ψ ∈ [20°, 50°]**。
- 朴素策略对照：沿示向度前进 500 m → D = 500 m（横向无约束，符合 §1.4）；前进 1000 m
  → D = 1000 m；垂直 500 m → P_s=0.842，D = 121 m；垂直 1000 m → P_s=0.368，D=65.8 m；
  反向 500 m → 定位区域无界（两检测点共线且在源同侧）。**垂直探测精度高但接收概率低、
  前进探测则反之，35° 偏转的前进-偏转组合以 0.9994 概率换取 50 m 精度**。

## 3. 问题3：全向源的自动搜索-定位-清除（7 站扫描 + 交会归航）

### 3.1 覆盖扫描站集（保证检测到每个源）
**站集 = 原点 + 半径 1200 m 正六边形 6 站（共 7 站）**。
定理：盘（R=1800 m）内任一点距 7 站最近距离 ≤ 969 m。数值验证（20 万样本）：
max_G min_S |SG| = **967.92 m** < 1000 m ≤ r_G（r_G~U[1000,1500] 取下界）→
在每个站上对 20 个频道逐一检测，**每个源必被至少一站检测到**（全向无方向条件）。
7 站扫描的纯检测时间 = 7×20×5 s = 700 s，移动 ≤ 7×1200/5 = 1680 s。

### 3.2 定位与清除策略
1. **扫描**：逐站 × 频道 1..20，跳过已清除频道。返回 near（≤5 m 且在覆盖内）→
   直接 /clear（清除半径 20 m 与朝向无关，near 必清除成功）；返回 direction →
   记录 (站, svd)。
2. **交会定位**：≥2 条示向度 → §1.1 区域，取**区域形心**为归航起点（全向源无方向
   约束，形心处必在接收半径内且越近越省时）；1 条示向度 → 从该站出发。
3. **归航**：从起点沿示向度方向 100 m/步行进，每步重新 /measure 校正；示向度翻转
   （新方向与行进方向点积 <0，说明已越过源）→ 步长减半回头（最小 2 m）；near → 清除。
   行走方向始终朝向源 ⇒ 距源单调下降 ⇒ 全程在接收半径内（cos 1° > 0），**必收敛**。

### 3.3 蒙特卡洛演练统计（N=400，seed=2026，legion 28 核）
| 统计量 | 值 |
|---|---|
| 被清除干扰源个数比例 | **100%（400/400 全清，0 失败）** |
| 平均定位清除时间（总虚拟时间/清除数） | **507 ± 50 s**（P5 433，P95 590，max 666）|
| 总虚拟时间 | 均值 **6595 s**（P95 7829，max 8852）|
| 其中扫描阶段占比 | 35.0% |
| 干扰源个数 | 10–16（均 13.1）|

总虚拟时间均值 ≈ 1.83 h，仅为 360000 s 时限的 1.8%。剩余时间余量极大，策略对
r_G 分布下界（1000 m）与误差 ±1° 的扰动有天然鲁棒性。

## 4. 问题4：含定向干扰源的检测清除（49 站扫描 + 扇区安全归航）

### 4.1 定向源的可检测性
定向源仅覆盖方向 ±90° 扇区（方向未知）。检测点 P 能测到 G ⇔ |PG| ≤ 1000（取下界）
**且 P 在 G 的方向 ±90° 扇区内**。对固定 G，测到 ⇔ P ∈ disk(G,1000) ∩ 某 180° 方向窗。
**充要条件判据**：disk(G,1000) 内站点的方向角（从 G 看）最大间隙 ≤ 180°
⇔ 任意 180° 方向窗内必有站。

### 4.2 站集设计（49 站）
**原点 + 600 m×12 + 1200 m×12 + 2100 m×24**。数值验证（6 万随机 (G, 方向) 样本）：
disk(G,1000) 内站方向角**最大间隙 158.42° < 180°，0 失败**。

外环半径的临界性（已排除的方案）：R=2150 出现 180.7° 边际失败（3/60000），R=2200
失败（206.0°）。原因：|G|=1200 处径向站距 = R−1200，要求 ≤1000 → **R ≤ 2200 是必要
条件**；而角向间隙要求外环站足够多、足够近，R=2100 时 24 站恰好留 21.6° 裕量。
纯检测时间 = 49×20×5 s = 4900 s，移动 ≤ 49×2100/5 ≈ 20.6 ks。

### 4.3 定位与清除策略（对 3.2 的修改）
1. 扫描同上（49 站，20 频道）。
2. **归航一律从"离交会点最近的示向站"出发**：全向源可从区域形心直接归航，但定向源
   若形心恰在扇区外会立即 no_signal 丢失方向——从示向站出发保证起点在扇区内且沿
   示向度行进时 (P−G)·u_θ 递减但不越界（cos 1°>0）。
3. **越过源的扇区风险与兜底**：行进越过源后 P 越出 ±90° 扇区，/measure 返回
   no_signal 且不再给示向度（与全向源的"翻转示向度"不同，无法直接回头）。兜底：
   **先直接 /clear 试探**（清除半径 20 m 与朝向无关，距源 ≤20 m 即成功），失败则
   **向上一检测点二分回退**——二分区间收敛于扇区边界（即源附近），2~3 次迭代内必
   进入 20 m 清除半径。此修复前 MC 有 2/400 案例归航在 80 次上限处未收敛（均为
   定向源越过源后振荡），修复后全部收敛。

### 4.4 蒙特卡洛演练统计（N=400，seed=2026，legion 28 核）
| 统计量 | 值 |
|---|---|
| 被清除干扰源个数比例 | **100%（400/400 全清，0 失败）** |
| 平均定位清除时间 | **1247 ± 148 s**（P5 1042，P95 1503，max 1666）|
| 总虚拟时间 | 均值 **16094 s**（P95 17564，max 19236）|
| 其中扫描阶段占比 | 68.3% |
| 干扰源个数 | 10–16（均 13.1，定向源概率 0.5）|

总虚拟时间均值 ≈ 4.47 h，为 360000 s 时限的 4.5%。扫描（检测+移动）是主要耗时，
归航-清除每源平均约 1.25 ks（含移动）。

### 4.5 现实时限核算
单案例动作数：49×20 次扫描测量 + 每源 ~20–40 次归航测量 + 清除 ≈ 1600 次 HTTP 请求；
本机 HTTP 往返实测 <10 ms/次 → 墙钟 < 30 s ≪ 1200 s 现实时限（虚拟时间才是约束项）。
