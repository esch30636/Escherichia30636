# B 题 · 无线电干扰源的快速自动定位与清除（CUMCM 2026）

本目录是 B 题的求解工程。模型推导、方法、验证与蒙特卡洛演练统计的详细内容见
**[成果汇总.md](成果汇总.md)**（论文素材主文档）；本 README 回答"有哪些文件、各在哪里、怎么复现"。

**重要约定（应队内要求）：未安装官方模拟器。** 问题3/4 的仿真验证全部在自研环境
`b_sim.py` 中进行；`b_sim.py` 严格按附件2通信协议（HTTP+JSON，`/enter /measure /clear /exit`，
含幂等、错误码、计时规则）实现，`b_robot.py` 通过 HTTP 协议与之通信，因此**可直接连接官方
模拟器运行**（无需改代码，仅需换 URL / robot_id），但本工程不包含任何官方模拟器测试记录。

## 3. 关键结果速览

**问题1（定位区域与覆盖圆）**：k 个检测点测得的示向度（±1° 误差）把源限定在 2k 个半平面的
交（凸多边形）。区域直径 D 由对径点对给出；最小覆盖圆 r_min 覆盖判定即 r_min ≤ D/2。
Jung 定理保证 r_min/D ≤ 1/√3 ≈ 0.577（比 D/2 判定最多松 15.5%，等边三角形取等）。实测
k=2 时 r_min ≈ D/2（比值 ≤ 1.0006，覆盖判定几乎处处精确）；k≥3 比值最大 ≈ 1.14。
反例：两检测点与源共线同侧时 D 达到上界 2εd（ε=1°），覆盖判定给出源必在圆内的最紧界。

**问题2（第二检测点策略）**：最优 S2 = 沿示向度前进 1100 m 再偏转 **35°**（两侧对称），
P_s = 0.9994，E[D|成功] = **50.0 m**（对比：前进 500 m 得 500 m、垂直 500 m 得 121 m 且
P_s 仅 0.842；在源后方检测无界）。候选区域（P_s≥0.90 且 E[D]≤1.15×最优）：
**L ∈ [850, 1450] m，ψ ∈ [20°, 50°]**。

**问题3（全向源，7 站扫描）**：站集 = 原点 + 半径 1200 m 正六边形 6 站。已证盘内任一点距
最近站 ≤ 969 m < 1000 ≤ r_G，故每个源必被至少一站检测到（扫描 20 频道全覆盖）。MC 演练
（N=400）：**清除比例 100%（400/400）**，平均定位清除时间 **507 ± 50 s**（P95 590 s），
总虚拟时间均值 **6595 s**（P95 7829 s，扫描占 35.0%），远小于 360000 s 时限。

**问题4（含定向源，49 站扫描）**：站集 = 原点 + 600 m×12 + 1200 m×12 + **2100 m×24**。
对任意 G 与任意定向方向，disk(G,1000) 内站的方向角最大间隙 ≤ 158.4° < 180°，即任意
±90° 扇区内必有站且距 ≤ 1000 m → 每个定向源必被检测到（数值验证 60k 样本 0 失败；
外环半径必须 ≤ 2100 m，取 2150 m 即出现 180.7° 的边际失败）。归航越出定向扇区后用
二分回退 + 20 m 清除半径试探兜底。MC 演练（N=400）：**清除比例 100%（400/400）**，
平均定位清除时间 **1247 ± 148 s**（P95 1503 s），总虚拟时间均值 **16094 s**（P95 17564 s，
扫描占 68.3%）。

## 5. 与官方模拟器的对接说明

- `b_robot.py` 只通过附件2定义的 HTTP+JSON 协议与环境交互，`--http --url http://127.0.0.1:2026
  --robot-id <队号>` 即可在官方模拟器上运行，无需任何代码改动。
- `b_sim.py` 实现了同样的协议（含幂等重放、409 冲突、400/404/405/413/415/429、200+
  accepted=false 业务拒绝、计时规则：移动=距离/5 s、切换 1 s、检测 5 s、清除 5 s/3 s、
  示向度误差按 (源, 检测点) 固定、svd_deg 两位小数），与官方一致，用于本工程的演练统计。
- 按队内要求**未安装、未运行官方模拟器**，本工程不包含官方演练/正式测试的任何记录；
  最终提交如需官方测试，只需用上述命令连接官方模拟器。
