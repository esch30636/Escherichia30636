## 1 建模路线概述

本文的建模路线可概括为：**以物理模型为唯一求解器，以文献模型为选型依据与局限裁判，
以生成模型为不确定度输入源**。三者的职责边界明确、互不越界：

| 线索 | 在求解链中的位置 | 产出 | 不可替代性 |
|---|---|---|---|
| 物理模型 | **唯一的求解器**（控制方程 → 离散 → 积分） | result1–4、表 1–6、烘干时间 | 提供题目要求的内部场 `T(r,t)`、`C(r,t)` |
| 文献模型 | 求解链**之外**：论证与边界条件 | 假设合法性、组件出处、简化误差上界 | 回答"为何此模型适用于本题"与"漏掉了什么" |
| 生成模型 | 求解链**上游**：仅生成边界条件样本 | 61 h 烘房偏差情景 200 条 | 量化题面未给出的 53 h 环境条件 |

需要强调：**生成模型不产生任何物理预测**。任一情景轨迹均须代入同一套控制方程与同一套离散格式求解，
方能得到烘干时间；因而本文的预测能力完全来自物理模型，生成模型的作用仅限于构造边界条件的随机样本。

## 3 控制方程与移动边界变换

### 3.1 控制方程

设 `C` 为干基含水率（kg/kg），`T` 为温度（K）。在假设 H1–H3 下，药材内部的热湿传递由下列
轴对称抛物型方程组描述：

```
ρ(C)·c_p(C)·∂T/∂t = (1/r)·∂/∂r( k(C)·r·∂T/∂r )          (1)
∂C/∂t             = (1/r)·∂/∂r( D(C,T)·r·∂C/∂r )        (2)
```

式 (1)(2) 属 Whitaker 体积平均方程组 [13] 在"局部热平衡 [24] + 忽略气压梯度 + 忽略力学变形"
条件下的特例；水分方程的 Fick 型单场形式 [34][189] 以 [45] 的结论为依据略去了交叉项。

### 3.2 移动边界（front-fixing）变换

问题 4 中半径 `R(t)` 由 2.0 cm 收缩至 1.198 cm（附件 2）。引入曲线坐标

```
ξ = r / R(t) ∈ [0, 1]
```

对任一物理量 `u(r,t) = ũ(ξ,t)`，链式法则给出

```
∂u/∂t|_r = ∂ũ/∂t|_ξ − (ξ·Ṙ/R)·∂ũ/∂ξ                                          (3)
```

在**仿射收缩**假设 H4 下，每个材料点固定于自身 `ξ`，故材料导数即 `ξ` 坐标下的偏导数，
式 (3) 右端第二项（表观对流项）恒为零。

**水分方程**。以随体控制体 `[ξ₁, ξ₂]` 作水分衡算，水的内含量为
`2πH·R²·∫ρ_d·C·ξ·dξ`，跨半径 `ξR` 的水分总流量为 `−2πH·ρ_d·ξ·D·∂C/∂ξ`，其中 `ρ_d` 为干物质密度。
由干物质守恒 `ρ_d·R² = const`，内含量对时间的导数中由 `R` 变化引起的项与干物质的
"压缩项"严格抵消，于是

```
ρ_d·R²·ξ·∂C/∂t|_ξ = ρ_d·∂/∂ξ( ξ·D·∂C/∂ξ )        ⇒   ∂C/∂t = (1/(R²ξ))·∂/∂ξ( ξ·D·∂C/∂ξ )   (4)
```

**`ρ_d` 完全约去**——这是式 (2) 在 `ξ` 坐标下不含物性密度的严格理由，也是水分方程无需
给定干物质密度的原因。收缩的全部影响体现为**有效扩散系数 `D/R(t)²`** 随 `R` 减小而增大。

**温度方程**。同理，在仿射收缩下材料导数等于 `ξ` 偏导数，式 (1) 化为

```
ρ·c_p·∂T/∂t = (1/(R²ξ))·∂/∂ξ( ξ·k·∂T/∂ξ )                                    (5)
```

### 3.3 边界条件与初始条件

```
ξ = 0 : ∂T/∂ξ = ∂C/∂ξ = 0                               (轴对称，无奇异)      (6)
ξ = 1 : −(k/R)·∂T/∂ξ = h·(T_s − T_air(t))               (对流换热)            (7)
        −(D/R)·∂C/∂ξ = h_m·(C_s − C_air(t))             (对流传质)            (8)
t = 0 : T = T₀ = 28 °C,  C = C₀ = 2.55 kg/kg                                  (9)
```

其中 `T_air(t)`、`C_air(t)` 取自附件 1，`h = 25 W/(m²·K)`、`h_m = 8×10⁻⁷ m/s` 取自附录 2。
式 (7)(8) 为第三类对流边界 [4][28][29]；需注意式 (8) 的驱动势是**烘房水分浓度**，
而非由吸湿等温线/水活度决定的表面平衡含水率（文献中的替代写法见 [55][175][185]），
这是题面给定口径下的直接采用。

### 3.4 特征时间尺度

对式 (1)(2) 作量纲分析。以初值状态 `C₀ = 2.55`、`T₀ = 301.15 K` 代入附录 3：

```
ρ = 976.4 kg/m³,  c_p = 3415.3 J/(kg·K),  k = 0.4830 W/(m·K)   ⇒  α = k/(ρc_p) = 1.448×10⁻⁷ m²/s
D₀ = 2.4×10⁻³·exp(−0.45/2.55)·exp(−3850/301.15) = 5.630×10⁻⁹ m²/s
```

```
热扩散时间      τ_T = R²/α          = 2762 s  = 46.0 min
质扩散时间      τ_C = R²/D₀         = 71051 s = 19.7 h
圆柱基模时间常数 τ₁  = R²/(λ₁²D₀)    = 12285 s = 3.4 h      (λ₁ = 2.4048, J₀(λ₁)=0 [189])
Biot 数         Bi  = hR/k          = 1.04
传质 Biot 数    Bi_m = h_m R/D      = 2.84
```

三者的量级分离为 `τ_T : τ₁ : τ_C ≈ 1 : 4.4 : 26`，构成本文两项判定的物理根据：
① 温度场在约 1 h 后进入准稳态，过程由水分扩散控制（与第 5.4 节敏感性结论一致）；
② 基模时间常数 3.4 h 与问题 2 的 3 h 考察窗同量级，故该窗口足以观察到水分的显著变化。
当 `C → 0.15` 时 `exp(−0.45/C)` 使 `D` 衰减 16.8 倍，`τ₁` 增至约 24 h，即末段"**自锁**"效应。

## 4 数值方法

### 4.1 有限体积半离散

将 `[0,1]` 等分为 `N = 400` 个单元，单元中心 `ξ_c,i = (i+½)/N`，面 `ξ_f = f/N`（`f = 0,…,N`）。
引入**约化通量**

```
Φ = −ξ·k·∂T/∂ξ   [W/m]        Ψ = −ξ·D·∂C/∂ξ   [kg/(m·s)]
```

（由 `ξ·q = const` 可知 `Φ` 在稳态下沿半径守恒；物理热流 `q = Φ/R`，总热流 `Q = 2πH·Φ`。）
在单元 `i` 上对式 (5) 作加权积分 `∫(·)ξdξ` 得守恒型半离散格式

```
dT_i/dt = (Φ_i − Φ_{i+1}) / ( ρ·c_p·R²·ξ_c,i·Δξ ),   Δξ = 1/N                  (10)
dC_i/dt = (Ψ_i − Ψ_{i+1}) / ( R²·ξ_c,i·Δξ )                                    (11)
```

内部面系数取**调和平均**（跳跃系数的界面通量连续的离散对应 [302][303]）：

```
G_f = ξ_f·2k_{f−1}k_f/(k_{f−1}+k_f)/Δξ        (传热)
```

调和平均优于算术平均有直接的数值证据 [298][299][300]。

### 4.2 表面通量的精确处理

表面单元中心 `ξ_c,N` 到相界面 `ξ = 1` 之间存在半单元距离，且系数按 `1/ξ` 变化。
由稳态关系 `dT/dξ = −Φ/(ξk)` 在 `[ξ_c,N, 1]` 上积分（该段内 `Φ` 为常数）：

```
T(ξ_c,N) − T_s = Φ_N · ∫_{ξ_c,N}^{1} dξ/(ξ·k) = Φ_N · ln(1/ξ_c,N)/k_N            (12)
```

联立式 (7)（写作 `Φ_N = h·R·(T_s − T_air)`）消去 `T_s`，得表面传导度

```
G_N = 1 / [ ln(1/ξ_c,N)/k_N + 1/(h·R) ]                                         (13)
```

式 (13) 是半单元导热与对流热阻的**精确串联**。常见的近似写法 `(Δξ/2)/(ξ_c,N·k_N)` 与之相差
`O(Δξ)`：由 `ln(1/(1−Δξ/2)) = Δξ/2 + (Δξ/2)²/2 + ⋯`，在 `N = 400`（`Δξ = 2.5×10⁻³`）下
相对偏差约 `6.2×10⁻⁴`。表面通量对温度场的影响权重最大，故本文采用式 (13)，
使表面值在两种独立实现（`ξ` 坐标与物理 `r` 坐标）间一致到 `10⁻¹⁵` 量级。

### 4.3 时间推进

采用线方法（MOL）：以式 (10)(11) 半离散为 `2N` 维刚性 ODE 初值问题，由
`scipy.integrate.solve_ivp(method='BDF')` 求解 [279][308][311][317]，取
`rtol = 10⁻⁸`、`atol = 10⁻¹⁰`。未知量按交错次序 `[T₀,C₀,T₁,C₁,…]` 排列，
单元 `i` 仅与 `i−1,i,i+1` 耦合，故 Jacobian 半带宽为 3；传入稀疏结构后
`N = 400` 时积分步数仅 515–4544 步。

### 4.4 输出采样与表面值反解

内部各列按 `ξ` 线性插值；最后一列（表面）**由边界条件反解**而非线性外推：

```
T_s = T_air + Φ_N/(h·R),    C_s = C_air + Ψ_N/(h_m·R)                          (14)
```

式 (14) 由式 (7)(8) 整理而得，其精度高于线性外推约一个数量级，是保证输出四位小数可靠的前提。

## 5 模型检验与验证

按 V&V 三分体系 [284][290] 报告如下三项独立检验。

### 5.1 代码验证：右端项恒等性

另写一套**物理 `r` 坐标**的独立实现（`a_ref.py`），在同一状态点上逐分量比较两套实现的右端项
（均匀初值、随机扰动、强梯度三种状态 × `t = 0, 137, 1800 s`）。相对偏差
**10⁻¹⁴ ~ 10⁻¹⁵**，即移动边界变换、通量装配与边界处理在机器精度内一致，
排除了求解器噪声对结论的影响。

### 5.2 守恒性检验

对式 (1)(2) 的积分守恒量作逐时刻核算：能量残差 **2.55×10⁻⁹**、水分残差 **2.12×10⁻⁹**（相对量）。

### 5.3 网格收敛性

以 `N = 1600` 的 Richardson 外推为基准 [283][287]，烘干时间的网格序列为

```
N = 100 : 206263.1 s   N = 200 : 205971.7 s   N = 400 : 205862.4 s   N = 800 : 205825.4 s
Richardson 极限 ≈ 205813 s
```

观测收敛阶为干净的 2 阶（离散格式与网格均匀性一致 [301]）。`N = 400` 时各列相对误差为
`C(r=0) −1.8×10⁻⁸`、`C(r=1.9) −1.3×10⁻⁵`、`C(表面) −2.5×10⁻⁶`、`T(表面) 3.6×10⁻⁶`，
均远小于保证四位小数所需的 `5×10⁻⁵`。据此全文取 `N = 400`。

### 5.4 结果的自洽性检验

- **与题面自述一致**：问题 3 得 205862.4 s = **57.1840 h = 2.3827 天**，
  问题 4 得 182974.1 s = **50.8261 h = 2.1178 天**，均落在题面所述"2–3 天"区间内；
  这是一个不依赖任何外部数据的独立检验。
- **与文献量级一致**：同类药材薄层（mm 级）在 40–60 °C 下干时为 7–32 h [85][95][110]；
  本文对象为半径 2 cm 的整根圆柱（特征尺寸大一个数量级）且终点含水率更低（末段自锁，
  `τ₁` 由 3.4 h 增至约 24 h），故干时长一个数量级是尺度效应与深度干燥的共同结果（第 6.3 节）。
- **问题 3/4 的交叉现象**：约 41.0 h 处两条中心含水率曲线相交（由两问中心水分曲线的
  600 s 采样插值确定），即问题 4 **前期更慢、后期更快**。
  其机理为两个相反效应的叠加：附录 4 的扩散前置因子（4.2×10⁻⁴）在 `C = 2.55` 时比附录 3
  （2.4×10⁻³）小 5.4 倍，使高含水阶段更慢；而收缩使有效系数按 `1/R²` 放大（最大 2.79 倍），
  且附录 4 的浓度依赖 `exp(−0.30/C)` 弱于附录 3 的 `exp(−0.45/C)`，使低含水阶段反超。

### 5.5 敏感性分析对模型判定的支持

以弹性系数 `S = (Δt/t)/(Δp/p)` 作单因子分析（OAT，[406][408]）：

| 参数 | 问题 3 `S`（+20% / −20%） | 问题 4 `S` |
|---|---|---|
| 扩散系数 `D` | **−0.73 / −1.11** | **−0.73 / −1.10** |
| 传质系数 `h_m` | −0.091 / −0.148 | −0.039 / −0.067 |
| 换热系数 `h` | −0.001 / −0.002 | −0.001 / −0.002 |
| 导热系数 `k` | ≈ 0 | ≈ 0 |
| 密度 `ρ`、比热 `c_p` | +0.002 | +0.002 |

**判定**：烘干时间几乎完全由扩散系数决定，全部传热类参数的弹性 `|S| < 0.003` 可以忽略。
其物理根据正是第 3.4 节的时间尺度分离 `τ_T ≪ τ_C`：传热参数只影响最初约 1 h 的热瞬态，
而过程总长达数十小时。该结果反过来支持了本文的建模选择——**温度场可按准稳态处理，
过程由水分扩散控制**。

## 6 模型论证：文献依据与组件映射

本节回答两个评审必然提出的问题：**为何选取此模型**，以及**模型的每个组件出自何处**。

### 6.1 模型选型论证

文献中干燥传质模型存在六代谱系（Fick → Philip–de Vries → Luikov → Whitaker → REA →
介观/数据驱动，详见 `文献核心模型汇总.md` §1）。逐条比较如下：

| 候选模型 | 优点 | 本题不采用的理由 | 依据 |
|---|---|---|---|
| Luikov 全式（含交叉项） | 双场框架最完整 | 交叉系数 `K12`、`K21` 赛题未给；恒温段 Soret 效应可略 | [2][45] |
| Whitaker 多相方程组 | 物理最严格 | 需相渗透率、毛细压力曲线、孔隙率等未给参数 | [13][22] |
| Philip–de Vries 双通量 | 区分液/汽两相输运 | 等温条件下 `D_θ` 主导，`D_T` 可并入等效 `D` | [36][41] |
| REA / S-REA | 参数少，擅长大变形与非平衡 | 需平衡含水率 `X_e` 与活化能 `ΔE_v` 实验数据 | [55][56] |
| 孔网络 / 分形 / LBM | 微观机理清晰 | 需孔隙尺度结构数据 | [37][40][53] |
| 经验薄层模型（Page、Midilli 等） | 参数少，拟合优度高 | **无法给出题目要求的内部场 `T(r,t)`、`C(r,t)`** | [81][138] |
| **Fick 双场 + 移动边界 + FVM/BDF（本文）** | 参数全部由赛题给出、给出全场剖面、可验证可收敛 | —（在准稳态 + 局部平衡 + 恒温条件下成立） | [18][189][216][307] |

结论：在"参数全部由赛题给定"的硬约束下，可选的完整模型族（Luikov 交叉项、Whitaker 多相、
REA、介观）均因缺参数而不可辨识；而经验模型虽可拟合，却**无法满足题目对内部剖面的要求**。
因此 Fick 双场 + 移动边界是本题约束下**唯一同时满足"参数可得"与"给出全场剖面"的选择**。

### 6.2 逐组件映射

本文模型的 20 个组件与文献的对应关系（完整表见 `文献核心模型汇总.md` §4），关键项摘录：

## 7 模型简化 H5 的量化：蒸发潜热汇项

### 7.1 命题

文献中干燥能量方程通常含蒸发潜热汇项 [31][30][32][52]，而本文式 (1) 与式 (5) 不含该源项。
本节不满足于定性说明，而是**将该项补全后重解问题 2**，给出简化误差的定量上界。

### 7.2 两种等价写法

```
vol  (体积汇，Luikov 型):  ρc_p·∂T/∂t = (1/r)∂/∂r(k r ∂T/∂r) + L_v·ρ_c·∂C/∂t      (15)
surf (表面通量):           式 (5) 不变，表面边界 (7) 增加潜热流 L_v·J_s，
                           J_s = ρ_c·h_m·(C_s − C_air)                            (16)
```

两式的**能量总量严格相等**（潜热总量 = `L_v` × 总失水量），差别仅在于潜热在空间上的吸收位置：
`vol` 按局部失水率分布，`surf` 全部在表面扣除。`surf` 写法需重新推导表面反解：由表面能流平衡

```
(T_{N−1} − T_s)/R_c = h·R·(T_s − T_air) + Λ,   R_c = ln(1/ξ_c,N)/k_N,  Λ = L_v·ρ_c·Ψ_N
```

消去 `T_s` 得

```
Φ_N = G_N·(T_{N−1} − T_air) + Λ/(1 + R_c·h·R),   T_s = T_air + (Φ_N − Λ)/(h·R)    (17)
```

### 7.3 换算密度 `ρ_c` 的口径

模型的水分方程是**约化**的：物理水分质量为 `2πH·ρ_d·R²·∫C·ξ·dξ`，故模型约化通量 `Ψ` 对应的
水的质量通量为 `J_s = ρ_d·h_m·(C_s − C_air)`。由第 3.2 节的干物质守恒，问题 2/3 中 `R` 恒定
⇒ `ρ_d` 恒定，由初值锚定：

```
ρ_d = ρ(C₀)/(1+C₀) = (650 + 128×2.55)/3.55 = 275.04 kg/m³       ← 推荐口径 (dry0)
```

对照口径（用作上下界，见 `02-lit/README.md`）：`dry`：`ρ(C)/(1+C)`（275→582）；
`bulk`：`ρ(C)`（650→976）；`unit`：1（"浓度型"下界）。四种口径跨越 **10³ 量级**，
构成本节结论的唯一不确定来源，故本文全部给出而不仅报单一值。

### 7.4 数值结果与结论

取 `L_v = 2383 kJ/kg`（50 °C 蒸汽表值；28–50 °C 内由 2435 降至 2383，变化 2.2%），
`Le = 0.849`。主要结果：

| 量 | 数值 | 说明 |
|---|---|---|
| 热质类比传质系数 | `h_m ≈ h/(ρ_a c_{p,a} Le^{2/3}) = 2.4531×10⁻² m/s` [29] | 题面给定 `8×10⁻⁷ m/s`，**小 3.066×10⁴ 倍** |
| 3 h 内潜热流 `L_v·J_s` | **503 ~ 847 W/m²** | 为同期对流的 5.5 ~ 88 倍 |
| 烘房最大可供给热流 | `h(T_air − T₀) = 25 × 22.17 = 554 W/m²` | 潜热流在 t = 0.5 h 已达 847 W/m²，**超过该上限** |
| 含潜热模型预测的最低料温 | 表面 11.03 ~ 12.35 °C，中心 9.62 ~ 12.20 °C | **低于初始温度 28 °C**，且低于湿球温度约束的表面温度下限 [10] |
| 烘干时间（全流程） | 基线 **57.1840 h**；`vol·dry0` **61.0873 h（+6.83%）**；`surf·dry0` **60.1766 h（+5.23%）**；`vol·unit` 57.1968 h（+0.02%） | 全部仍落在"2–3 天"内 |

**结论**：
1. 潜热项在题面参数下**不是小量**，且与题面参数体系**不能自洽共存**——题面 `h_m` 比热质类比式
   小 3.07×10⁴ 倍，且对流供热能力不足以在表面维持接近烘房温度的同时供上潜热流。
   这说明题面参数是按"**潜热并入有效参数**"的简化口径标定的，即题面"为简化问题"的确切含义。
2. **但对本文关心的结论（烘干时间）影响有限**：在模型自洽的换算口径下仅长 5.2%–6.8%，
   在最保守的下界口径下仅 0.02%。据此本文将式 (1)(5) 的无潜热模型作为正式模型，
   并声明：**该简化对本题结论的影响 ≤ 7%**（已量化）。
3. 出于严谨，本文不采用含潜热模型的数值作为答案——其 3 h 中心温度与基线相差约 28 K，
   已超出题目参数体系的适用范围，只能作为模型讨论而非结果。

**验证**：① 补全潜热能力后，基线路径仍与冻结版结果**逐位一致**（表 3、表 4 偏差 `0.000e+00`），
证明模型扩展未扰动原有结论；② 含潜热模型的能量记账满足半离散恒等式
`Σ(ρ·c_p·ξ·Δξ·dT/dt) = (q_conv − q_lat)/R`，在三个状态点上的相对残差为 `10⁻¹⁴ ~ 10⁻¹⁶`。

## 8 模型简化 H6 的量化：烘房情景的数据驱动不确定度分析

### 8.1 命题

附件 1 仅提供前 14400 s 的烘房温湿度，而问题 3/4 的积分区间为 205862 s / 182974 s，
即**约 53 h 的环境条件未给定**。基准假设 H6 为"此后维持末值"
（`T = 50.1650 °C`，`C = 0.04986 kg/kg`）。该假设的影响须拆为两个通道分别量化：

```
H6 的影响 = ① 系统性设定值偏移  +  ② 围绕设定值的随机波动
            （§8.2 前的常数偏移情景已覆盖）  （本节用生成模型量化）
```

**通道 ①** 由常数偏移情景给出保守界：烘房 `−5 °C` → 问题 3 干时 `+18.2%`、
`+5 °C` → `−14.6%`（问题 4 为 `+18.1%`/`−14.5%`）。其量级超过任何单一物性参数
（`D` 的 `±20%` 仅对应 `−14.7%`/`+22.2%`），因为 `D` 含 Arrhenius 因子 `exp(−3850/T)`：
**温度每升高 1 K，`D` 增大约 3.7%**。故 H6 是本题**最大的建模不确定度来源**。

### 8.2 恒温段偏差的统计特征

取附件 1 后 2 h（`t ∈ [7200, 14400] s`，121 个样本，60 s 间隔），逐通道线性去趋势后的残差
`d_T`、`d_C` 的统计特征为：

| 通道 | 水平 lag-1 | 一阶差分 lag-1 | 标准差 | 结构判定 |
|---|---|---|---|---|
| 温度 `d_T` | +0.009 | **−0.526** | 0.1571 °C | 近似**白噪声**（差分强负相关 = 围绕设定值来回修正，控制器特征） |
| 湿度 `d_C` | **+0.537** | — | 2.31×10⁻⁴ | **持续型**；且其持久性几乎全部来自 >30 min 的窗口均值慢漂移（窗内去均值后 lag-1 仅 ≈ 0.07） |

该特征表明：简单的高斯白噪声只能复现边际标准差，**无法同时复现"温度白噪声 + 湿度慢漂移"的
联合时间结构**。这正是引入生成模型的必要性，而非为使用深度学习方法而使用。

### 8.3 生成模型

**生成器选择**：采用 WGAN-GP [413][414][416]，并附加矩匹配正则。记 30 min 窗口
（`L = 30` 个样本）的生成器为 `G: ℝ¹⁶ → ℝ³⁰`，判别器为 `D: ℝ³⁰ → ℝ`，则

```
L_D = E[D(G(z))] − E[D(x)] + λ_GP·E_{x̂}[( ‖∇_{x̂}D(x̂)‖₂ − 1 )²],   x̂ = εx + (1−ε)G(z)   (18)
L_G = −E[D(G(z))] + λ_m·Σ_k w_k·( m_k(G(z)) − m_k(x) )²                                (19)
```

取 `λ_GP = 10`、`λ_m = 2`、`N_critic = 5`、批次 64、训练 4000 次迭代（CPU 约 100 s）。
矩 `m_k` 取（**逐窗口去均值后**）{两通道标准差, `d_T` 差分 lag-1, `d_C` 水平 lag-1, `corr(d_T,d_C)`}。
其中"逐窗口去均值"是必要的：若对全局去均值，窗口间慢漂移会混入相关计算，
使实测的 `d_C` 自相关由 0.537 被稀释至 0.33，(19) 式将匹配错误的目标。

**结构**：生成器 `16 → 3×128 → 30`，**输出层线性**。此处不用 `tanh` 是有意的：
`tanh` 将输出幅值限制在 `±1` 个标准差内，使 61 h 轨迹的极值范围仅剩 0.31 °C，
将系统性削掉真实极值；判别器为 2 层全连接。

**轨迹装配**：逐窗生成 30 min 序列，相邻窗按 10 min 线性交叉淡化拼接至 61 h（3427 步），
以消除拼接处的人工间断。

### 8.4 校验与三角验证

本文不以单一生成器的正确性作为结论的前提，而同时构造两个结构已知的基线生成器
（**块自助**：循环重采样 10 min 实测块，非参数；**参数化**：`d_T ~ i.i.d. N(0,s_T)`，
`d_C ~ AR(1), ρ = 0.536`），三者全部传播，结论互相印证：

| 生成源 | `s_T` (°C) | `d_T` 差分 lag-1 | `d_C` 水平 lag-1 | 61 h 平均极差 `T` (°C) |
|---|---|---|---|---|
| 实测（后 2 h） | 0.1571 | **−0.526** | **+0.537** | 0.570（仅 4 h） |
| **GAN** | 0.1521 | −0.498 | +0.217 | **1.209** |
| 块自助 | 0.1560 | −0.525 | +0.398 | 0.570 |
| 参数化 | 0.1570 | −0.501 | +0.536 | 1.124 |

三源均复现了温度通道的 i.i.d. 特征（差分 lag-1 ≈ −0.50 ~ −0.53）与边际标准差（0.152 ~ 0.157
对实测 0.157）。**本文如实报告一项不足**：GAN 拼接后 `d_C` 的水平 lag-1 为 0.217，
低于实测 0.537，即窗口内的白噪声结构正确、窗口间的慢漂移仅部分复现。因其影响可忽略
（`C_air` 变化 ±0.02 仅对应干时 ∓0.4%/+1.2%），本文以参数化基线（`ρ` 精确等于 0.536）
作交叉校验，并以三源一致的结论作为最终判据。

### 8.5 传播与结论

将每条情景经 `a_model.py` 的 `chamber_series` 接口作为自定义烘房时序代入**同一求解器**
（`N = 400`，同一格式、同一容差），得到烘干时间分布。每源 200 条情景 × {问题 3, 问题 4}
+ 维持末值基准 = 1202 次求解（24 进程并行，2787 s）。尾段按 300 s 采样：因烘干的热/湿时间
常数约为 1 h，亚小时波动被系统滤波；一致性检验为同一情景 60 s 全采样 57.1506 h
对 300 s 采样 57.1087 h，相差 0.07%。

| 情景源 | 问题 3 均值 ± std (h) | P05–P95 (h) | Δ均值/维持 | 问题 4 均值 ± std (h) | Δ均值/维持 |
|---|---|---|---|---|---|
| 维持末值 | 57.1840 | — | — | 50.8261 | — |
| GAN | 57.1239 ± 0.0088 | 57.1086–57.1373 | −0.11% | 50.7740 ± 0.0079 | −0.10% |
| 块自助 | 57.1767 ± 0.0102 | 57.1595–57.1968 | −0.01% | 50.8201 ± 0.0093 | −0.01% |
| 参数化 | 57.1833 ± 0.0118 | 57.1640–57.2031 | −0.00% | 50.8261 ± 0.0105 | −0.00% |

**结论**：随机波动引起的烘干时间标准差 **σ ≈ 0.01 h（≈ 0.6 min）**，95% 区间宽度约 2 min；
与参数不确定度（第 9 节，`σ = 4.5 h`）和系统性偏移情景（`∓14.6%/+18.2%`）相比，
**波动通道小两个数量级以上**。因此假设 H6 的风险几乎全部来自**系统性设定值偏移**，
随机波动可以忽略——§8.1 的常数偏移情景正是该假设的正确风险界。

### 8.6 生成器残余均值偏置的量化

上表三源的均值偏移（−0.11% / −0.01% / −0.00%）需给出机制解释，本文对其作如下核算。
本文采用的两项检验为：

1. **凸性（Jensen）整流项的估计**。因 `D ∝ exp(−a/T)`（`a = 3850 K`）在本题温区内对 `T` 为凸函数，
   温度波动经凸响应整流后应使平均扩散系数略增，从而略微加速烘干。其二阶估计为
   `⟨D⟩/D(T̄) − 1 ≈ σ_T²·a(a/2 − T̄)/T̄⁴ = 1.3×10⁻⁵`（`T̄ = 323.3 K`，`σ_T = 0.157 K`），
   对应干时变化约 `10⁻⁵`（约 3 s），**比观测偏移小近两个数量级，故不是主因**。
2. **生成序列残余均值偏置的换算**。矩匹配正则 (19) 约束的是标准差、lag-1 自相关与互相关系数，
   **不约束均值**，故各源残余均值可存在微小偏置。由第 8.1 节的温度灵敏度
   `∂(Δt/t)/∂⟨d_T⟩ = −0.79 × a/T̄² = −2.91 %/K`，可将其换算为干时偏移。实测核算如下：

| 生成源 | 残余均值 `⟨d_T⟩` (K) | 残余均值 `⟨d_C⟩` (kg/kg) | 逐条时均 `d_T` 范围 (K) | 由均值偏置预计 `Δt/t` | 实测 `Δt/t` |
|---|---|---|---|---|---|
| GAN | **+0.01685** | +7.84×10⁻⁵ | +0.00774 ~ +0.02429（**全为正**） | −0.049% | −0.11% |
| 块自助 | +0.00598 | +2.60×10⁻⁵ | −0.00313 ~ +0.01292 | −0.017% | −0.01% |
| 参数化 | +0.00011 | −2.06×10⁻⁷ | −0.00846 ~ +0.00651 | −0.000% | −0.00% |

**判读**：① 参数化源（均值偏置 `1.1×10⁻⁴ K`，可视为零）给出 `−0.000%` 的预计与 `−0.00%` 的实测，
**完全吻合**，验证了"均值偏置 → 干时偏移"的换算关系与灵敏度系数；② 块自助源同号同量级吻合；
③ GAN 源的实测偏移约为其均值偏置预计值的 2.2 倍，即除均值偏置外还有约同量级的剩余贡献，
可归因于其时间结构差异（`d_C` 相关长度偏短、61 h 极值范围 1.209 °C 显著宽于块自助的 0.570 °C）。
**三种来源的偏移方向一致（均为负）、量级均在 0.1% 以内**，且远小于波动通道的判定阈值，
故不影响本节结论。作为方法学结论，本文指出：**矩匹配正则应补充对均值的约束**，
否则生成轨迹的残余均值不受控，会将微小偏置传入 UQ 结果。

## 9 不确定度分解与综合结论

汇总各来源对烘干时间的影响（以问题 3 为基准）：

| 来源 | 传播方式 | 对干时的影响 | 相对量级 |
|---|---|---|---|
| 外部条件（H6）系统偏移 | 常数偏移情景 | `−5 °C: +18.2%`；`+5 °C: −14.6%` | **10⁰（主导）** |
| 物性参数不确定度 | 拉丁超立方 MC，`N = 1000` [409][403][404] | `57.69 ± 4.53 h`（CV 7.85%，P05–P95 51.1–65.2 h） | 10⁰ |
| 外部条件（H6）随机波动 | WGAN-GP 情景传播 | `σ ≈ 0.01 h`（≈ 0.6 min） | **10⁻²（可忽略）** |
| 模型简化（H5，潜热汇项） | 补全后重解 | `+5.2% ~ +6.8%`（下界口径 +0.02%） | 10⁻¹ ~ 10⁻² |

蒙特卡洛与烘干时间的相关系数：`D` 为 `−0.98 / −0.99`（绝对主导），`h_m` 为 `−0.18 / −0.09`，
其余 `|r| < 0.04`——即**在上述参数不确定度下，烘干时间的不确定度基本等于 `D` 的不确定度**，
95% 区间约为 `57.4 h ± 7 h`。

**综合结论**：

1. 问题 3 烘干时间为 **205862.4 s = 57.1840 h = 2.3827 天**；
   问题 4 为 **182974.1 s = 50.8261 h = 2.1178 天**，收缩使干时缩短约 6.4 h。
   两者均落在题面所述"2–3 天"内，且与文献量级自洽（第 6.3 节）。
2. 全部数值均通过三项独立验证（右端项恒等性 `10⁻¹⁴~10⁻¹⁵`、守恒残差 `~10⁻⁹`、二阶网格收敛），
   四位小数可靠。
3. 模型的两处实质简化已分别量化：潜热汇项（H5）对结论影响 **≤ 7%**；
   烘房条件假设（H6）的随机波动通道 **σ ≈ 0.01 h**、可忽略，其真实风险为**系统性设定值偏移**
   （`±5 °C` → `∓14.6%/+18.2%`），已给出保守界。

## 10 模型评价

### 10.1 优点

1. **参数完全来自题面**：模型不含任何需要外部实验标定的可调参数，全部物性与边界系数
   （附录 2/3/4、附件 1/2）均由赛题给定，可复现性强。
2. **给出全场剖面**：相对于经验薄层模型，本模型给出题目要求的 `T(r,t)`、`C(r,t)`，可直接填表 1–6。
3. **移动边界的严格处理**：`ξ = r/R(t)` 变换 + 仿射收缩假设，使收缩的影响以 `D/R²` 的解析形式
   进入方程，避免了动网格带来的守恒误差；干物质守恒使 `ρ_d` 严格约去（第 3.2 节）。
4. **表面通量的精确格式**：式 (13) 的串联热阻为半单元导热的精确解，消除了 `O(Δξ)` 的格式误差。
5. **验证完备**：代码验证、守恒性、网格收敛性三项独立检验全部通过，并有独立坐标系实现交叉验证。
6. **简化误差已量化**：对仅有的两处实质简化（H5、H6）均给出定量的误差上界而非定性说明。

### 10.2 局限（均已量化）

| 局限 | 影响 | 依据/处理 |
|---|---|---|
| 能量方程未含蒸发潜热汇项 | 干时被低估 **≤ 7%** | 第 7 节；文献处理见 [31][30][32] |
| 恒温阶段烘房条件未给定 | 系统偏移通道 `∓14.6%/+18.2%`；波动通道可忽略 | 第 8 节；最大不确定度来源 |
| 省略 Soret/Dufour 交叉项 | 恒温段可忽略；快速升温段（前 2 h）理论上有偏 | [45][48] |
| 物性不含 `k(T)` 依赖 | 未量化（赛题口径如此） | [148][151] |
| 仿射收缩假设 | 未量化；文献中收缩可各向异性 [224][225][234] | [222][307] |
| 未含力学耦合与结壳 | 未量化；高收缩率下有影响 | [244][246][249][261] |

### 10.3 改进方向

1. **采用含潜热的完整模型**：本文已实现该能力（第 7 节），若采用需同步重解问题 3/4
   并更新全部结果文件；在当前参数体系下，其预测的早期料温超出湿球温度约束，
   故须连同边界条件一并重新标定。
2. **烘房模型的闭环化**：将烘房视为受控系统，用控制器模型代替"维持末值"假设，
   可从根本上消除 H6。
3. **收缩机理的参数化**：以各向异性或力学耦合模型 [226][261] 代替附件 2 的几何标定，
   可检验仿射假设的误差。
4. **矩匹配正则的完善**：如第 8.6 节所述，对生成轨迹补充均值约束。
