## 1. 主干模型族（干燥传质理论的六代谱系）

### 1.1 Fick 扩散模型与有效扩散系数框架（第一代）

**形式**（柱坐标一维径向）：

```
∂C/∂t = (1/r) ∂/∂r ( D_eff r ∂C/∂r )
```

**假设**：水分迁移由浓度（含水率）梯度驱动；毛细、蒸汽、表面扩散等全部机制被打包进单一
`D_eff`；温度只通过 `D_eff(T)` 间接进入。

**代表文献**
- 综述与方法：[34]（D_eff 测定与含水率/温度依赖表达）
- 函数形式：`D = (B·M₀ + C)·exp(−Ea/RT)` [160]；含水率下降时 D 指数增大的实测 [161]；
  `D(M)` 依赖不可省（只含 T 平均相对误差 19.8%）[188]
- 圆柱几何实测与反演：[164][165][166][170]；`Bi` 有限时 D 的反演偏差 [168][441]
- 解析基础：[189]（Crank，圆柱级数解）、[194]（Crank 简化式的系统偏差）

**在本题中**：**直接采用**为骨架方程；`D_eff` 由赛题附录给出为 `D(C,T)`，其结构
（温度 Arrhenius 项 × 含水率指数项）与 [160][161][188] 同族。

### 1.2 Luikov 热湿耦合方程组（第二代，最接近本题的母体）

**形式**：

```
∂T/∂t = K11 ∇²T + K12 ∇²C
∂C/∂t = K21 ∇²T + K22 ∇²C
```

**假设**：温度梯度也驱动水分（热湿传导/Soret），水分梯度也影响温度（Dufour）；交叉系数
K12、K21 用 Luikov 数 Lu、相变数 Pn 等无量纲准则表达。第三类对流边界与"单值性条件"
（初值 + 边界）有标准写法。

**代表文献**：[1][2][3]（原始专著与权威综述）、[4]（单值性条件）、[5]（物性随含水率变化的
非线性解）、[6]（集总-微分降维）、[7]（加气压梯度的三场扩展）、[8]（周期边界半解析解，
可作自制程序的**基准解**）、[9]（吸湿毛细多孔体高效数值解）、[10][11]（恒速/降速转折与
经典解析解）。

**在本题中**：**取"双场、弃交叉"**——保留两场耦合框架，省略 K12、K21 项。依据 [45]：
Soret/Dufour 交叉效应在**恒温干燥可忽略**、仅在动态变温时不可忽略；本题主体是恒温段
（2 h 后烘房稳定在 ~50 °C）。

### 1.3 Philip–de Vries 液汽双通量模型（并行物理路线）

**形式**：水分通量由两个驱动势叠加

```
j = −D_T ∇T − D_θ ∇θ
```

**假设**：液态流与蒸汽扩散并行；在等温、高含湿区，D_θ 主导，D_T 可并入等效 D。

**代表文献**：[36]（原始文献）、[41]（毛细流/蒸汽扩散切换判据）、[42]（非稳态蒸发）。

**在本题中**：用于**假设 H3 的合理性论证**——本题径向温差在准稳态后仅约 0.12 °C
（见 `成果汇总.md` §3），温度梯度驱动项相对可忽略，故可用单一 `D(C,T)` 代替双通量。

### 1.4 Whitaker 体积平均理论（第三代，严格化）

**形式**：对液相、汽相、空气相、固相分别写守恒方程，经 REV（代表性单元体）尺度分离
`l ≪ d ≪ L` 平均与闭合，得到含有效系数的宏观方程组；在**局部热平衡**假设下退化为单一
温度方程 + 水分方程。

**代表文献**：[13]（奠基）、[14]（闭合与交叉耦合通量）、[15]（温度+饱和度耦合方程）、
[16]（方法学专著）、[17]（水分迁移机制分类）、[19]（完整方程组数值求解与敏感性）、
[20][21]（理论推导与饱和/非饱和统一处理）、[23]（TransPore 控制体积法实现）、
[25]（40 年机理建模总览）、[18]（Luikov/Whitaker/REA/Krischer 全面对比）。

**在本题中**：作为**模型体系归属**引用——说明本题方程是体积平均方程组在
"局部热平衡 + 忽略气压梯度 + 忽略力学变形（问题 1–3）"下的特例；局部平衡的成立性
引 [24][50]。

### 1.5 REA 反应工程法（第三代变体）

**形式**：把蒸发视为"活化"过程，干燥速率写成

```
ṁ_v ∝ ρ_v,sat(T) · exp( −ΔE_v / (R T) ) · (传质项)
```

ΔE_v（蒸发"活化能"）随含水率变化；S-REA 版本给出空间水蒸气浓度剖面 [57]。

**代表文献**：[55]（专著）、[56]（REA 与 Fick 型、Luikov、Whitaker 的**适用性直接对比**，
模型选型论证素材）、[57][58]（空间化版本与综述）。

**在本题中**：**不采用**——REA 需要平衡含水率 `X_e` 与活化能 `ΔE_v` 的实验数据，赛题未给；
但 [56] 用于 §3 的模型选型论证。

### 1.6 介观/微观模型（孔网络、分形、LBM）

**代表文献**：[37]（孔网络综述）、[38][39]（蒸发主导机制与降速期蒸汽扩散）、
[40]（分形迂曲毛细管估算 D_eff）、[52]（LBM 综述）、[53]（孔网络 30 年）、
[54]（吸湿多孔介质 DNS）。

**在本题中**：**不采用**（需要孔隙尺度结构数据），用于"模型尺度层级"讨论与局限说明；
[136]（枳壳 CT 建模）说明有微观数据时可走这条路。

### 1.7 交叉效应（Onsager / Soret–Dufour）

**代表文献**：[44]（Onsager 不可逆热力学导出交叉通量系数）、[45]（**结论：动态变温干燥
不可忽略、恒温干燥可略**）、[46][47]（Soret/Dufour 数对热湿对流的量化）、
[48]（非傅里叶/非斐克松弛时间的适用判据）。

**在本题中**：**不采用**，但 [45] 是"省略交叉项"这一简化的**直接依据**；[48] 用于说明
快速升温段理论上的局限。

### 2.5 圆柱几何解析模型

**无限长圆柱（Fick）**：


## 3. 模型选型论证：为什么是"Fick 双场 + 移动边界 + FVM/BDF"

| 候选模型 | 优点 | 本题不适用的原因 | 依据 |
|---|---|---|---|
| Luikov 全式（含交叉项） | 最完整的双场框架 | 交叉系数 K12/K21 赛题未给；恒温段 Soret 可略 | [2][45] |
| Whitaker 多相方程组 | 物理最严格 | 需相渗透率、毛细压力曲线、孔隙率等（赛题未给） | [13][22] |
| REA / S-REA | 参数少、擅长大变形与非平衡 | 需平衡含水率与活化能实验数据 | [55][56] |
| 孔网络 / 分形 / LBM | 微观机理清晰 | 需孔隙尺度结构数据 | [37][40][53] |
| 经验薄层模型（Page 等） | 参数少、拟合优度高 | **给不出题目要求的内部 T(r,t)、C(r,t) 剖面** | [81][138] |
| **Fick 双场 + 移动边界（本题）** | 参数全部由赛题给出；给全场剖面；可验证、可收敛 | —（在"准稳态 + 局部平衡 + 恒温"条件下成立） | [18][189][216][307] |

补充论证（可写入论文"模型假设"一节）：
1. **局部热平衡**成立：含湿多孔介质在本题尺度（R=2 cm）与加热速率下，局部热平衡假设的
   适用判据见 [24][50]；
2. **温度准稳态**：τ_T = 46 min ≪ τ_C = 19.7 h，温度场在约 1 h 后即由水分扩散主导
   （§5.1 敏感性：h、k、ρ、cp 的弹性 |S| < 0.003）；
3. **交叉效应可略**：[45] 明确"恒温干燥可忽略"；
4. **忽略收缩的代价已知**：[230] 给出 75–83% 的 D_eff 高估量级，这正说明问题 4 必须建模收缩。

## 5. 可直接写进论文的"模型—文献"表述（模板）

1. **模型归属**：本文采用 Whitaker 体积平均理论 [13] 在局部热平衡 [24] 与常压条件下的
   Fick 型简化：温度场与含水率场各由一个抛物型方程描述 [34][189]，两场通过
   `k(C)`、`D(C,T)` 与边界条件耦合。
2. **省略交叉项**：温度梯度驱动的水分迁移（Soret/Dufour 效应）在恒温干燥条件下可以忽略
   [45]，本文主体干燥段为恒温段，故水分通量仅取浓度梯度项。
3. **几何与假设**：药材为长径比 12.5 的圆柱，热风沿周向均匀，取轴对称一维径向模型；
   圆柱轴对称处理的先例与一维近似误差见 [192][215][224]。
4. **物性**：ρ、cp、k 的含水率依赖式与食品物料组分模型的总体规律一致 [146][149][151]；
   扩散系数的温度与含水率依赖形式与 [160][161][188] 同族。
5. **移动边界**：问题 4 采用 front-fixing 变换 [222][307] 将移动域映到固定计算域
   `ξ = r/R(t)`；在仿射收缩假设下不出现对流项，收缩的影响表现为有效扩散系数
   `D/R(t)²` 增大——与忽略收缩会高估 D_eff 75–83% 的结论 [230] 方向一致。
6. **离散**：控制体法 [274] 与圆柱坐标 FVM [305]；界面系数取调和平均，其优于算术平均
   有直接的数值证据 [298]。
7. **时间推进**：线方法半离散后用 BDF 刚性积分器 [279][308][311]，软件实现为 SciPy 的
   `solve_ivp` [317]。
8. **验证**：按 Richardson 外推与 GCI 规范 [283][286][289] 报告网格收敛性，
   验证框架遵循 V&V 三分体系 [284][290]。
9. **终点**：干燥终点取干基含水率 0.15 kg/kg，与中药材安全含水率的吸湿等温线研究一致
   [183][184][185]。
10. **两阶段**：烘房 0–2 h 升温、随后恒温的设置属于分段变温工艺 [86][88][342]，
    其机理可用预热–恒速–降速三段干燥曲线说明 [333][334]。
11. **不确定度**：参数不确定度用拉丁超立方抽样传播 [409]，方法与食品干燥 UQ 研究一致
    [403][404]；烘房偏差情景用 WGAN-GP 生成 [413][414][416]。
12. **局限**：模型未含蒸发潜热汇项、力学耦合与各向异性收缩，相应文献处理见
    [31][244][263]；忽略收缩的代价与适用边界见 [230][237][376]。
