## 知识点详解

### 一、工作原理和结构

#### 概述：平板电容器的电容量与电容式传感器的分类

**定义**：电容式传感器（Capacitive Sensor）以电容器为敏感元件，将被测量转换为电容量变化。平板电容器由被绝缘介质分开的两个平行金属板组成，不考虑边缘效应（Edge Effect）时，其电容量为

$$C = \frac{\varepsilon A}{d} = \frac{\varepsilon_0 \varepsilon_r A}{d}$$

符号：$C$——电容量（F）；$\varepsilon$——极板间介质的介电常数（Dielectric Constant，F/m）；$\varepsilon_0$——真空介电常数（$8.854\times10^{-12}\ \text{F/m}$）；$\varepsilon_r$——介质相对介电常数（Relative Permittivity）；$A$——两极板有效覆盖面积（m²）；$d$——极距，即两极板间距（m）。

边缘效应（Edge Effect）：极板边缘处电场分布不均匀、电力线向外弯曲，使实际电容量偏离上式；上式成立的前提是不考虑边缘效应。

改变 $A$、$d$、$\varepsilon$ 三个参量中的任意一个量，均可使平板电容器的电容量 $C$ 改变。据此电容式传感器分为三类：

- ① 变极距型：覆盖面积和介电常数不变，被测量为极距，用于测量机械位移；
- ② 变面积型：改变覆盖面积（覆盖长度或宽度），用于测量位移；
- ③ 变介电常数型：覆盖面积及极距均不变，改变 $\varepsilon$，用于测量物性参数、物位等。

**理解**：电容量由两类要素构成：几何要素（覆盖面积 $A$、极距 $d$）与介质要素（介电常数 $\varepsilon$）。公式的直接含义是 $C$ 与 $A$、$\varepsilon$ 成正比、与 $d$ 成反比。分类的依据是"被测量改变哪一个参量"：测量机械位移时改变 $d$ 或 $A$；测量物性参数、物位时电极几何结构不变，介质成分变化使 $\varepsilon$ 变化。三类传感器共用同一基本公式，区别仅在于哪一个参量是被测量的函数。边缘效应是使实际电容偏离理论公式的非理想因素，其影响程度与极板面积、极距的取值有关。

**作用**：基础概念，独立知识点；本章全部内容的出发点。后置知识点：三类传感器各自的工作特性（变极距型、变面积型、变介电常数型），以及电容测量电路。

#### 1.1 变极距型电容传感器

**定义**：覆盖面积与介电常数保持不变、以极距 $d$ 为被测量的电容传感器。设初始极距 $d_0$ 对应的初始电容 $C_0 = \varepsilon A/d_0$，动极板移动使极距变为 $d = d_0 - \Delta d$（$\Delta d$ 为极距变化量，即被测量），则传感器电容为

$$C = \frac{\varepsilon A}{d_0 - \Delta d} = C_0 \cdot \frac{1}{1 - \dfrac{\Delta d}{d_0}}$$

课件给出的特性（原文）：随极距的增加电容减小；电容相对变化与极距相对变化呈现明显的非线性特性。课件配图为变极距型电容传感器结构图、电容相对变化–极距相对变化曲线（$\Delta C$–$\Delta d$）与极距–电容曲线（$d$–$C$）。

**理解**：极距位于电容表达式的分母，电容与极距之间不是比例关系。动极板位移使 $d$ 偏离 $d_0$ 后，$C$ 随 $d$ 的增大而单调减小，且减小速度随 $d$ 增大而变慢，因此 $\Delta C$ 与 $\Delta d$ 的关系曲线是弯曲的（非线性）。结构构成要素为定极板、动极板与极距 $d$；被测量（机械位移）直接改变极距这一几何参数。

**作用**：第三章三类电容传感器中的第一种，是灵敏度与非线性误差分析、差动结构分析、以及运算法测量电路的分析对象；与变面积型、变介电常数型并列。

#### 1.1 变极距型电容传感器：灵敏度

**定义**：对 $C = C_0/(1-\Delta d/d_0)$ 在 $\left|\Delta d/d_0\right| \ll 1$ 条件下按级数展开：

$$\frac{1}{1 - \dfrac{\Delta d}{d_0}} = 1 + \frac{\Delta d}{d_0} + \left(\frac{\Delta d}{d_0}\right)^2 + \left(\frac{\Delta d}{d_0}\right)^3 + \cdots$$

略去高次项得 $C \approx C_0\left(1 + \dfrac{\Delta d}{d_0}\right)$，即电容相对变化量

$$\frac{\Delta C}{C_0} \approx \frac{\Delta d}{d_0}$$

灵敏度（Sensitivity）为

$$K = \frac{\Delta C}{\Delta d} \approx \frac{C_0}{d_0}$$

变极距电容传感器典型参数：

| 参数 | 数值范围 |
| --- | --- |
| 极距相对变化量 $\Delta d/d_0$ | 约为 0.02～0.1 |
| 初始电容 $C_0$ | 20～100 pF |
| 初始极距 $d_0$ | 25～200 μm |

结论（课件原文）：由于非线性大，这种传感器一般应用于微位移测量。

**理解**：级数展开把分式关系分解为线性项与各高次项之和；只有当 $|\Delta d/d_0| \ll 1$ 时高次项才可忽略，此时电容相对变化量近似等于极距相对变化量，灵敏度近似为常数 $C_0/d_0$。灵敏度表达式的直接含义是：初始电容越大、初始极距越小，单位极距变化产生的电容变化越大。参数范围 0.02～0.1 表明允许的极距变化量仅为初始极距的百分之几至十分之一，这一限制是该传感器只适用于微位移测量的直接原因。

**作用**：给出变极距型传感器的线性化近似与灵敏度公式，是差动结构分析（灵敏度倍增、非线性改善）的比较基准；也是运算法测量电路中"输出幅值与被测量成正比"结论的依据。

#### 1.1 变极距型电容传感器：非线性

**定义**：单电容（非差动）变极距传感器的相对非线性误差（Nonlinearity Error）$\delta$ 定义为级数展开中二次项与一次项之比，课件给出的表达式为

$$\delta = \frac{\left(\dfrac{\Delta d}{d_0}\right)^2}{\left|\dfrac{\Delta d}{d_0}\right|} \times 100\% = \left|\frac{\Delta d}{d_0}\right| \times 100\%$$

课件原文的说明：由于非线性太大，仅适用于微位移测量；随后提出思考题"有什么办法减小非线性？"（解决途径为采用差动结构），并给出结论句"减小 $d_0$，灵敏度 $K$ 提高，但非线性误差增大"（课件该句文字提取残缺，仅可辨"$d_0$，灵敏度 $K$，但非线性误差"，此处按上下文与课程知识复原）。

**理解**：非线性误差的来源是电容表达式的高次项。相对非线性误差取二次项与一次项之比，其结果为 $\Delta d/d_0$ 的一次方：极距相对变化量与相对非线性误差在数值上相等（$\Delta d/d_0 = 0.1$ 时非线性误差约为 10%）。由 $K \approx C_0/d_0$ 与 $\delta \approx \Delta d/d_0$ 可见，减小 $d_0$ 使灵敏度提高，但同时也使同一位移对应的 $\Delta d/d_0$ 增大，非线性误差随之增大；两个指标由同一结构参数 $d_0$ 决定，方向相反。

**作用**：量化单电容变极距传感器的非线性程度，说明引入差动结构的必要性；前置知识点为灵敏度与级数展开；后置知识点为差动结构的误差分析。

#### 1.1 变极距型电容传感器：用差动结构减少非线性

**定义**：差动平板式电容传感器由上下两片定极板与中间一片动极板构成两个电容器 $C_1$、$C_2$。当动极板向上移动 $\Delta d$ 时，电容器 $C_1$ 的间隙 $d_1$ 变为 $d_0 - \Delta d$，电容器 $C_2$ 的间隙 $d_2$ 变为 $d_0 + \Delta d$，则

$$C_1 = \frac{C_0}{1 - \dfrac{\Delta d}{d_0}}\ (\text{增大}), \qquad C_2 = \frac{C_0}{1 + \dfrac{\Delta d}{d_0}}\ (\text{减小})$$

在 $\Delta d/d_0 \ll 1$ 时按级数展开得

$$C_1 = C_0\left[1 + \frac{\Delta d}{d_0} + \left(\frac{\Delta d}{d_0}\right)^2 + \left(\frac{\Delta d}{d_0}\right)^3 + \cdots\right]$$

$$C_2 = C_0\left[1 - \frac{\Delta d}{d_0} + \left(\frac{\Delta d}{d_0}\right)^2 - \left(\frac{\Delta d}{d_0}\right)^3 + \cdots\right]$$

二者的电容差值为

$$\Delta C = C_1 - C_2 = 2C_0\left[\frac{\Delta d}{d_0} + \left(\frac{\Delta d}{d_0}\right)^3 + \left(\frac{\Delta d}{d_0}\right)^5 + \cdots\right]$$

课件结论：偶次项消除，非线性得到改善。

**理解**：两个电容的极距变化方向相反，其归一化表达式分别为 $1/(1-x)$ 与 $1/(1+x)$（$x = \Delta d/d_0$）。两个级数展开式中偶次项符号相同、奇次项符号相反，相减后偶次项抵消、奇次项加倍，因此差值表达式中只保留奇次项。差值的第一项 $2C_0\Delta d/d_0$ 与被测量成正比，是差动结构的有效输出项；其余奇次项（三次项起始）构成残余非线性。

**作用**：给出差动结构的电容表达式与差值表达式，是"通过差动结构减少非线性误差"一节定量结论（灵敏度与非线性误差）以及后续球—平面型差动压力传感器、二极管双T电桥（要求差动电容）的结构基础。

#### 通过差动结构减少非线性误差

**定义**：由差值表达式 $\Delta C = 2C_0\left[\dfrac{\Delta d}{d_0} + \left(\dfrac{\Delta d}{d_0}\right)^3 + \cdots\right]$ 可得电容值相对变化量

$$\frac{\Delta C}{C_0} = 2\frac{\Delta d}{d_0}\left[1 + \left(\frac{\Delta d}{d_0}\right)^2 + \cdots\right]$$

略去高次项，则 $\Delta C/C_0$ 与 $\Delta d/d_0$ 近似成为如下的线性关系：

$$\frac{\Delta C}{C_0} \approx 2\frac{\Delta d}{d_0}$$

只考虑线性项和三次项，则差动电容式传感器的相对非线性误差 $\delta$ 近似为

$$\delta = \frac{2\left|\left(\dfrac{\Delta d}{d_0}\right)^3\right|}{2\left|\dfrac{\Delta d}{d_0}\right|} \times 100\% = \left(\frac{\Delta d}{d_0}\right)^2 \times 100\%$$

课件归纳的两条结论：

- 灵敏度增加 1 倍：差动结构 $k = \dfrac{\Delta C}{\Delta d} \approx \dfrac{2C_0}{d_0}$，单电容 $k = \dfrac{\Delta C}{\Delta d} \approx \dfrac{C_0}{d_0}$；
- 线性度得到改善：单电容 $\delta = \dfrac{\Delta d}{d_0} \times 100\%$，差动结构 $\delta = \left(\dfrac{\Delta d}{d_0}\right)^2 \times 100\%$。

符号：$C_0$——单侧初始电容；$\Delta C$——两电容之差；$\Delta d$——动极板位移（极距变化量）；$d_0$——初始极距；$k$——灵敏度。

**理解**：差动结构产生三个直接结果。其一，有效输出项由 $C_0\Delta d/d_0$ 变为 $2C_0\Delta d/d_0$，灵敏度增大一倍。其二，残余非线性由一次项 $\Delta d/d_0$ 降为三次项与一次项之比 $\left(\Delta d/d_0\right)^2$，数值上变为原来的平方（$\Delta d/d_0 = 0.1$ 时，单电容非线性误差约 10%，差动结构约 1%）。其三，$\Delta C$ 与 $\Delta d$ 的关系在工作范围内接近线性，即线性度改善。

**作用**：差动结构分析的结论，给出灵敏度与非线性误差的定量对比，是电容式传感器结构设计（选择单电容或差动结构）的直接依据；前置知识点为差动结构的电容表达式，后置知识点为其工程实现（球—平面型差动压力传感器）与配套测量电路（要求差动电容的双T电桥等）。

#### 实例：球—平面型差动电容压力传感器

**定义**：以中心膜片为动电极、以球面电极为定电极构成的差动电容式压力传感器（差动电容传感器的工程实例）。课件给出的特点：温度稳定性好、耐腐蚀、抗震性好，可用于工业过程的各种压力测量。典型产品：美国 Rosemount 公司 1151 型压力变送器（Transmitter）。课件在结构图旁给出以比例系数 $K$ 表示的电容与压力关系式（该式为图形公式，文本提取残缺，可辨符号为 $K$、$C$、$P$，其后的等效电路部分文字标注"线性关系"）。

符号：$P_H$——高压侧压力；$P_L$——低压侧压力；$d_0$——膜片平直时与电极的初始间隙；$h_{max}$——膜片最大挠度；$C_0$——膜片平直状态两侧电容；$C_L$——膜片上凸后上部电容；$C_H$——膜片上凸后下部电容；$C_A$——膜片当前位置与平直位置之间的电容。

工况分析（课件原文）：

- ① 压力 $P_H = P_L$ 时，中心膜片处于平直状态，膜片两侧电容均为 $C_0$；
- ② $P_H > P_L$ 时，中心膜片上凸，上部电容为 $C_L$，下部电容为 $C_H$；
- ③ $C_H$ 相当于当前膜片位置与平直位置间的电容 $C_A$ 和 $C_0$ 的串联；而 $C_0$ 又可以看成是膜片上部电容 $C_L$ 与 $C_A$ 的串联。

课件将此归纳为"差动电容的另一种推导方法：电容串并联分析法"，即按串联关系写出

$$C_H = \frac{C_A C_0}{C_A + C_0}, \qquad C_0 = \frac{C_L C_A}{C_L + C_A}$$

线性化设计结论（课件原文）：针对球—平面型电容器，可用面积分法计算得到 $C_0/C_A$ 与压力差 $(P_H - P_L)$ 的关系（教材 P61），再通过电容测量电路（教材 P53），将其转换为电流输出；经过传感器结构和测量电路二者结合，将变极距型传感器设计为原理上线性的传感器系统。

**理解**：该传感器属于变极距型：被测量（压差）引起膜片挠度变化，即极距变化；单侧电容与挠度之间同样存在非线性。其线性化分两层实现：结构层采用差动布置（膜片两侧间隙一增一减，两侧电容一增一减）；电路层把两侧电容经测量电路转换为电流输出，使最终输出与压差成线性关系。电容串并联分析法把膜片上凸后的电容分解为基本电容的串联组合：$C_H$ 是"膜片当前位置至平直位置"段与平直位置段两部分电容的串联，$C_0$ 是"平直位置"段与"上凸位置"段两部分电容的串联，用串联关系定量描述膜片位置与各电容之间的联系。

**作用**：差动变极距原理的工程应用实例，同时是"电容串并联分析法"的典型应用场合；前置知识点为差动结构减小非线性；后置关联为电容测量电路（把电容信号转换为电流输出）。

#### 1.2 变面积型电容式传感器：测量平移距离

**定义**：被测量通过动极板移动引起两极板有效覆盖面积 $A$（原课件记作 $S$）改变、从而得到电容量变化的电容传感器，极距与介电常数保持不变。设极板沿长度方向初始覆盖长度为 $a$、宽度为 $b$，初始电容为

$$C_0 = \frac{\varepsilon_0 \varepsilon_r \, b a}{d}$$

当动极板相对于定极板沿长度方向平移 $\Delta x$ 时，则电容变化量为

$$\Delta C = -\frac{\varepsilon_0 \varepsilon_r \, b}{d}\,\Delta x$$

电容相对变化量为

$$\frac{\Delta C}{C_0} = -\frac{\Delta x}{a}$$

课件原文：其电容量 $C$ 与水平位移 $\Delta x$ 呈线性关系；$\varepsilon_0$ 为真空介电常数，$\varepsilon_r$ 为介质相对介电常数。

**理解**：与变极距型不同，变面积型的覆盖面积位于电容表达式的分子，面积变化量与电容变化量直接成正比，不需要级数近似即可得到线性关系，因此不存在原理性非线性。构成要素为动极板、定极板与平移机构；被测量（平移距离）改变覆盖长度。负号表示覆盖面积减小时电容减小（动极板移出使有效覆盖面积减小）。

**作用**：三类电容传感器中的第二种（含平移距离与角位移两种测量方式）；与变极距型并列，用于位移测量；也是二极管双T电桥等电压激励测量电路的适用对象（具有线性特性）。

#### 1.2 变面积型电容式传感器：测量角位移

**定义**：以角位移为被测量的变面积型电容传感器，动极板（半圆形）相对定极板转过角位移 $\theta$。课件给出的推导：$\theta = 0$ 时，$C = C_0$；$\theta \neq 0$ 时，板级间的相对面积为

$$S_\theta = S\left(1 - \frac{\theta}{\theta_0}\right)$$

故

$$C = \frac{\varepsilon S_\theta}{d} = \frac{\varepsilon S\left(1 - \dfrac{\theta}{\theta_0}\right)}{d} = C_0\left(1 - \frac{\theta}{\theta_0}\right) = C_0 - \Delta C$$

课件结论：$C_1$（$\Delta C$）与 $\theta$（角位移）成线性关系。课件配图为平板电容式角位移传感器结构图（动极板、定极板）。

符号：$\theta$——角位移；$\theta_0$——极板满覆盖对应的转角（半圆形极板时为 $\pi$，此时 $\dfrac{\Delta C}{C_0} = \dfrac{\theta}{\pi}$）；$S$——极板总面积；$S_\theta$——转过 $\theta$ 后的有效覆盖面积；$C_0$——初始电容；$\Delta C$——电容变化量。（课件该组公式为图形公式，提取文本中分母符号残缺，此处按课件给出的"线性关系"结论与量纲关系复原。）

**理解**：角位移的测量机制是把角位移转换为覆盖面积的变化：转过 $\theta$ 后有效覆盖面积按 $1 - \theta/\theta_0$ 的比例减小，电容同步线性减小，因此 $\Delta C$ 与 $\theta$ 成正比。与平移测量相比，两者几何参数不同（角度对长度），但转换原理相同：都是面积位于分子、无高次项的直接线性关系。

**作用**：变面积型传感器的第二种测量方式（测量角位移），与测量平移距离并列；共同说明变面积型传感器的线性特性。

#### 1.3 变介电常数型电容传感器：测量液位

**定义**：覆盖面积与极距均不变、以极板间介质的介电常数 $\varepsilon$ 变化为被测量的电容传感器，用于测量物性参数、物位（Liquid Level）等。测量液位采用同心圆筒形结构：内筒外半径为 $r$，外筒内半径为 $R$，筒长为 $L$，液位高度为 $L_x$。课件说明：储罐材料为导体、溶液为绝缘体时，可以把罐体作为电极。课件同时提出思考题：其他情况下如何测量？比如液体为导体。液位测量示意图上另标注 $D$、$d$、$H$、$h$ 等尺寸符号。

分析采用串并联分析法——并联：同心圆筒形电容器的总电容 $C$ 是空气电容和液体电容的并联（液面以上为空气介质段、液面以下为液体介质段，两段共用电极，等效为并联）。

空载（全部为空气）电容：

$$C_0 = \frac{2\pi\varepsilon_0 L}{\ln(R/r)}$$

带负载电容：

$$C = C_0 + \frac{2\pi(\varepsilon - \varepsilon_0)L_x}{\ln(R/r)} = C_0\left[1 + (\varepsilon_r - 1)\frac{L_x}{L}\right]$$

课件结论：液位 $L_x$ 与输出电容成正比。符号：$\varepsilon_0$——真空中的介电常数；$\varepsilon_r$——板级间介质的相对介电常数；$\varepsilon$——板级间介质的介电常数；$r$——内筒外半径；$R$——外筒内半径；$L$——筒长；$L_x$——液位高度；$C_0$——空载电容；$C$——带负载电容。

**理解**：总电容由两段构成：空气段电容与液体段电容；两段极板相同、在电路上是并联关系，电容直接相加。带载表达式中 $L_x$ 只以一次项出现，故输出电容随液位线性变化：$L_x = 0$ 时 $C = C_0$，$L_x = L$ 时 $C = \varepsilon_r C_0$（液体全部取代空气段）。罐体直接作外电极的前提是罐体为导体且液体绝缘；液体为导体时液面本身成为等电位面，电极配置需另行处理（课件留作思考题）。

**作用**：变介电常数型的典型应用（物位测量）；"电容串并联分析法"的又一应用场合；与水分测量并列。

#### 1.3 变介电常数型电容传感器：测量水份

**定义**：电容式水份计（水分计）利用水与空气介电常数的差异测量被测物的水分含量，功能是测量被测物的水分含量，例如测量稻谷中的水分。测量原理（课件原文）：

- 水的相对介电常数是空气的 82 倍，故以水为介质的电容器对水的变化非常敏感；
- 测量时，总电容等效于三个电容并联：空气、水份和固体介质电容。

课件给出总电容表达式与参数（该式为嵌入公式，文本提取残缺，可辨因子与符号为 $\dfrac{2\pi\varepsilon_0 L}{\ln(R/r)}$、$k = L_x/L$、$\varepsilon_r$、$\varepsilon_{rH}$、$\omega_H$）：

$$C = C_1 + C_2 + C_3\ (\text{空气电容} + \text{水份电容} + \text{固体介质电容})$$

符号：$\varepsilon_r$——被测物自身介电常数（相对）；$\varepsilon_{rH}$——水的相对介电常数；$\omega_H$——物体的含水量；$k = L_x/L$——含水段长度与筒长之比；$R$、$r$、$L$——同心圆筒电极的外筒内半径、内筒外半径与筒长。课件结论：当其它量不变时，电容的变化正比于含水量 $\omega_H$ 的大小。（该式具体代数形式无法从提取文本完全确认，按课件给出的符号与"三电容并联"结构列出。）

**理解**：水分测量的实质是变介电常数型测量：物料含水量的变化引起物料等效介电常数变化（水的相对介电常数远高于空气与固体介质），进而引起总电容变化。总电容是空气、水分、固体介质三部分电容的并联和，含水量上升使水分部分的电容增大。课件以"当其它量不变时"为条件给出正比关系，即该正比关系成立的前提是密度、温度、物料成分等其它因素保持不变。

**作用**：变介电常数型传感器在农业检测中的应用实例；说明该类传感器的测量条件限制；与液位测量并列。

### 二、测量电路

#### 2 测量电路——挑战：杂散电容

**定义**：杂散电容（Stray Capacitance）是电路中导线之间、引线之间以及电子器件输入端的分布电容。课件列出的挑战（原文数据）：

- 电极引线之间以及导线间有杂散电容，其数值约 100 pF/m；
- 用于选择不同测量电极的电子开关其输入电容值约 8 pF；
- 在普通线路板上两段间隔 1 mm、长 1 cm 的导线之间的分布电容约 1 pF；
- 测量电容小：最多数十 pF，远小于影响电容测量的杂散电容值，抗杂散电容的能力是小电容电路必须具备的重要性能。

课件结论：电容传感器的测量电路不容易设计；电容传感器的测量电路非常丰富。

| 来源 | 数值 |
| --- | --- |
| 电极引线之间以及导线间杂散电容 | 约 100 pF/m |
| 电子开关输入电容 | 约 8 pF |
| 普通线路板上间隔 1 mm、长 1 cm 的两段导线间分布电容 | 约 1 pF |
| 被测量电容 | 最多数十 pF |

**理解**：杂散电容与被测电容在电路上处于并联位置，直接叠加到测量结果上。被测电容最多数十 pF，而引线杂散电容达 100 pF/m，在量级上超过被测信号，且随引线长度、布线方式、开关切换而变化，无法通过一次性标定消除。因此测量电路必须采取措施抑制或消除杂散电容的影响，这是各种电容测量电路（运算法、二极管双T电桥、调频法）以及分布电容消除技术（驱动电缆技术、电荷转移法）被提出的直接原因。

**作用**：测量电路部分的总起，给出电路设计的外部条件与性能指标；后置知识点为运算法、二极管双T电桥、调频测量电路，以及杂散电容的影响及其解决思路。

#### 3 测量电路——1）运算法

**定义**：用反相比例放大器构成的电容测量电路（运算法）。电路构成：增益为 $-K$ 的反相放大器，电容 $C_x$ 为传感器电容、$C_0$ 为固定电容，输入电压 $\dot U_i$，输出电压 $\dot U_0$（课件电路图标注 $-K$、$C_x$、$C_0$、$U_0$、$U_i$、$a$）。课件给出的推导：

$$\dot Z_x = \frac{1}{\text{j}\omega C_x}, \qquad \dot Z_0 = \frac{1}{\text{j}\omega C_0}$$

反相比例放大器：

$$\dot U_0 = -\frac{\dot Z_0}{\dot Z_x}\dot U_i = -\frac{C_0}{C_x}\dot U_i$$

对于变极距传感器，$C_x = \dfrac{\varepsilon A}{d}$，代入得

$$\dot U_0 = -\frac{C_0 \, d}{\varepsilon A}\dot U_i$$

课件在该结论旁标注："对于变极距传感器：幅值与被测量（位移）成正比? !"（未展开证明）。符号：$\dot U_i$、$\dot U_0$——输入、输出交流电压相量；$\dot Z_x$——传感器电容的复阻抗；$\dot Z_0$——固定电容的复阻抗；$\omega$——激励角频率；$C_x$——传感器电容；$C_0$——固定电容；$\varepsilon$——介电常数；$A$——极板面积；$d$——极距。

课件给出的输出信号特征（原文）：

- 由高频交流正弦波供电；
- 输出信号的相位由激励电源和待测信号两种因素的相位所决定；
- 其频率与电源频率相同；
- 大小不能反映方向。

**理解**：放大器工作于反相比例状态，$\dot U_0/\dot U_i = -\dot Z_0/\dot Z_x$ 的直接含义是输出电压幅值由两电容之比决定。对变极距传感器，$C_x$ 与极距 $d$ 成反比，$C_0/C_x = C_0 d/(\varepsilon A)$ 与 $d$ 成正比，即一次反比关系在电压表达式中被消去，输出幅值与极距成正比，从原理上避开了变极距型的非线性（课件仅以"? !"标注该结论，未给出证明）。由于电路使用交流激励，输出为同频交流量：幅值只给出位移大小，不能直接区分位移方向，方向信息包含在输出相位之中；相位的取值同时取决于激励电源与待测信号两方面的相位。

**作用**：变极距型传感器线性化测量的电路手段，与充放电法（二极管双T电桥）、调频法并列，同属电容测量电路的三大方法；前置知识点为杂散电容挑战与变极距型特性。

#### 3.1 测量电路——2）二极管双T电桥：电路结构与工作原理

**定义**：二极管双T电桥（Diode Dual-T Bridge）是以电容充放电特性为基础的电容测量电路，由美国麻省理工学院教授 K. S. Lion 于 1963 年发明的二极管交流双T型网络（课件注明参考习题集例 4-7）。电路由两个二极管 $D_1$、$D_2$，两个等值电阻 $R_1 = R_2 = R$，两个电容 $C_1$、$C_0$（其一为电容式传感器的电容，另一为参考电容）以及负载电阻 $R_L$ 组成对称的"双T"形网络，由方波电源 $E$ 激励（电源幅值 $U_E$、周期 $T$）。电路具体连接关系见课件电路图。

课件给出的电路元件与条件（原文）：

- $E$ 为电压信号，可为正弦波或方波；
- $C_1$、$C_2$ 为差动电容传感器的两个电容，或者一个为固定电容、另一个为电容传感器的电容；
- $R_L$ 为负载电阻，$U_L$ 为输出电压；
- 设输入为占空比（Duty Cycle）50% 的方波，周期为 $T$，且 $R_1 = R_2 = R$。

电路的输出为负载电阻 $R_L$ 两端电压 $U_L$ 的直流分量（平均值）；负载电压瞬时值为 $U_L = R_L \times i_f$，其中 $i_f$ 为流经 $R_L$ 的负载电流。

课件归纳的电路原理：

- ① 二极管控制放电回路的路由，使之在正、负半周分别流经电容 $C_0$ 和 $C_1$；
- ② 电容值不同，放电时间常数不同，放电电流不同；
- ③ 负载电阻两端的电压平均值和一个周期内电容放电时间常数有关。

正半周工作过程（电源 $E$ 的正半周：$D_1$ 导通、$D_2$ 截止）：

- (1) 上升沿时刻：$C_1$ 立即充电至电源电压，等于 $+U$；$C_0$ 的初始电压为 $-U$（可由上一负半周条件得到）；因 $R_1 = R_2$ 且 $U_A = +U$、$U_B = -U$，故 $U_L = 0$。其中 $U_A$ 为 A 点即 $C_1$ 上端电压，$U_B$ 为 B 点即 $C_0$ 上端电压。
- (2) 其后时间内：$C_1$ 电压（A 点）不变，恒等于 $+U$（作为下一个负半周的初始条件）；电源 $E$ 通过 $R_1$、$R_2$ 和 $R_L$ 向 $C_0$ 充电，$C_0$ 初始电压为 $-U$；$C_0$ 电压 $U_B$ 呈指数下降，充电电流为 $i_0$（红线）和 $i_f$（紫线），其中 $i_0$ 为 $C_0$ 的充电电流，$i_f$ 为负载电流，从 0 指数上升，形成 $i_f$ 曲线的上半周。

负半周工作过程（电源 $E$ 的负半周：$D_1$ 截止、$D_2$ 导通）：

- (1) 起始时刻：$C_0$ 立即充电至电源电压，等于 $-U$；$C_1$ 的初始电压为 $+U$（由正半周过程获得）；因 $R_1 = R_2$ 且 $U_A = +U$、$U_B = -U$，故 $U_L = 0$。
- (2) 其后时间内：$C_0$ 电压（$U_B$）不变，恒等于 $-U$；电源 $E$ 通过 $R_2$、$R_1$ 和 $R_L$ 放电，$C_1$ 初始电压为 $+U$；$C_1$ 电压 $U_A$ 呈指数下降；$i_f$ 从 0 指数下降，形成 $i_f$ 曲线的下半周。

输出电压 $U_L$ 的直流分量（整个 $T$ 周期内）：

- 当传感器空载时：$C_1 = C_0$，那么在电源正负半周流经 $R_L$ 电阻的电流是波形相同的，而方向相反的，所以流经 $R_L$ 上的电流平均值为零；
- 当传感器工作时，$C_1 \neq C_0$，流经 $R_L$ 上的电流平均值不为零；
- 通过简单的滤波电路可滤除 $U_L = R_L \times i_f$ 的交流成分，获得其直流分量，该直流分量约等于 $k(C_1 - C_0)$（$k$ 为与电路参数有关的比例系数；课件该处原文提取为 $k(C_1 \neq C_0)$，按上下文与下一节定量结果应为 $k(C_1 - C_0)$）。

**理解**：电路构成要素及其分工：$D_1$、$D_2$ 是导通路径控制元件，在方波电源的正半周 $D_1$ 导通、$D_2$ 截止，负半周 $D_2$ 导通、$D_1$ 截止；$C_1$、$C_0$ 是储能电容，充放电电流的大小与衰减快慢由各自的电容值决定；$R_1 = R_2$ 保证电路对称；$R_L$ 把充放电电流转换为输出电压 $U_L$。正、负半周的结构对称：每个半周只有一个二极管导通，被导通支路的电容立即充电至电源电压，另一电容按指数规律放电，$i_f$ 分别形成上半周与下半周波形。课件规定输入为占空比 50% 的方波，是为了保证正、负半周时间相等、电路工作对称；"立即充电"的成立条件是充电时间常数远小于半周期，使电容电压在各自半周内快速达到电源电压。输出直流分量与电容差的联系来自两个半周的平均电流分别由 $C_1$、$C_0$ 决定，两平均值之差反映电容差；$C_1 = C_0$ 时两半周波形相同而方向相反，平均值相消为零。

**作用**：差动电容传感器的测量电路之一（充放电电路型），与运算法并列；前置知识点为差动结构（要求两电容）与一阶 RC 电路瞬态分析；后置知识点为本电路的数值计算与输出电压表达式。

#### 3.1 测量电路——2）二极管双T电桥：数值计算与输出直流分量

**定义**：双T电桥的定量计算，设 $R_1 = R_2 = R$。课件给出的分段条件：$T/2 < t < T$ 即电源处于负半周时，此时 $D_2$ 导通、$D_1$ 截止，$C_1$ 放电，$U_A$ 电压从 $+U_E$ 呈指数下降，而 $U_B = -U_E$（电路左侧部分为等效电路）；$0 < t < T/2$ 即电源处于正半周时，情况对称。

负半周（$T/2 < t < T$，电源处于负半周，$R_1 = R_2 = R$）$C_1$ 放电电流 $i_1$ 及其直流分量 $I_1$：

$$i_1 = \frac{U_E + \frac{R_L}{R + R_L}U_E}{R + (R \parallel R_L)}\, e^{-\frac{t}{(R + R \parallel R_L)C_1}}, \qquad I_1 = \frac{1}{T}\int_0^T i_1\,dt$$

正半周（$0 < t < T/2$，电源处于正半周，$R_1 = R_2 = R$）对 $C_0$ 支路同理有（以 $C_0$ 替换 $C_1$）：

$$i_2 = \frac{U_E + \frac{R_L}{R + R_L}U_E}{R + (R \parallel R_L)}\, e^{-\frac{t}{(R + R \parallel R_L)C_0}}, \qquad I_2 = \frac{1}{T}\int_0^T i_2\,dt$$

负载输出电压（直流分量）：

$$U_L = \frac{RR_L}{R + R_L}(I_1 - I_2) = \frac{RR_L(R + 2R_L)}{(R + R_L)^2 T}U_E\left(C_1 - C_0 - C_1 e^{-k_1} + C_0 e^{-k_0}\right)$$

式中系数 $k_0$、$k_1$ 定义为

$$k_0 = \frac{(R + R_L)T}{2R_L(R + 2R_L)C_0}, \qquad k_1 = \frac{(R + R_L)T}{2R_L(R + 2R_L)C_1}$$

当 $k_0$、$k_1 > 5$ 时，其非线性误差 < 1%（$k > 5$ 时 $e^{-k} < 0.007$，输出表达式中的 $e^{-k_0}$、$e^{-k_1}$ 修正项可忽略），输出直流分量近似为

$$U_L \approx \frac{RR_L(R + 2R_L)}{(R + R_L)^2 T}U_E(C_1 - C_0)$$

符号：$U_E$——电源幅值；$T$——电源周期；$t$——放电时间；$R$——桥路电阻（$R_1 = R_2 = R$）；$R_L$——负载电阻；$C_1$、$C_0$——两个电容；$i_1$、$i_2$——两电容支路的放电电流；$I_1$、$I_2$——两电流的直流分量；$U_L$——负载输出电压（直流分量）；$k_0$、$k_1$——无量纲系数；$R \parallel R_L = \dfrac{RR_L}{R + R_L}$——$R$ 与 $R_L$ 的并联电阻值。

**理解**：数值计算的路线是半周期分段分析。第一步按电源极性把周期分为正、负半周；第二步在每个半周内判断二极管导通状态，被导通支路的电容立即充电到电源电压（近似瞬间完成），另一电容通过电阻网络按一阶 RC 规律放电，其电流为指数衰减函数（$i_1$、$i_2$）；第三步把指数电流在一个周期内积分并取平均，得到直流分量 $I_1$、$I_2$；第四步取两直流分量之差，乘以系数 $\dfrac{RR_L}{R + R_L}$ 得到负载电压 $U_L$。输出表达式中的 $-C_1 e^{-k_1} + C_0 e^{-k_0}$ 两项是误差项（非线性来源），$k_0$、$k_1$ 越大这两项越小；$k_0$、$k_1 > 5$ 时两项均小于 0.007 倍，非线性误差小于 1%，输出简化为与电容差 $(C_1 - C_0)$ 成正比，与前一节的定性结论一致。

**作用**：给出双T电桥的定量输出公式与线性化条件（$k_0$、$k_1 > 5$），是该类电路参数设计（选择 $R$、$R_L$、周期 $T$ 及电源频率）的定量依据；前置知识点为电桥工作原理与一阶 RC 电路瞬态分析；后置知识点为电路参数设计与误差分析。与电路工作原理构成同一定性、定量两部分。

#### 3.1 测量电路——2）二极管双T电桥：电路原理小结与特点

**定义**：课件对本电路原理的三点小结（原文）：① 二极管控制放电回路的路由，使之在正负半周分别流经电容 $C_0$ 和 $C_1$；② 电容值不同，放电时间常数不同，放电电流不同；③ 负载电阻两端的电压平均值和一个周期内电容放电时间常数有关。

课件给出的电路特点（原文）：

- 该线路非常简单，不需要附加相敏解调器，就能获得高电平的直流输出，而且灵敏度较高；
- 二极管以及二个电阻都可放在探头内，缩短电容引线，减小分布电容的影响；
- 电源的频率与幅值的稳定性直接影响精度，对电源要求较高。

**理解**：三点小结分别说明路由控制、时间常数与输出三者的因果链：二极管决定每个半周由哪个电容参与放电，电容值决定放电时间常数，时间常数决定该半周电流平均值，两半周平均值的差决定输出。特点的前两条是优点：无需相敏解调器即可得到高电平直流输出，把二极管与电阻置于探头内可缩短电容引线、减小分布电容（针对测量电路面临的杂散电容挑战）；第三条是限制：输出表达式中的 $U_E$、$T$ 直接进入结果，电源幅值与频率的漂移会直接改变输出，故对电源稳定性要求较高。

**作用**：本电路的结构性结论，说明其优缺点与适用条件；前置知识点为双T电桥工作原理与数值计算。

#### 3.1 测量电路——2）二极管双T电桥：输出电压与适用性

**定义**：课件以"双T电桥输出电压为："引出结论（该处输出电压公式在文本提取中残缺，按前一节结果为 $U_L \approx \dfrac{RR_L(R + 2R_L)}{(R + R_L)^2 T}U_E(C_1 - C_0)$），并给出三点适用性结论：

- ① 线路为电压激励，适用于具有线性特性的单端或差动电容。例如：变面积式电容传感器等；
- ② 不适用于变极距式差动电容式传感器；
- ③ 引入 $1/(C_0 + C_1)$ 后，可用于变极距差动电容式传感器。

课件随后给出该结论的公式依据（该组公式为图形公式，提取残缺，可辨形如 $\varepsilon A/(d_0 \pm \Delta d)$ 的表达式与 $1/(C_0 + C_1)$ 因子）。按此结构补全：对差动变极距电容

$$C_1 = \frac{\varepsilon A}{d_0 - \Delta d}, \qquad C_0 = \frac{\varepsilon A}{d_0 + \Delta d}$$

则

$$\frac{C_1 - C_0}{C_1 + C_0} = \frac{\Delta d}{d_0}$$

即引入 $1/(C_0 + C_1)$ 因子后，输出正比于 $\dfrac{C_1 - C_0}{C_1 + C_0}$，与极距变化量 $\Delta d$ 成正比，变极距型的非线性被消除。（符号：$\varepsilon$——介电常数；$A$——极板面积；$d_0$——初始极距；$\Delta d$——极距变化量；$C_1$、$C_0$——差动两电容。以上为该组公式的复原表述，原式在课件中为图形公式。）

**理解**：为什么变极距差动电容不适用——变极距型电容本身与被测量为非线性关系，其电容差 $(C_1 - C_0)$ 用于该电路时输出不满足线性要求；引入 $1/(C_0 + C_1)$ 因子后输出为 $(C_1 - C_0)/(C_1 + C_0)$ 的形式，对差动变极距结构该比值恰与 $\Delta d/d_0$ 成正比，非线性由此消除。为什么变面积型适用——变面积型电容与被测量本身即为线性关系，电容差直接反映位移。

**作用**：给出双T电桥的适用范围与线性化条件，是"激励源类型决定适用对象"这一结论的直接应用；前置知识点为恒压源激励的适用性结论与差动变极距的电容表达式。

#### 传感器激励源：恒电荷激励

**定义**：恒电荷激励（Constant-Charge Excitation）指激励源保证电容极板上的电荷恒定。由 $Q = CU$ 与 $C = \varepsilon A/d$ 得极板电压与电容参数的关系：

$$U_C = \frac{Q}{C} = \frac{Qd}{\varepsilon A}$$

符号：$U_C$——极板电压；$Q$——极板电荷（恒定）；$C$——电容；$\varepsilon$——介电常数；$A$——极板面积；$d$——极距。

课件结论（原文）：

- $U_C$ 与电容极距 $d$ 有单值线形关系（规范写法为"线性"），与 $\varepsilon$ 和 $A$ 是单值非线性关系；
- 恒电荷激励适用于变极距型电容传感器；
- 恒电荷激励实用困难，常用恒电流激励；
- 恒电荷或恒电流激励，测量电路的输入阻抗应为无穷大，否则形成的并联分路成为电荷泄露回路。

**理解**：$Q$ 恒定时，约束关系 $Q = CU$ 把电容的变化直接转换为电压的变化：$U_C = Qd/(\varepsilon A)$。当被测量只改变极距 $d$（变极距型传感器），$U_C$ 与 $d$ 成正比，输出为线性；当被测量改变 $\varepsilon$ 或 $A$（变介电常数型、变面积型），$U_C$ 与 $\varepsilon$、$A$ 成反比，输出为非线性。因此恒电荷激励只适用于变极距型。输入阻抗须为无穷大的原因：若测量电路输入阻抗有限，该阻抗与电容并联形成分路，电荷经分路泄漏，极板电荷不再恒定，激励条件被破坏。

**作用**：传感器激励源选择的理论依据之一，与恒压源激励并列；前置知识点为三类电容传感器的输出特性；后置知识点为测量电路输入阻抗设计（恒电流激励的实用实现）。

#### 传感器激励源：恒压源激励

**定义**：恒压源激励（Constant-Voltage Excitation）指保持电容器上的交流电压有效值恒定不变。此时输出变量为电流 $I_c$，其大小将随电容 $C_x$ 的变化而变化：

$$I_c = 2\pi f U C_x = \omega U C_x = \omega U\frac{\varepsilon A}{d}$$

符号：$I_c$——输出电流；$f$、$\omega = 2\pi f$——激励频率与角频率；$U$——激励电压有效值（恒定）；$C_x$——传感器电容；$\varepsilon$——介电常数；$A$——极板面积；$d$——极距。

课件结论（原文）：恒电压激励适用于变面积型和变介电常数型电容传感器；对于变极距型传感器，采用恒电压激励时存在理论非线性。

**理解**：$U$ 恒定时 $I_c = \omega U C_x$。对变面积型（$A$ 变化）与变介电常数型（$\varepsilon$ 变化）传感器，$I_c$ 与 $A$、$\varepsilon$ 成正比，输出线性；对变极距型（$d$ 变化）传感器，$I_c$ 与 $d$ 成反比，输出非线性。二极管双T电桥属于电压激励线路，其适用性结论（适用于变面积式等线性特性的电容、不适用于变极距差动电容、引入 $1/(C_0 + C_1)$ 后可用于变极距差动电容）与本知识点结论一致。

**作用**：与恒电荷激励并列的激励源选择依据；前置知识点为电容传感器类型与输出特性；后置知识点为测量电路选型（双T电桥适用性即为本结论的直接应用）。

#### 3.4 测量电路——3）调频测量电路

**定义**：调频测量电路（Frequency Modulation，FM）把电容式传感器作为振荡器谐振回路的一部分，当输入量导致电容量发生变化时，振荡器的振荡频率就发生变化。振荡频率为

$$f = \frac{1}{2\pi\sqrt{LC}}$$

式中 $C$ 为振荡回路的总电容：$C = C_1 + C_2 + C_x$；$C_1$ 为振荡回路固有电容，$C_2$ 为传感器引线分布电容，$C_x = C_0 \pm \Delta C$ 为传感器的电容（$C_0$ 为传感器初始电容，$\Delta C$ 为被测信号引起的电容变化量）。课件给出的完整形式为

$$f = \frac{1}{2\pi\sqrt{L(C_1 + C_2 + C_0 \pm \Delta C)}}$$

当被测信号不为 0 时，$\Delta C \neq 0$，振荡器频率有相应变化，此时频率为

$$f = \frac{1}{2\pi\sqrt{L(C_0 \pm \Delta C)}} \quad(\text{课件此处公式为图形公式，提取残缺})$$

课件对该电路的标注：非线性；较高的灵敏度。

课件给出的特点（原文）：调频电容传感器测量电路具有较高的灵敏度，可以测量高至 0.01 μm 级位移变化量；信号的输出频率易于用数字仪器测量，并与计算机通讯；抗干扰能力强；可以发送、接收，以达到遥测遥控的目的。课件配图为测量电路框图：传感器电容 $C_x$ 与电感 $L$ 构成振荡器，后接限幅放大器、鉴频器（输出 $\Delta f \to \Delta u$）。

符号：$f$——振荡频率；$L$——谐振回路电感；$C$——振荡回路总电容；$C_1$——振荡回路固有电容；$C_2$——传感器引线分布电容；$C_x$——传感器电容；$C_0$——传感器初始电容；$\Delta C$——电容变化量。

**理解**：原理拆解为四个环节：谐振回路的振荡频率由电感 $L$ 与总电容 $C$ 决定；传感器电容 $C_x$ 是总电容 $C$ 的组成部分；被测量改变传感器电容，就改变了总电容，进而改变振荡频率；频率的变化承载被测量的信息。特点的对应关系：灵敏度高、可测 0.01 μm 级位移，是因为频率对电容变化的响应灵敏；输出为频率信号，故便于数字仪器测量与计算机通讯；频率信号抗干扰能力强，且可发送、接收，所以能用于遥测遥控。

**作用**：电容测量三大方法之一（运算法、充放电法、调频法）；前置知识点为 LC 振荡器工作原理；后置知识点为数字频率测量、信号远传与遥测遥控系统。与双T电桥法相比，调频法输出频率信号而非直流电压，适合远传与抗干扰场景。

#### 测量电容的方法总结

**定义**：课件总结的测量电容的三种电路方法（原文）：

- ① 采用运算放大器的运算法：等效为阻抗，产生交流信号；
- ② 利用电容的充放电特性设计的电路：例如双T电桥电路，用电压/电流平均值表示电容大小；
- ③ 调频测量电路：通过谐振电路，频率信号可远传、抗干扰。

**理解**：三种方法的共同点是把电容值的变化转换为可测量的电信号；区别在于转换的中间媒介不同——运算法经阻抗转换产生交流信号，充放电法经充放电电流平均值转换产生直流（平均）信号，调频法经谐振回路转换产生频率信号。三种方法的选择依据是输出信号的形式与传输要求：需要远传、抗干扰时选调频法；需要高电平直流输出、电路简单时选充放电法（双T电桥）；需要线性化变极距型非线性时选运算法。

**作用**：测量电路部分的总结性知识点，统领运算法、双T电桥法（充放电法）、调频法三个并列知识点；其后的集成芯片测量电路与激光焦点测量电路均属于这三种方法的实现或组合。

#### 水份测量电容式传感器的集成芯片测量电路

**定义**：用于水份（分）测量的电容式传感器集成芯片测量电路。课件给出的工作原理（原文）：

- ① $C_{X1}$ 和 $C_{X2}$ 分别连接测量参考端和测量端，利用电容差值进行测量；
- ② 电容 $C_{OSC}$ 确定参考振荡器的频率，之后通过积分器，而积分器的振幅是由电容 $C_{X1}$ 和 $C_{X2}$ 决定的；
- ③ 在此过程两个积分器的相位和周期是相同的，它们的振幅差反映了两个电容的电容变化差；
- ④ 之后利用二级低通滤波器将此差分信号转化为直流电压信号。利用电阻值可以改变滤波器的滤波常数及放大比例。

课件指标：图示电路可以精确测出参考电容的 5%～100% 的变化电容值。此外还有一种叫 CDC（Capacity to Digital Converter，电容-数字转换器）的芯片，可以把电容值转换为数字量，可直接与微机接口。

符号：$C_{X1}$、$C_{X2}$——参考端与测量端的电容；$C_{OSC}$——决定参考振荡器频率的电容。

**理解**：电路构成要素及其关系为：参考振荡器（频率由 $C_{OSC}$ 决定）→ 两个积分器（振幅分别由 $C_{X1}$、$C_{X2}$ 决定，相位与周期相同）→ 二级低通滤波器（把振幅差即差分信号转化为直流电压）→ 输出；电阻用于调节滤波常数与放大比例。信息传递路径为：电容差值 → 积分器振幅差 → 低通滤波 → 直流电压。测量范围数据 5%～100% 说明该电路可测相对变化量较大的电容。CDC 芯片的作用是把电容值直接转换为数字量，便于与微机接口，属于测量结果的数字化环节。

**作用**：集成化电容测量电路的应用实例，展示"振荡—积分—滤波"测量链路；前置知识点为差动电容测量原理、积分器与低通滤波器；后置知识点为数字系统接口（CDC 芯片）。

#### 应用：电容式激光焦点测量传感器及其测量电路

**定义**：用于激光切割的电容式焦点位置（间隙）测量传感器系统。课件给出的应用背景（原文）：激光切割是一种非接触式加工技术，激光头与加工工件表面留有间距；在激光切割过程中，为了保证切割质量，需要使切口处的功率密度最大，这要求切割头的喷嘴与被加工工件表面的间隙恒定；在实际生产加工中，待切割加工的工件表面通常是不平整的（例如热轧钢板表面为曲面），且工件装夹受力形变、加工热形变等因素也会使激光头与工件表面之间的距离发生变化，这些形变无法事先测量，所以使用激光焦点位置测量系统获得实际距离，再通过控制系统调节激光切割头的焦距。

激光切割加工原理（课件原文）：用高功率密度的激光去照射待加工的金属工件表面，工件在激光照射下被迅速地溶化、汽化并形成孔洞；在激光光束与加工工件的相对运动之下，形成对金属材料的切割；被激光烧灼形成的熔融物被辅助气体在拖拽力的作用下从切缝内吹出；从原理上看，激光切割加工属于热切割加工方法中的一种。

传感器系统结构示意图编号标注：1-切割头；2-电容传感器；3-电容电缆；4-前置放大器；5-同轴电缆；6-控制盒；7-直流电源；8-工件；9-接地点。

测量电路存在的问题（课件原文）：

- 测量电路多采用分立元件构成，测量电路庞大而复杂，因此无法将后续的信号处理电路一并集成到传感器端；
- 一般采用的都是传感器和后续信号处理电路分离的方式，被测模拟量从传感器输出要经过较长的导线送到后续的模拟或者数字信号处理电路中；
- 模拟量在这一段传输过程中，又引入了杂散电容的影响，这些杂散电容值可以达到上百 pF，会显著降低传感器灵敏度；并且导线如果不固定，或者固定时的摆放形状发生变化，都将会引起电缆电容发生变化，使得传感器输出值不稳定。

改进电路（课件原文）：该电路由双振荡器（555 定时器）、触发器和温度传感器组成，电路结构简单；基于差动模式可以降低共模噪声的考虑，使用了双振荡器电路和 D 触发器；一路振荡器的电容是基准电容，另一路振荡器的电容是传感器电容；在电路设计中把参考电容的波形从 D 触发器的时钟端引入，把敏感电容的波形从 D 端引入，D 触发器的输出为两个波形的频率差，这样可以减少温度对电路的影响，对电源电压的波动也有抑制作用；由于激光焊接时热量极高，温度变化大，为了对测量值进行温度补偿，在差频电容式测量电路中附加了一个集成温度传感器，该温度传感器的测量值提供给焦点控制电路使用。

**理解**：测量需求来源：工件表面形状（如热轧钢板不是平面而是曲面）、装夹方式造成的受力形变、加工热形变等因素使激光头与工件表面之间的距离发生变化且无法事先测量；在激光切割头沿工件表面做相对运动时，需要实时测量该间隙并据此调节焦距，以获得切口处最大功率密度。工程问题：分立元件测量电路无法与信号处理电路一起集成到传感器端，传感器与信号处理电路分离后，模拟量经长导线传输引入杂散电容（可达上百 pF），显著降低灵敏度；导线不固定或摆放形状变化还会引起电缆电容变化，使输出不稳定。改进电路的三项措施分别对应三个问题：双振荡器与 D 触发器构成差动模式，降低共模噪声；把参考电容波形接时钟端、敏感电容波形接 D 端，输出为两波形频率差，抑制温度影响与电源电压波动；附加集成温度传感器，对高温环境下的测量值进行温度补偿。

**作用**：电容传感器与差频（调频）测量电路在工业非接触检测中的典型应用实例；前置知识点为电容传感器原理、振荡器电路与触发器电路；后置知识点为闭环控制系统（切割头焦距/间隙控制）。其测量电路部分同时说明实际电路中传输导线杂散电容的影响及差动结构的必要性。

#### 3.5 其它测量电路：木工防护装置（手指救星）

**定义**：利用人体电容检测原理实现的电锯（台锯）安全防护装置。课件给出的工作原理与指标（原文）：

- 将一个 500 kHz 的正弦波信号加于电锯刀片，振幅峰值可以在 3～25 伏之间调整；
- 由于刀片是良好的导体，该高频信号能够在整个刀片上保持一致性；
- 由于人体带有电容，当手指和刀刃发生接触时，将产生寄生电容，最大将引起 40% 的信号衰减；
- 实时性指标：在五毫秒内强行制动刀刃，探测+制动。

信号处理（原文）：基于 TI 的 TMS320LF2403A DSP 作为电机控制器，用以探测由于人体电容引起的刀刃上的感应电压的变化；积分器每 6 微秒就对来自刀片的传感信号进行绝对积分计算，积分器的幅值则由 DSP 在每个第 6 微秒末采样，且采样电容会在下一个采样周期前被放空；采用积分器是由于它能够测量刀片信号的幅值，并对噪声扰动有一定的抵抗力。

**理解**：检测过程由四个环节构成。激励环节：500 kHz 正弦波（峰值 3～25 V 可调）施加于导电刀片，因刀片导电，高频信号在整个刀片上保持一致；传感环节：人体接触刀片引入寄生电容，使刀片上的感应电压发生变化（最大衰减 40%）；检测环节：积分器每 6 μs 对传感信号做绝对积分计算，DSP 在每个 6 μs 末采样积分器幅值，采样电容在下一采样周期前放空；执行环节：DSP 判定人体接触后 5 ms 内强行制动刀刃。采用积分器的原因是它能够测量刀片信号的幅值，并对噪声扰动有一定抵抗力。

**作用**：电容传感原理在安全防护领域的应用实例（属课件"3.5、其它测量电路"部分）；前置知识点为电容传感器原理、积分器电路、DSP 采样与控制；后置知识点为电机控制与安全执行机构（制动）。

### 三、温度特性（温度对结构尺寸的影响）

#### 4 温度特性与温度误差

**定义**：当环境温度变化时，传感器各零件的几何形状、尺寸发生变化，从而引起电容量变化，这一性质称为电容式传感器的温度特性。课件给出的电容构成式：

$$C = C_0 + \Delta C_P + \Delta C_t$$

符号：$C_0$——传感器的初始电容值；$\Delta C_P$——在被测信号作用下电容变化量；$\Delta C_t$——由环境温度变化而产生的附加电容增量。

课件结论（原文）：$\Delta C_t$ 决定了传感器温度误差的大小；在设计电容传感器时，正确选择零件的尺寸，可以减少温度造成的测量误差。

**理解**：该知识点区分两类电容变化：被测信号引起的 $\Delta C_P$ 是测量目标，温度引起的附加电容增量 $\Delta C_t$ 是干扰项。温度不直接作用于被测信号，而是通过改变零件尺寸再由尺寸变化改变电容量，因此温度误差属于结构误差。减小温度误差的途径在设计阶段：选择零件尺寸（而非依靠后级电路补偿），从结构参数上使 $\Delta C_t$ 减小。

**作用**：电容式传感器误差分析与误差抑制内容的第一部分（温度特性），为温度补偿设计提供问题定义；前置知识点为变极距型电容基本公式 $C = \varepsilon A/d$；后置知识点为电容式压力传感器的结构尺寸分析与温度补偿条件。

#### 4 电容式压力传感器的结构尺寸与温度误差

**定义**：以电容式压力传感器为例分析温度对结构尺寸的影响（课件结构图标注：工作极片、固定极片、绝缘材料，$P$ 为被测压力）。设初始温度 $t_0$ 时电容间隙为

$$d_0 = L - h_1 - h_2$$

随着温度变化 $\Delta t$ 后，间隙 $d_t$ 为

$$d_t = (1 + \alpha_L \Delta t)L - (1 + \alpha_1 \Delta t)h_1 - (1 + \alpha_2 \Delta t)h_2 = d_0 + (\alpha_L L - \alpha_1 h_1 - \alpha_2 h_2)\Delta t$$

符号：$L$——两极片间的总装配尺寸；$h_1$、$h_2$——两处绝缘材料的厚度；$d_0$——初始温度下的电容间隙；$d_t$——温度变化后的间隙；$\alpha_L$——尺寸 $L$ 对应零件的线膨胀系数（Coefficient of Linear Thermal Expansion）；$\alpha_1$、$\alpha_2$——两绝缘材料的线膨胀系数；$\Delta t$——温度变化量。

**理解**：间隙 $d_0$ 由三个尺寸合成：总尺寸 $L$ 减去两个绝缘厚度 $h_1$、$h_2$。温度变化时各零件按各自线膨胀系数膨胀，且膨胀对间隙的贡献方向不同：$L$ 所在零件伸长使间隙增大（正贡献），绝缘材料 $h_1$、$h_2$ 增厚使间隙减小（负贡献）。间隙的实际变化量 $\Delta d = (\alpha_L L - \alpha_1 h_1 - \alpha_2 h_2)\Delta t$ 是三项代数和的 $\Delta t$ 倍。若正负贡献恰好相等（$\alpha_L L = \alpha_1 h_1 + \alpha_2 h_2$），则 $\Delta d = 0$，间隙不随温度变化，电容也不随温度变化。

**作用**：把"温度影响"定量化为几何计算问题，是温度补偿条件推导的前提；前置知识点为温度特性概念；后置知识点为温度误差表达式与温度补偿设计方法。

#### 4.1 温度补偿的条件与设计方法

**定义**：由于温度变化而引起的电容量相对误差为

$$\delta_t = \frac{\Delta C_t}{C_0} = -\frac{\Delta d}{d_0}$$

要实现温度补偿，应使 $\delta_t = 0$，即要求 $\Delta d = 0$，由此得补偿条件

$$\alpha_L L = \alpha_1 h_1 + \alpha_2 h_2$$

考虑到 $L = d_0 + h_1 + h_2$，代入上式得

$$\alpha_L(d_0 + h_1 + h_2) = \alpha_1 h_1 + \alpha_2 h_2$$

经整理后可得设计方程

$$\alpha_L d_0 = (\alpha_1 - \alpha_L)h_1 + (\alpha_2 - \alpha_L)h_2$$

课件给出的设计方法（原文）：先确定 $d_0$，再根据上式选择合适的 $h_1$ 和 $h_2$，可满足温度补偿要求。

符号：$\delta_t$——电容相对误差；$\Delta C_t$——温度引起的附加电容增量；$C_0$——初始电容；$\Delta d$——温度变化引起的间隙变化量；$d_0$——初始间隙；$\alpha_L$——总装配尺寸 $L$ 对应零件的线膨胀系数；$\alpha_1$、$\alpha_2$——两绝缘材料的线膨胀系数；$h_1$、$h_2$——两绝缘材料厚度。

**理解**：推导分三步。(1) 误差表达式：电容与间隙成反比，间隙增大使电容减小，故间隙相对变化量的负值即电容相对误差（负号由此而来）。(2) 补偿条件：令误差为零，即要求温度引起的间隙变化量 $\Delta d$ 为零，得到 $\alpha_L L = \alpha_1 h_1 + \alpha_2 h_2$。(3) 设计方程：代入 $L = d_0 + h_1 + h_2$ 消去 $L$，得到 $d_0$ 与 $h_1$、$h_2$ 必须满足的关系式。补偿的本质是使各零件的膨胀量相互抵消，而不是抑制膨胀本身。设计流程为：先由量程与灵敏度要求确定 $d_0$，再由上式选择 $h_1$、$h_2$（材料决定 $\alpha_1$、$\alpha_2$，厚度可调）。

**作用**：温度特性分析的结论，给出可操作的设计方法；掌握后可解两类问题——已知结构参数求温度误差，给定零误差要求设计 $h_1$、$h_2$；前置知识点为压力传感器结构尺寸的几何分析；并列知识点为电场边缘效应、寄生电容与分布电容的抑制。

### 四、杂散电容的影响及其解决思路

#### 4.2 电容的电场边缘效应

**定义**：电容的电场边缘效应（Edge Effect / Fringe Effect）指平行板电容器极板边缘的电力线向外凸出、电场分布不均匀的现象。课件给出的三个要点（原文）：

- 原理：相当于并联一个附加电容；
- 危害：灵敏度降低，非线性增加；
- 处理方案：1）$A$ 增加，$d$ 减小：可使边缘效应影响变小；2）加装等位环（保护环）：等位环与上极板保持等电位，等位环一般接导线内屏蔽层。

课件配图为普通平行板电容器（标注极板、极距 $d$、电力线）与带保护环的平行板电容器（标注保护环）的对比。

符号：$A$——极板面积；$d$——极距。

**理解**：该知识点由现象、等效、危害、对策四个要素构成。极板边缘电力线不平行而向外弯曲，使边缘区域储存额外电荷，其效果等同于在理想电容上并联一个附加电容；该附加电容与间隙的关系不满足 $C = \varepsilon A/d$，使输出电容偏离理想值（灵敏度基准改变）且变化规律非线性。对策一从几何上降低边缘区域的占比：面积增大、间隙减小，边缘区域相对于总电场区域的占比减小；对策二从电学上隔离边缘电场：等位环与上极板等电位，二者之间无电位差、无电荷积累，边缘电场的作用转移到等位环上，不进入测量电极。

**作用**：电容传感器非理想效应之一；前置知识点为平行板电容公式；后置知识点为驱动电缆技术（等位环接内屏蔽层的接法与驱动电缆的屏蔽接法相衔接）。

#### 4.2 寄生电容与分布电容

**定义**：课件给出两类干扰电容的定义、特性与解决办法（原文）：

- 寄生电容：电容极板与周围物体（各种元件甚至人体）产生的电容联系。特性：固定或随机发生。解决办法：静电屏蔽——将传感器电容极板放置在金属壳体内，并将壳体与大地相连（接地良好）。
- 分布电容：电缆线之间产生的带有分布特性的电容。特性：数值大（> 100 pF/m）；可变（与电缆位置形状有关）。解决办法：1）驱动电缆技术；2）电荷转移法。

**理解**：两类干扰电容的成因与对策不同。寄生电容的成因是极板与周围任意导体之间存在的电容联系，其数值随周围物体位置变化而固定或随机波动；静电屏蔽用接地的金属壳体切断极板与外部的电场联系，壳体电位固定后，外部电荷变化不再影响极板。分布电容的成因是连接电缆芯线与屏蔽层（或芯线之间）沿长度连续分布的电容，单位长度数值大于 100 pF/m，电缆长度远大于极板间隙，故影响大；且电容值随电缆位置、形状变化，属于可变干扰。两种解决办法的共同思路是使分布电容不参与测量：驱动电缆技术使分布电容两端等电位，电荷转移法使分布电容的充放电电流不流经被测电容。

**作用**：电容传感器干扰抑制内容的总纲；前置知识点为电容概念与电缆结构；后置知识点为驱动电缆技术与电荷转移法两种具体技术。

#### 4.2 驱动电缆技术

**定义**：驱动电缆技术（Driven Cable / Active Shield）是消除电缆分布电容影响的技术（课件配图为驱动电缆原理电路图）。课件给出的内容（原文）：

- 思路：屏蔽层跟踪电容的极板电位，使二者电位保持一致（幅值、相位必需一致）；
- 原理：芯线和内层屏蔽层之间的分布电容由于两端电位相等，表现为既不吸收电荷也不释放电荷，对电容传感器 $C_X$ 没有影响；
- 外屏蔽：单点接地；
- 内屏蔽：1:1 倍放大器连接；
- 要求放大倍数为 1，相移为零，且：输入阻抗无穷大，输入电容为 0，无相移——难满足。

课件同时提出思考题：为什么要单点接地？

**理解**：该技术由电缆结构（芯线、内屏蔽、外屏蔽）、驱动放大器、接地方式三个要素构成。因果链为：芯线与内屏蔽等电位时，两者之间分布电容两端电压恒为零，不存储也不释放电荷，等效于断路；若屏蔽电位不跟随芯线电位，分布电容两端存在电压差，其充放电电流成为附加干扰。外屏蔽单点接地的原因：多点接地时各接地点电位不等，形成地电流环路，屏蔽层电位发生波动，破坏内屏蔽与芯线的等电位关系。该方案的困难在于理想 1:1 放大器（增益 1、零相移、输入阻抗无穷大、输入电容为零）无法完全实现。

**作用**：分布电容解决办法之一（驱动电缆技术）的原理方案；前置知识点为分布电容概念与保护环（等位环）；后置知识点为改进型驱动电缆技术（降低对放大器的要求）。

#### 4.3 驱动电缆技术——改进型

**定义**：改进型驱动电缆技术（课件编号 4.3）用两级放大器实现屏蔽驱动：

- 放大器 2 为驱动电缆，其输入电容为放大器 1 的负载，因而无附加电容与 $C_x$ 并联；
- 只需两放大器的放大倍数满足

$$A_1 \cdot A_2 = 1$$

（推导过程参见教材 P60），即可使屏蔽层电位与芯线电位一致。

符号：$A_1$、$A_2$——放大器 1、放大器 2 的放大倍数；$C_x$——被测电容（传感器电容）。

**理解**：改进之处在放大器 2 的输入接法。放大器 2 的输出驱动电缆屏蔽层，其输入端接放大器 1 的输出端，因此放大器 2 的输入电容成为放大器 1 的负载电容，而不是直接并联在被测电容 $C_x$ 上；$C_x$ 两端不并联附加电容，分布电容不参与测量。两级放大倍数之积为 1 时，放大器 2 的输出（屏蔽层电位）等于放大器 1 的输入（芯线电位），分布电容两端电位相等，表现为不吸收、不释放电荷。改进型把"单个放大器同时满足增益 1、零相移、高输入阻抗、零输入电容"的要求，转化为"两级放大倍数之积为 1"的条件，在工程上较易实现。

**作用**：驱动电缆技术的工程实现方案；前置知识点为驱动电缆原理；并列知识点为电荷转移法（分布电容消除的另一技术）。

#### 4.2 电荷转移法：差分式充放电电容检测电路

**定义**：电荷转移法（Charge Transfer Method）是消除分布电容影响的第二种方法，电路为差分式充放电电容检测电路。电路元件：$S_1$～$S_4$ 为四个开关，$C_x$ 为被测电容，$C_{s1}$、$C_{s2}$ 为分布电容，$C$ 为运放输入电容，$R_f$ 为充放电电阻，$V_c$ 为充电电压，$V_1$、$V_2$ 为两路平均电压，$V_o$ 为差分输出电压。课件要求：输出仅与 $C_{s1}$、$C_{s2}$、$C$ 这 3 个电容无关。

课件给出的工作过程（原文）：

- 第 1 步：$S_1$ 和 $S_4$ 闭合，$S_2$ 和 $S_3$ 断开，$V_c$ 对 $C_x$ 充电，充电电阻 $R_f$；
- 第 2 步：$S_2$ 和 $S_3$ 闭合，$S_1$ 和 $S_4$ 断开，$C_x$ 对地放电，放电电阻也为 $R_f$；
- 不断重复，重复频率为 $f$，充放电电流产生平均电压 $V_1$ 和 $V_2$，其差分电压输出 $V_o = V_1 - V_2$。

由工作过程可得定量关系：每周期转移电荷 $Q = C_x V_c$；平均充放电电流 $I = fQ = fC_x V_c$；平均电压 $V = IR_f = fC_x V_c R_f$，故差分输出与 $C_x$ 成正比：

$$V_o = V_1 - V_2 = fC_x V_c R_f$$

（该式为按电路工作过程与课件给出的关系式 $V_o = V_1 - V_2$ 复原，课件原文未给出显式公式。）

**理解**：该方法的构成要素为开关时序（充电、放电两相）、电阻 $R_f$（电流—电压转换）与差分结构（$V_1 - V_2$）。因果链为：每个周期把电荷 $C_x V_c$ 从电源经 $C_x$ 转移到地；重复频率 $f$ 下等效为平均电流 $fC_x V_c$ 流经 $R_f$，形成与 $C_x$ 成正比的直流平均电压；差分输出抵消两路共有的干扰量。分布电容的充放电电流不经过 $C_x$ 所在支路，因此不进入输出。

**作用**：给出电荷转移法的电路结构与工作过程；前置知识点为分布电容概念；后置知识点为逐项分析杂散电容影响如何被消除。

#### 4.2 电荷转移法中杂散电容影响的消除

**定义**：差分式充放电电容检测电路中杂散电容影响的消除（课件原文）：

- $C_{S1}$：由 $V_c$ 充电，对地放电，其充放电电流不经过 $C_x$，不影响输出 $V_o$；
- $C_{S2}$：放大器虚短，相当于两端均接地，对电路输出无影响；
- $C$：不参与 $C_x$ 的充放电过程，对电路输出无影响（放大器输入电容）。

**理解**：按电流路径逐项说明三个电容为何不进入输出。(1) $C_{S1}$ 的充电电流由电源 $V_c$ 直接提供、放电电流直接流入地，均不经过被测电容支路，故不出现在负载电阻 $R_f$ 上；(2) $C_{S2}$ 两端分别接放大器的两个输入端，因虚短两端电位相等，$C_{S2}$ 上无电压变化，不产生充放电电流；(3) 运放输入电容 $C$ 不位于 $C_x$ 的充放电回路上，不参与电荷转移。因此输出 $V_o$ 只反映 $C_x$ 的充放电电流，与三个杂散电容无关。

**作用**：电荷转移法的误差分析结论，说明"输出与 $C_{s1}$、$C_{s2}$、$C$ 无关"的实现机制；前置知识点为电荷转移电路工作过程与运放虚短概念；并列知识点为驱动电缆技术。

### 五、动态特性（以电容式加速度传感器为例）

#### 差动式电容加速度传感器

**定义**：差动式电容加速度传感器（Capacitive Accelerometer）利用质量块与固定电极间的差动电容测量加速度。结构构成（课件结构图数字标注，图注文字在文本提取中残缺，可辨识为）：1—固定极板；2—绝缘体；3—质量块；4—弹簧；5—输出端；6—壳体；$C_1$、$C_2$ 为两侧差动电容，$d_1$、$d_2$ 为两侧间隙。

工作原理（课件原文）：当传感器壳体随被测对象沿垂直方向作直线加速运动时，质量块在惯性空间中相对静止，两个固定电极将相对于质量块在垂直方向产生大小正比于被测加速度的位移；此位移使两电容的间隙发生变化，一个增加，一个减小，从而使 $C_1$、$C_2$ 产生大小相等、符号相反的增量，此增量正比于被测加速度。

课件给出该传感器的主要特点：频率响应快和量程范围大；大多采用空气或其它气体作阻尼物质（课件标注"（了解）"）。

**理解**：构成要素为壳体（随被测对象运动）、惯性质量块（在惯性空间中相对静止）、两个固定电极与质量块构成的差动电容对 $C_1$、$C_2$。因果链为：加速度使壳体与质量块之间出现相对位移（惯性原理）；相对位移改变两电容的间隙（一增一减）；间隙变化产生大小相等、符号相反的电容增量（差动结构）；电容增量正比于加速度。用气体作阻尼的原因是提供能量耗散以抑制谐振、改善动态特性，且气体阻尼结构简单。

**作用**：第五部分"动态特性"的引入实例，把差动变极距电容原理应用于加速度测量；前置知识点为差动变极距电容结构；后置知识点为测振方式分类与动态特性分析。

#### 测量运动参数的两种方式：相对式与绝对式测振传感器

**定义**：课件给出的测量运动参数的两种方式（原文）：

- ① 相对式测振传感器：用于测量振动体相对其振动参照点的运动（例如机床转轴相对于机床底座的振动）。图(a) 相对测振：可动部分在被测体上，固定部分在参照点上。
- ② 绝对式测振传感器：用于测量振动体相对于大地或惯性空间的运动（例如机床底座的振动、地面的振动）。图(b) 绝对测振：固定部分在被测体上，可动部分做相对运动。

课件结构图标注元件：被测物体、顶杆、可动部分、弹簧、固定部分。

**理解**：两种方式的区别在参照点。相对式测振的参照点是实际物体（如机床底座），传感器可动部分与被测体固连、固定部分与参照点固连，输出为被测体与参照点之间的差值运动；绝对式测振的参照点是大地或惯性空间（无实体参照），固定部分与被测体固连，可动部分（质量块）因惯性保持相对静止，输出为被测体相对惯性空间的运动。绝对式不需要实际参照点，适用于参照点本身振动或无法安装参照点的情况。

**作用**：测振传感器的分类框架；绝对式测振即电容式加速度传感器的原理类型；前置知识点为电容式加速度传感器；后置知识点为惯性测量原理。

#### 惯性式加速度测量原理

**定义**：课件给出的原理要点（原文）：不依赖外部信息，在运动体的内部可以测出物体的加速度；对所测得的加速度，积分一次可得速度 $v$，积分两次得载体在积分时间间隔中的位移，如果再考虑初始条件，就能确定载体在任一时刻的位置与速度：

$$v(t) = \int a\,dt + v_0, \qquad x(t) = \int v\,dt + x_0$$

课件讲稿补充的实例与说明：在运动物体内部能测出物体加速度的仪器叫做加速度计（Accelerometer）；当车厢有加速度时，单摆向后偏离铅垂线，垂直上抛的小球落到抛出点后方；考虑相对运动，加上牵连惯性力 $Q$，可解释为牵连惯性力 $Q$ 向后拉动小球；如能测出单摆偏角 $\theta$，则运动物体加速度是

$$a = g\tan\theta$$

单摆可作加速度计使用但不方便；弹簧质点系统是可行方案：当壳体（安装在载体上）沿仪器敏感轴有加速度时，惯性力作用在惯性质量上使其移动，直至与弹簧恢复力平衡，电位计即有与惯性力成正比的信号输出，因而可测出载体的加速度 $a$。

符号：$a$——加速度；$v$——速度；$x$——位移；$v_0$——初始速度；$x_0$——初始位置；$g$——重力加速度；$\theta$——单摆偏角；$Q$——牵连惯性力。

**理解**：该原理分测量与推算两部分。测量部分：加速度产生的惯性力是运动体内部可观测的物理量，表现为单摆偏角或弹簧变形，故不参照外部物体即可测出加速度；单摆偏角 $\theta$ 与加速度的关系 $a = g\tan\theta$ 由重力分力与惯性力的平衡得出。推算部分：加速度是速度的时间导数、位移的二阶导数，故积分一次得速度、积分两次得位移，积分常数由初始条件确定。车厢内单摆后偏、上抛小球落于抛出点后方，均为惯性力方向与加速度方向相反的直接表现。

**作用**：惯性测量与惯性导航的基本原理，说明加速度计输出如何换算为速度与位置；前置知识点为绝对式测振；后置知识点为绝对位移与相对位移的定量关系。

#### 静基准、绝对位移与相对位移

**定义**：课件由牛顿第二定律建立相对运动与绝对运动的联系。物体（动极板）受到惯性力、阻尼力 $F_c = c\dfrac{dy}{dt}$、弹簧力 $F_k = ky$，运动方程为

$$m\frac{d^2x_0}{dt^2} = -c\frac{dy}{dt} - ky$$

考虑到质量块的绝对位移 $x_0$ 与基座绝对位移 $x$、相对位移 $y$ 的关系 $x_0 = x + y$，方程可写为以相对位移表示的形式

$$m\frac{d^2y}{dt^2} + c\frac{dy}{dt} + ky = -m\frac{d^2x}{dt^2}$$

课件给出的定义：

- 静基准：与大地（或惯性空间）保持相对静止的运动参照点；
- $x$：被测振动体 2 及传感器底座 1 相对该参照点的位移，即绝对位移；
- $y$：质量块 $m$ 相对于传感器底座 1 的位移，称为相对位移；
- $x_0$：质量块 $m$ 相对该参照点的位移，即绝对位移。

三个位移满足

$$x_0 = x + y$$

课件结论（原文）：建立了相对运动和绝对运动的联系；将被测参数，即加速度的大小，变为电容动极板相对位移 $y$ 的转换。

符号：$m$——质量块质量；$c$——阻尼系数；$k$——弹簧刚度；$y$——动极板与定极板之间的相对位移；$x$——基座（被测体）的绝对位移；$x_0$——质量块的绝对位移；$F_c$——阻尼力；$F_k$——弹簧力。（上述运动方程为按课件给出的受力项与位移符号复原，课件原式为图形公式。）

**理解**：底座与被测体固连，其绝对位移为 $x$；质量块不与底座固连，因惯性产生相对位移 $y$，故质量块的绝对位移 $x_0 = x + y$。物理过程为：质量块感受加速度并产生与加速度成比例的惯性力，使弹簧产生与质量块相对位移相等的伸缩变形，弹簧变形又产生与变形量成比例的反作用力；当惯性力与弹簧反作用力相平衡时，质量块相对于基座的位移与加速度成比例，故可通过该位移（即电容动极板位移 $y$）或惯性力来测量加速度。该方程是二阶线性微分方程，其频率特性由固有频率与阻尼比决定。

**作用**：为加速度传感器建立力学模型并定义位移变量，是频率特性分析的变量基础；前置知识点为惯性式加速度测量原理；后置知识点为正弦运动响应与幅频、相频特性。

#### 电容式加速度传感器的频率特性

**定义**：当输入为

$$x = X_m \sin\omega t$$

输出为

$$y = Y_m \sin(\omega t - \varphi)$$

课件给出的幅频特性与相频特性：

$$\frac{Y_m}{X_m} = \frac{\left(\dfrac{\omega}{\omega_0}\right)^2}{\sqrt{\left[1 - \left(\dfrac{\omega}{\omega_0}\right)^2\right]^2 + 4\xi^2\left(\dfrac{\omega}{\omega_0}\right)^2}}$$

$$\tan\varphi = \frac{2\xi\left(\dfrac{\omega}{\omega_0}\right)}{1 - \left(\dfrac{\omega}{\omega_0}\right)^2}$$

$$\omega_0 = \sqrt{\frac{k}{m}}, \qquad \xi = \frac{c}{2\sqrt{km}}$$

课件结论（原文）：当被测刚体作正弦运动时，电容器的动极板亦相对于定极板作正弦运动，其振幅和相位则与传感器的结构参数 $\xi$、$\omega_0$ 有关；动极板质量轻，固有频率非常高。

符号：$x$——基座（被测体）的位移；$X_m$——位移振幅；$y$——质量块相对基座的位移；$Y_m$——相对位移振幅；$\omega$——激励角频率；$\varphi$——相位差；$\omega_0$——固有频率；$\xi$——阻尼比（Damping Ratio）；$k$——弹簧刚度；$m$——质量块质量；$c$——阻尼系数。

**理解**：加速度传感器是二阶振动系统：输入正弦位移（对应正弦加速度）时，质量块相对位移 $y$ 作同频正弦运动，其幅值与相位随激励频率变化。在远低于 $\omega_0$ 的频段，幅频特性的取值趋于 $\left(\omega/\omega_0\right)^2$、相移小，输出真实反映被测加速度；激励频率接近 $\omega_0$ 时幅频特性出现峰值（谐振）；阻尼比 $\xi$ 决定谐振峰值的大小与相频曲线的形状。动极板质量轻使固有频率很高，保证工作频段远离谐振区。

**作用**：加速度传感器动态特性的频域分析，引出固有频率与灵敏度的制约关系；前置知识点为位移变量定义与二阶系统频率特性；后置知识点为固有频率与灵敏度的关系及微弱电容信号的读出。

#### 固有频率与灵敏度的制约关系

**定义**：课件结论（原文）：可以提高固有频率，增大频区，但灵敏度降低。

由弹簧—质量系统的两个关系推出该结论。其一，固有频率

$$\omega_0 = \sqrt{\frac{k}{m}}$$

符号：$k$——弹簧刚度；$m$——质量块质量；$\omega_0$——固有频率。提高 $k$（或减小 $m$）可提高 $\omega_0$，扩大远离谐振区的可用频区。其二，稳态平衡条件 $ma = ky$ 给出

$$y = \frac{ma}{k} = \frac{a}{\omega_0^2}$$

当 $\omega \ll \omega_0$ 时，传感器的振幅将反映被测量的加速度，即由上一节的幅频特性近似得

$$Y_m \approx \frac{\omega^2}{\omega_0^2}X_m = \frac{A_m}{\omega_0^2}$$

其中 $A_m = \omega^2 X_m$ 为加速度振幅。灵敏度

$$S = \frac{Y_m}{A_m} \approx \frac{1}{\omega_0^2}$$

符号：$a$——加速度；$y$——相对位移；$\omega_0$——固有频率；$Y_m$——相对位移振幅；$X_m$——基座位移振幅；$A_m$——加速度振幅；$S$——灵敏度。（灵敏度表达式为按课件结论与幅频特性近似复原，课件原式为图形公式。）

**理解**：两条因果链的公共变量是刚度 $k$：增大 $k$ 同时导致固有频率提高（频区增大）与同一加速度下的位移输出减小（灵敏度降低）。灵敏度与固有频率的平方成反比，$\omega_0$ 提高为原来的 2 倍时灵敏度降为原来的 1/4。因此频区与灵敏度不可同时提高，二者构成加速度传感器的设计权衡。

**作用**：加速度传感器动态特性分析的结论，指出频区与灵敏度之间的工程权衡；前置知识点为频率特性；后置知识点为微弱输出信号的电容读出电路。

#### MEMS 电容传感器与 MS3110 电容读取芯片

**定义**：MEMS 传感器（如微加速度计、微陀螺仪）的输出电容变化量非常微弱，往往只有几或几十 fF（$1\ \mathrm{fF} = 10^{-15}\ \mathrm{F}$），对检测电路的分辨率提出了较高的要求；电容检测电路的设计是 MEMS 传感器设计中的主要问题之一。

MS3110 芯片是美国 Irvine 传感器公司生产的一种通用电容读取芯片，具有超低噪声特点，可以读取低至 $4.0\ \mathrm{aF/Hz^{1/2}}$ 的电容变化（输入参考电容噪声密度），适用于高性能要求的电容式测量电路。换算关系：$1\ \mathrm{aF} = 10^{-18}\ \mathrm{F}$。

**理解**：MEMS 传感器的敏感结构尺寸微小，其电容变化仅 $10^{-15}$ F 量级，普通测量电路的分辨率不足以区分该变化，需要专用低噪声读出电路。指标 $4.0\ \mathrm{aF/Hz^{1/2}}$ 的含义：将电路输出噪声折算到输入电容端，单位带宽（1 Hz）内的等效输入电容噪声为 $4\times10^{-18}$ F；带宽增大时总等效噪声按带宽的平方根增大。该指标远小于待测的 fF 级变化，因此 MS3110 能可靠读出 MEMS 电容的变化量。

**作用**：把电容检测电路与 MEMS 传感器的需求联系起来，引入 MS3110 专用芯片；前置知识点为电容测量电路；后置知识点为芯片内部组成与调制解调读取原理。

#### MS3110 芯片的内部组成与功能

**定义**：MS3110 由电容补偿电路、电荷放大器（Charge Amplifier）、低通滤波器（Low-Pass Filter）以及驱动放大器组成（课件配图为内部结构框图）。课件给出的引脚与内部元件：

- $C_{S1IN}$、$C_{S2IN}$：被读取差分电容对（外部输入）；
- $C_{S1}$、$C_{S2}$：MS3110 芯片内部的可调补偿电容阵列，用于调节由于输入电容不对称而引起的偏置；
- $C_F$：电荷放大器的可调积分电容，通过调节可以设置前端积分器的增益。

**理解**：信号链为：差分电容对（$C_{S1IN}$、$C_{S2IN}$）→ 电容补偿电路（内部电容阵列 $C_{S1}$、$C_{S2}$）→ 电荷放大器（积分电容 $C_F$）→ 低通滤波器 → 驱动放大器。两个可调元件的用途不同：内部补偿电容阵列用于抵消外部差分电容对的不对称——当 $C_{S1IN} \neq C_{S2IN}$ 时输出存在偏置，用阵列补齐差值；积分电容 $C_F$ 决定电荷放大器增益——输出电压与输入电荷之比为 $V = Q/C_F$，$C_F$ 越小增益越高。

**作用**：MS3110 芯片的功能说明，为调制解调读取原理提供模块背景；前置知识点为芯片总体介绍；后置知识点为调制解调电容读取原理。

#### MS3110 的调制解调电容读取原理

**定义**：MS3110 采用调制解调（Modulation and Demodulation）的电容读取方法（课件配图为信号流程或波形图）。课件原文：MS3110 芯片内部可以输出两路幅值相等、相位相反的方波作为待读取电容的激励信号，实现对电容变化的调制；调制信号经过电荷积分放大器将电容变化转换为电压变化，再经过低通滤波、增益放大，就得到了与电容变化成正比的电压信号。

**理解**：该方法的四个环节为：调制（两路反相方波激励差分电容对，把电容变化反映到载波信号上）、电荷积分放大（把电容与电荷的变化转换为电压变化）、低通滤波（滤除载波频率成分，取出与电容变化成正比的低频信号）、增益放大（调整输出幅度）。采用调制解调的原因：把低频的电容变化转换为较高频段的已调信号再进行处理，可避开低频噪声（如闪烁噪声）对微弱电容信号的干扰，从而提高分辨率。

**作用**：MS3110 的工作原理总结，也是第五部分电容检测电路内容的收尾；前置知识点为芯片组成与电荷转移电路；并列知识点为驱动电缆技术。

**杂散电容数据**

| 来源 | 数值 |
| --- | --- |

**二极管双T电桥各半周工作要点**

| 半周 | 工作要点 |
| --- | --- |
| 正半周（$D_1$ 导通、$D_2$ 截止） | $C_1$ 立即充电至 $+U$；$C_0$ 初始电压 $-U$；$R_1=R_2$ 且 $U_A=+U$、$U_B=-U$ 时 $U_L=0$；$C_1$ 电压保持 $+U$；电源经 $R_1$、$R_2$、$R_L$ 向 $C_0$ 充电；$U_B$ 呈指数下降；充电电流 $i_0$ 与负载电流 $i_f$，$i_f$ 从 0 指数上升 |
| 负半周（$D_2$ 导通、$D_1$ 截止） | $C_0$ 立即充电至 $-U$；$C_1$ 初始电压 $+U$；$U_L=0$；$C_0$ 电压保持 $-U$；$C_1$ 电压 $U_A$ 呈指数下降；$i_f$ 从 0 指数下降 |
| 整周期 | 空载（$C_1=C_0$）时正负半周 $R_L$ 电流波形相同、方向相反，平均值为零；工作（$C_1 \neq C_0$）时平均值不为零；滤波后直流分量约等于 $k(C_1-C_0)$ |
| 数值计算条件 | 负半周 $T/2<t<T$：$D_2$ 导通、$D_1$ 截止，$C_1$ 放电，$U_A$ 从 $+U_E$ 指数下降，$U_B=-U_E$；非线性误差 < 1%（当 $k_0$、$k_1 > 5$ 时） |

**双T电桥特点**：线路简单，不需要附加相敏解调器就能获得高电平直流输出，灵敏度较高；二极管及两个电阻都可放在探头内，缩短电容引线，减小分布电容的影响；电源的频率与幅值的稳定性直接影响精度，对电源要求较高。

**激励源结论**

| 激励方式 | 输出量 | 适用类型 |
| --- | --- | --- |
| 恒电荷激励（实用困难，常用恒电流激励） | $U_C = Qd/(\varepsilon A)$，与 $d$ 单值线性，与 $\varepsilon$、$A$ 单值非线性 | 变极距型；测量电路输入阻抗应为无穷大 |
| 恒压源激励 | $I_c = \omega U C_x$，随 $C_x$ 变化 | 变面积型与变介电常数型；变极距型存在理论非线性 |

**调频测量电路**：$C = C_1 + C_2 + C_x$，其中 $C_1$ 为振荡回路固有电容、$C_2$ 为传感器引线分布电容、$C_x = C_0 \pm \Delta C$ 为传感器电容；$\Delta C \neq 0$ 时频率相应变化；非线性；灵敏度较高；可测高至 0.01 μm 级位移变化量；输出频率易于数字仪器测量、与计算机通讯、抗干扰能力强，可发送接收实现遥测遥控。

**测量电容的三种方法**：运算法（阻抗→交流信号）；充放电法（双T电桥，电压/电流平均值表示电容大小）；调频法（谐振→频率信号，可远传、抗干扰）。

**水份测量集成芯片电路**：可精确测出参考电容 5%～100% 的变化电容值；CDC（Capacity to Digital Converter）芯片可把电容值转换为数字量，直接与微机接口。

**激光焦点测量电路**：双振荡器（555 定时器）+ D 触发器 + 温度传感器；参考电容波形接 D 触发器时钟端、敏感电容波形接 D 端，输出为两波形频率差；附加集成温度传感器做温度补偿。

**木工防护装置**：500 kHz 正弦波激励、峰值 3～25 V 可调；人体接触产生寄生电容，最大引起 40% 信号衰减；5 ms 内强行制动（探测+制动）；TMS320LF2403A DSP 作电机控制器；积分器每 6 μs 绝对积分；DSP 每 6 μs 末采样；采样电容下一采样周期前放空。

**温度特性符号**：$C_0$——传感器的初始电容值；$\Delta C_P$——在被测信号作用下电容变化量；$\Delta C_t$——由环境温度变化而产生的附加电容增量；$\Delta C_t$ 决定了传感器温度误差的大小；在设计电容传感器时，正确选择零件的尺寸，可以减少温度造成的测量误差。

**边缘效应处理方案**：1）$A$ 增加、$d$ 减小，可使边缘效应影响变小；2）加装等位环：等位环与上极板保持等电位，等位环一般接导线内屏蔽层。

**分布电容数据**：数值大（> 100 pF/m）；可变（与电缆位置形状有关）。

**驱动电缆接法要求**：外屏蔽单点接地；内屏蔽 1:1 倍放大器连接；要求放大倍数为 1、相移为零，且输入阻抗无穷大、输入电容为 0、无相移——难满足。

**改进型驱动电缆**：放大器 2 为驱动电缆，其输入电容为放大器 1 的负载，因而无附加电容与 $C_x$ 并联；只需两放大器的放大倍数满足乘积为 1（推导过程参见教材 P60）。

**电荷转移法工作步骤**：第 1 步：$S_1$ 和 $S_4$ 闭合，$S_2$ 和 $S_3$ 断开，$V_c$ 对 $C_x$ 充电，充电电阻 $R_f$；第 2 步：$S_2$ 和 $S_3$ 闭合，$S_1$ 和 $S_4$ 断开，$C_x$ 对地放电，放电电阻也为 $R_f$；不断重复，重复频率为 $f$，充放电电流产生平均电压 $V_1$ 和 $V_2$，差分电压输出 $V_o = V_1 - V_2$。

**杂散电容消除结论**：$C_{S1}$ 由 $V_c$ 充电、对地放电，其充放电电流不经过 $C_x$，不影响输出 $V_o$；$C_{S2}$ 放大器虚短，相当于两端均接地，对电路输出无影响；$C$ 不参与 $C_x$ 的充放电过程，对电路输出无影响（放大器输入电容）。

**加速度传感器特点**：频率响应快、量程范围大；大多采用空气或其它气体作阻尼物质。

**测振实例**：相对式——机床转轴相对于机床底座的振动；绝对式——机床底座的振动、地面的振动。

**加速度计实例**：车厢加速度使单摆向后偏离铅垂线、上抛小球落于抛出点后方；牵连惯性力 $Q$ 向后拉动小球；测单摆偏角 $\theta$ 得 $a = g\tan\theta$；弹簧质点系统电位计输出与惯性力成正比。

**位移变量**：静基准为与大地（或惯性空间）保持相对静止的运动参照点；$x$ 为被测振动体及传感器底座的绝对位移；$y$ 为质量块相对底座的相对位移；$x_0$ 为质量块的绝对位移；关系 $x_0 = x + y$。

**MS3110 指标**：可读取低至 $4.0\ \mathrm{aF/Hz^{1/2}}$ 的电容变化；换算 $1\ \mathrm{aF} = 10^{-18}\ \mathrm{F}$；$1\ \mathrm{fF} = 10^{-15}\ \mathrm{F}$；通用电容读取芯片，美国 Irvine 传感器公司生产。

### 公式汇总与符号说明

**基本关系与推导公式**（课件中以结论或推导形式给出）

$$C = \frac{\varepsilon_0 \varepsilon_r A}{d} \quad(\text{平行板电容器})$$

$$C = \frac{C_0}{1 - \dfrac{\Delta d}{d_0}} \quad(\text{变极距型})$$

$$K = \frac{\Delta C}{\Delta d} \approx \frac{C_0}{d_0} \quad(\text{单电容灵敏度})$$

$$K = \frac{\Delta C}{\Delta d} \approx \frac{2C_0}{d_0} \quad(\text{差动结构灵敏度})$$

$$\delta = \left|\frac{\Delta d}{d_0}\right| \times 100\% \quad(\text{单电容相对非线性误差})$$

$$\delta = \left(\frac{\Delta d}{d_0}\right)^2 \times 100\% \quad(\text{差动结构相对非线性误差})$$

$$C_0 = \frac{\varepsilon_0 \varepsilon_r b a}{d},\qquad \Delta C = -\frac{\varepsilon_0 \varepsilon_r b}{d}\Delta x,\qquad \frac{\Delta C}{C_0} = -\frac{\Delta x}{a} \quad(\text{变面积型：平移})$$

$$S_\theta = S\left(1 - \frac{\theta}{\theta_0}\right),\qquad C = C_0\left(1 - \frac{\theta}{\theta_0}\right) \quad(\text{变面积型：角位移})$$

$$C_0 = \frac{2\pi\varepsilon_0 L}{\ln(R/r)},\qquad C = C_0\left[1 + (\varepsilon_r - 1)\frac{L_x}{L}\right] \quad(\text{变介电常数型：液位})$$

$$U_C = \frac{Q}{C} = \frac{Qd}{\varepsilon A} \quad(\text{恒电荷激励})$$

$$I_c = \omega U C_x = 2\pi f U C_x \quad(\text{恒压源激励})$$

$$\dot Z_x = \frac{1}{\text{j}\omega C_x},\qquad \dot U_0 = -\frac{\dot Z_0}{\dot Z_x}\dot U_i = -\frac{C_0}{C_x}\dot U_i,\qquad \dot U_0 = -\frac{C_0 d}{\varepsilon A}\dot U_i \quad(\text{运算法})$$

$$i_1 = \frac{U_E + \frac{R_L}{R + R_L}U_E}{R + (R \parallel R_L)}e^{-\frac{t}{(R + R\parallel R_L)C_1}},\qquad I_1 = \frac{1}{T}\int_0^T i_1\,dt \quad(\text{双T电桥放电电流与直流分量})$$

$$U_L = \frac{RR_L}{R + R_L}(I_1 - I_2),\qquad U_L \approx \frac{RR_L(R + 2R_L)}{(R + R_L)^2 T}U_E(C_1 - C_0) \quad(\text{双T电桥输出})$$

$$k_0 = \frac{(R + R_L)T}{2R_L(R + 2R_L)C_0},\qquad k_1 = \frac{(R + R_L)T}{2R_L(R + 2R_L)C_1} \quad(\text{线性化系数，}>5\ \text{时非线性误差}<1\%)$$

$$\frac{C_1 - C_0}{C_1 + C_0} = \frac{\Delta d}{d_0} \quad(\text{变极距差动时引入}\ 1/(C_0+C_1)\ \text{得到线性输出})$$

$$f = \frac{1}{2\pi\sqrt{LC}},\qquad C = C_1 + C_2 + C_x,\qquad C_x = C_0 \pm \Delta C \quad(\text{调频测量电路})$$

$$V_o = V_1 - V_2 = fC_xV_cR_f \quad(\text{电荷转移法，按工作过程复原})$$

$$A_1 \cdot A_2 = 1 \quad(\text{改进型驱动电缆})$$

$$d_0 = L - h_1 - h_2,\qquad \Delta d = (\alpha_L L - \alpha_1 h_1 - \alpha_2 h_2)\Delta t \quad(\text{温度特性：结构尺寸})$$

$$\delta_t = \frac{\Delta C_t}{C_0} = -\frac{\Delta d}{d_0},\qquad \alpha_L L = \alpha_1 h_1 + \alpha_2 h_2,\qquad \alpha_L d_0 = (\alpha_1 - \alpha_L)h_1 + (\alpha_2 - \alpha_L)h_2 \quad(\text{温度补偿})$$

$$m\frac{d^2x_0}{dt^2} = -c\frac{dy}{dt} - ky,\qquad m\frac{d^2y}{dt^2} + c\frac{dy}{dt} + ky = -m\frac{d^2x}{dt^2} \quad(\text{加速度传感器运动方程})$$

$$x = X_m\sin\omega t,\quad y = Y_m\sin(\omega t - \varphi),\quad \omega_0 = \sqrt{\frac{k}{m}},\quad \xi = \frac{c}{2\sqrt{km}} \quad(\text{正弦运动响应})$$

$$\frac{Y_m}{X_m} = \frac{\left(\dfrac{\omega}{\omega_0}\right)^2}{\sqrt{\left[1 - \left(\dfrac{\omega}{\omega_0}\right)^2\right]^2 + 4\xi^2\left(\dfrac{\omega}{\omega_0}\right)^2}},\qquad \tan\varphi = \frac{2\xi\left(\dfrac{\omega}{\omega_0}\right)}{1 - \left(\dfrac{\omega}{\omega_0}\right)^2} \quad(\text{幅频、相频特性})$$

$$S = \frac{Y_m}{A_m} \approx \frac{1}{\omega_0^2} \quad(\text{加速度传感器灵敏度})$$

$$v(t) = \int a\,dt + v_0,\qquad x(t) = \int v\,dt + x_0,\qquad a = g\tan\theta,\qquad x_0 = x + y \quad(\text{惯性测量关系})$$

## 解题方法汇总

### 方法 1：级数展开线性化近似法

- **适用场景**：变极距型电容传感器（含差动）的特性分析——求电容—位移关系、灵敏度、非线性误差。
- **已知条件**：电容表达式 $C = C_0/(1 \mp \Delta d/d_0)$，且 $|\Delta d/d_0| \ll 1$。
- **计算步骤**：
  1. 令 $x = \Delta d/d_0$，写出展开式 $1/(1-x) = 1 + x + x^2 + x^3 + \cdots$（分母为 $1+x$ 时用 $1 - x + x^2 - x^3 + \cdots$）；
  2. 略去二次及以上高次项，得 $\Delta C/C_0 \approx \Delta d/d_0$；
  3. 将 $\Delta C = C_0\,\Delta d/d_0$ 代入灵敏度定义 $K = \Delta C/\Delta d$，得 $K \approx C_0/d_0$；
  4. 求非线性误差：二次项与一次项之比 $\delta = (\Delta d/d_0)^2/(\Delta d/d_0) = \Delta d/d_0$，写成百分数 $\delta = |\Delta d/d_0| \times 100\%$。
- **常见错误**：忽略收敛条件 $|\Delta d/d_0| \ll 1$ 直接展开；分母为 $1+x$ 时展开式符号写错；把相对变化量 $\Delta C/C_0$ 与灵敏度 $K$ 混淆。

### 方法 2：差动结构消偶次项法

- **适用场景**：减小变极距型传感器的非线性误差、提高灵敏度；差动电容传感器设计。
- **已知条件**：差动两电容 $C_1 = C_0/(1-x)$、$C_2 = C_0/(1+x)$，$x = \Delta d/d_0$，且 $|x| \ll 1$。
- **计算步骤**：
  1. 分别展开 $C_1 \approx C_0(1 + x + x^2 + x^3)$、$C_2 \approx C_0(1 - x + x^2 - x^3)$；
  2. 相减得 $\Delta C = C_1 - C_2 \approx 2C_0(x + x^3)$，偶次项抵消；
  3. 略去高次项得 $\Delta C/C_0 \approx 2x = 2\Delta d/d_0$；
  4. 求灵敏度 $K = \Delta C/\Delta d = 2C_0/d_0$（与单电容 $C_0/d_0$ 相比增加 1 倍）；
  5. 求非线性误差：三次项与一次项之比 $\delta \approx 2C_0x^3/(2C_0x) = x^2 = (\Delta d/d_0)^2$，写成百分数 $\delta = (\Delta d/d_0)^2 \times 100\%$。
- **常见错误**：差动灵敏度仍取 $C_0/d_0$（漏掉 2 倍）；差动非线性误差取 $\Delta d/d_0$（应为 $(\Delta d/d_0)^2$）；相减前不展开，无法看出偶次项抵消。

### 方法 3：电容串并联分析法

- **适用场景**：复杂电极结构电容传感器分析——球—平面型差动压力传感器、同心圆筒液位传感器、电容式水分计。
- **已知条件**：各部分电容的几何参数与介质；串并联规则：并联电容相加，串联电容取倒数相加。
- **计算步骤**：
  1. 将总电容分解为若干基本电容器的串联或并联组合；
  2. 写出各部分电容表达式；
  3. 按串并联规则合成总电容；
  4. 从合成式中分离被测量（液位、膜片挠度、含水量）与输出电容的线性关系。
  示例：球—平面型——把 $C_H$ 写成 $C_A$ 与 $C_0$ 的串联（$1/C_H = 1/C_A + 1/C_0$），把 $C_0$ 写成 $C_L$ 与 $C_A$ 的串联（$1/C_0 = 1/C_L + 1/C_A$）；同心圆筒液位——空载 $C_0 = 2\pi\varepsilon_0 L/\ln(R/r)$，带载 $C = C_0 + (\varepsilon_r - 1)C_0L_x/L$，液面上下两段并联相加；水分计——空气、水分、固体介质三电容并联。
- **常见错误**：把轴向分段（液位上下两段）误判为串联（实为并联，因两段共用电极）；串联公式忘记取倒数相加。

### 方法 4：半周状态等效电路法

- **适用场景**：二极管双T电桥等含二极管的交流充放电电路分析。
- **已知条件**：输入方波（占空比 50%、周期 $T$），$R_1 = R_2 = R$，差动电容 $C_1$、$C_2$（或一个固定电容、一个传感器电容）。
- **计算步骤**：
  1. 正半周：判断 $D_1$ 导通、$D_2$ 截止，画出正半周等效电路；
  2. 负半周：判断 $D_1$ 截止、$D_2$ 导通，画出负半周等效电路；
  3. 写出各半周的充电关系：正半周 $C_1$ 立即充电至电源电压 $E$；负半周 $C_2$（$C_0$）立即充电至电源电压 $E$；
  4. 综合两个半周求负载 $R_L$ 上的输出电压 $U_L$（定量表达式见方法 5）。
- **常见错误**：二极管导通/截止状态判断反（应随电源极性逐半周判断）；忽略"立即充电"的成立条件（充电时间常数须远小于半周期）。

### 方法 5：二极管双T电桥输出电压直流分量计算（半周期分段分析法）

- **适用场景**：求解双T电桥负载输出电压的直流分量（平均值）；定量分析电路输出与两电容差 $(C_1 - C_0)$ 的关系；检验线性条件是否满足（$k_0$、$k_1 > 5$）。
- **已知条件**：电阻 $R_1 = R_2 = R$、负载电阻 $R_L$、电源幅值 $U_E$、电源周期 $T$、电容 $C_1$ 与 $C_0$。
- **计算步骤**：
  1. 按电源极性把周期分段：$0 < t < T/2$ 为正半周（$D_1$ 导通、$D_2$ 截止，$C_1$ 迅速充电至 $+U_E$）；$T/2 < t < T$ 为负半周（$D_2$ 导通、$D_1$ 截止，$C_0$ 迅速充电至 $-U_E$，$C_1$ 放电、$U_A$ 从 $+U_E$ 指数下降、$U_B = -U_E$）。
  2. 负半周列 $C_1$ 放电电流表达式：把 $R$、$R_L$、$U_E$ 代入 $i_1 = \dfrac{U_E + \frac{R_L}{R+R_L}U_E}{R + R \parallel R_L} e^{-\frac{t}{(R + R\parallel R_L)C_1}}$，其中 $R\parallel R_L = \dfrac{RR_L}{R+R_L}$。
  3. 求 $C_1$ 支路直流分量：把 $i_1$ 代入 $I_1 = \frac{1}{T}\int_0^T i_1\,dt$，对指数函数 $e^{-t/\tau}$ 做定积分（$\tau = (R + R\parallel R_L)C_1$，积分结果为含 $(1 - e^{-T/\tau})$ 的形式）。
  4. 对 $C_0$ 支路重复第 2、3 步：把表达式中的 $C_1$ 换成 $C_0$，得到 $i_2$ 与 $I_2 = \frac{1}{T}\int_0^T i_2\,dt$。
  5. 求输出电压直流分量：把 $I_1$、$I_2$ 代入 $U_L = \frac{RR_L}{R+R_L}(I_1 - I_2)$，得到 $U_L = \dfrac{RR_L(R+2R_L)}{(R+R_L)^2 T}U_E\left(C_1 - C_0 - C_1e^{-k_1} + C_0e^{-k_0}\right)$。
  6. 计算并检验线性条件：代入 $k_0 = \dfrac{(R+R_L)T}{2R_L(R+2R_L)C_0}$、$k_1 = \dfrac{(R+R_L)T}{2R_L(R+2R_L)C_1}$；若 $k_0$、$k_1 > 5$，则 $e^{-k_0}$、$e^{-k_1} < 0.007$，忽略修正项（非线性误差 < 1%），输出简化为 $U_L \approx \dfrac{RR_L(R+2R_L)}{(R+R_L)^2 T}U_E(C_1 - C_0)$，即直流分量与电容差成正比。
- **常见错误**：未先验证 $k_0$、$k_1 > 5$ 就忽略指数修正项；混淆正、负半周对应的放电电容（负半周是 $C_1$ 放电、正半周是 $C_0$ 充放电）；把并联电阻 $R\parallel R_L$ 按串联 $R + R_L$ 计算；把周期 $T$ 与半周期 $T/2$ 混用；忽略修正项符号（$-C_1e^{-k_1}$ 为负、$+C_0e^{-k_0}$ 为正）；积分限误用 $0$ 到 $T/2$ 而非课件定义的 $0$ 到 $T$。

### 方法 6：差频测量法（双振荡器 + D触发器频率差检测）

- **适用场景**：电容测量电路中需要降低共模噪声、减少温度影响、抑制电源电压波动的场合（激光焦点测量电路的差频测量方案）。
- **已知条件**：两路振荡器输出波形（一路电容为基准电容，另一路电容为传感器电容）；D 触发器。
- **分析步骤**：
  1. 搭建双振荡器电路（课件采用 555 定时器）：一路振荡器的电容是基准电容，另一路振荡器的电容是传感器电容，两路结构对称。
  2. 把参考电容（基准电容）的波形从 D 触发器的时钟端（CLK）引入，把敏感电容（传感器电容）的波形从 D 端引入。
  3. D 触发器在每个时钟边沿对 D 端电平采样，其输出为两个波形的频率差（差频信号），以差动模式抑制共模噪声、减小温度影响并抑制电源电压波动。
  4. 附加集成温度传感器，把其测量值提供给焦点控制电路，用于温度补偿（激光焊接热量极高、温度变化大）。
- **常见错误**：把 D 触发器视为直接混频器（其输出是频率差信息的数字信号，不是模拟混频输出）；忽略温度补偿环节（高温焊接环境）；两路振荡器参数不对称导致共模抑制效果下降。

### 方法 7：电容式传感器温度补偿设计法

- **适用场景**：设计电容式传感器结构参数（绝缘材料厚度 $h_1$、$h_2$ 及材料）以消除温度引起的电容误差；或已知结构参数求温度误差大小。
- **已知条件**：结构关系 $d_0 = L - h_1 - h_2$；各零件线膨胀系数 $\alpha_L$、$\alpha_1$、$\alpha_2$；温度变化量 $\Delta t$。
- **计算步骤**：
  1. 写出温度引起的间隙增量：$\Delta d = (\alpha_L L - \alpha_1 h_1 - \alpha_2 h_2)\Delta t$——把 $L$ 的膨胀量 $\alpha_L L\Delta t$（使间隙增大）与 $h_1$、$h_2$ 的膨胀量 $\alpha_1 h_1\Delta t$、$\alpha_2 h_2\Delta t$（使间隙减小）按符号相加，得到净间隙变化。
  2. 写出电容相对误差：把 $\Delta d$ 与 $d_0$ 代入 $\delta_t = \Delta C_t/C_0 = -\Delta d/d_0$，得到误差表达式。
  3. 令 $\delta_t = 0$，得补偿条件 $\alpha_L L = \alpha_1 h_1 + \alpha_2 h_2$（即要求 $\Delta d = 0$）。
  4. 把 $L = d_0 + h_1 + h_2$ 代入补偿条件，整理得设计方程 $\alpha_L d_0 = (\alpha_1 - \alpha_L)h_1 + (\alpha_2 - \alpha_L)h_2$。
  5. 先确定 $d_0$（由量程/灵敏度要求），再选择满足设计方程的 $h_1$、$h_2$（材料决定 $\alpha_1$、$\alpha_2$，厚度可调），完成温度补偿设计。
- **常见错误**：
  - 膨胀量符号取错：$L$ 的膨胀使间隙增大（正），$h_1$、$h_2$ 的膨胀使间隙减小（负）。
  - 选择 $h_1$、$h_2$ 时不检查 $L = d_0 + h_1 + h_2$ 的约束，导致尺寸关系不成立。
  - 把温度补偿误解为选用低膨胀系数材料；补偿条件是各零件膨胀量代数和为零，不是膨胀量本身为零。
  - 漏掉 $\delta_t$ 表达式中的负号（$d$ 增大则 $C$ 减小）。

### 方法 8：电容公式的微分误差分析法

- **适用场景**：分析电容传感器中某一参数（间隙 $d$、极板面积 $A$、介电常数 $\varepsilon$）变化引起的电容相对误差，判断误差来源的主次。
- **已知条件**：平行板电容基本公式 $C = \varepsilon A/d$；各参数的变化量 $\Delta \varepsilon$、$\Delta A$、$\Delta d$。
- **计算步骤**：
  1. 对 $C = \varepsilon A/d$ 取对数后微分（或直接全微分），得相对误差分解式：
$$\frac{\Delta C}{C} = \frac{\Delta \varepsilon}{\varepsilon} + \frac{\Delta A}{A} - \frac{\Delta d}{d}$$
  2. 找出误差源对应的项：温度影响主要体现为结构尺寸变化，即 $-\Delta d/d$ 项；边缘效应、寄生电容、分布电容体现为并联附加电容项，需单独处理。
  3. 令总相对误差为零，代入结构关系（如 $\Delta d = (\alpha_L L - \alpha_1 h_1 - \alpha_2 h_2)\Delta t$ 与 $d_0 = L - h_1 - h_2$），解出结构参数应满足的补偿条件。
- **常见错误**：漏掉 $-\Delta d/d$ 的负号；把附加电容型误差（边缘效应、寄生电容）硬套 $-\Delta d/d$ 的线性化表达式；分析温度影响时忽略面积与介电常数随温度的变化项。

### 方法 9：加速度—速度—位移换算与灵敏度分析

- **适用场景**：由加速度计输出求载体速度与位移；分析加速度传感器固有频率与灵敏度之间的关系。
- **已知条件**：加速度 $a(t)$；初始条件 $v_0$、$x_0$；或弹簧刚度 $k$、质量块质量 $m$、单摆偏角 $\theta$。
- **计算步骤**：
  1. 求速度：对加速度积分一次，$v(t) = \int a\,dt + v_0$，代入初始速度 $v_0$ 确定积分常数。
  2. 求位移：对速度再积分一次，$x(t) = \int v\,dt + x_0$，代入初始位置 $x_0$。
  3. 单摆式换算：由 $a = g\tan\theta$，把测得的偏角 $\theta$ 直接换算为加速度 $a$。
  4. 弹簧质量式换算：由平衡条件 $ma = ky$ 得 $y = ma/k = a/\omega_0^2$（其中 $\omega_0 = \sqrt{k/m}$），灵敏度 $S = y/a = 1/\omega_0^2$；据此定量说明"提高固有频率使灵敏度按平方反比降低"。
- **常见错误**：积分时漏加初始条件项 $v_0$、$x_0$；认为灵敏度与固有频率成一次反比（实际为平方反比：$\omega_0$ 加倍，灵敏度降为 1/4）；混淆绝对位移 $x_0$ 与相对位移 $y$（应满足 $x_0 = x + y$）。
