## 知识点详解

### 知识点 1：按存储介质的存储器分类

**定义**：按存储介质不同，存储器分为三类：半导体存储器（20 世纪 70 年代开始广泛使用，包括 RAM、ROM）、光电存储器（光盘）和磁性介质存储器（第一个磁盘系统是 IBM 的 IBM 350 RAMAC）。

**理解**：该分类的标准是信息保存在什么物质上。半导体存储器以半导体器件保存信息，用电信号直接读写，速度快、体积小；磁性介质存储器以磁性材料的磁化状态保存信息，容量大、可脱机保存；光电存储器以介质表面的光学反射差异保存信息。介质不同，读写方式、速度、容量与用途也不同。

**作用**：本章存储器概述部分的第一级分类框架，其下的半导体存储器是后续 1.2 节展开的对象，是后置知识点的前置概念。

---

### 知识点 2：存储二进制信息的条件

**定义**：从原理上讲，只要一种器件或介质具有两个明显稳定的物理状态，并满足一定技术条件（能进行电信号转换、便于读写、速度高、可靠性好），就可用来存储二进制信息。

**理解**：二进制信息用两个可区分的状态表示 0 和 1，因此存储介质必须具有两个稳定状态，且状态不能自发漂移；其余五个技术条件各有功能：可电信号转换保证与电路接口互通，便于读写保证存取操作可行，速度高保证系统性能，可靠性好保证长期不出错。半导体器件满足全部条件，故成为主流存储介质。

**作用**：基础概念，独立知识点。它是判断一种介质能否用于存储、以及比较不同存储介质优劣的判据。

---

### 知识点 3：半导体存储器的分类

**定义**：半导体存储器按功能分为：随机存取存储器 RAM（含静态存储器与动态存储器，按器件工艺分双极型与 MOS 型）、只读存储器 ROM（掩膜 ROM、可编程 ROM（PROM）、可擦除 ROM（EPROM：紫外线擦除、电擦除 EEPROM、FLASH））、串行存储器（移位寄存器、电荷耦合器件 CCD）及其他（FIFO、双口 RAM）。

**理解**：主分类线索是读写能力：RAM 可随时读随时写，断电后数据丢失；ROM 只能读或有限次写，断电后数据保持。第二线索是存储单元的电路形态：RAM 按电路是否需要刷新分静态与动态，按器件工艺分双极型与 MOS 型；ROM 按写入与擦除手段分掩膜、一次可编程、紫外线擦除、电擦除等。每一小类都回答两个问题：能否写、断电后数据是否保持。

**作用**：半导体存储器分类的总纲，第 5 页的 RAM 分类与第 6–7 页的 ROM 分类都是它的逐项展开。

---

### 知识点 4：双极性 RAM

**定义**：采用双极型晶体管工艺制作的随机存取存储器。其特点是存取速度高、集成度低、功耗大、成本高，用于速度较高的场合。

**理解**：双极型晶体管开关速度快，因此存取速度高；但每个存储单元占芯片面积大、工作电流大，造成集成度低、功耗大、成本高。这四个特点之间存在因果：速度高源于器件特性，集成度低与功耗大源于单元面积和电流，成本高是前两者的直接结果。因此它只适合速度要求高、容量需求小的场合。

**作用**：RAM 分类中与 MOS RAM 并列的分支，是后述 SRAM/DRAM 的对比基准。

---

### 知识点 5：静态 RAM（SRAM）

**定义**：场效应管 RAM（MOS RAM）的一种。只要电源存在，数据可长期保留（不需要刷新）；价格高，容量小。

**理解**：SRAM 的存储单元由多管触发器电路构成，信息由电路的稳定状态保存，只要不断电就保持不变，故不需周期性刷新；但单元器件多、面积大，同样芯片面积能容纳的单元少，所以容量小、单位价格高。

**作用**：RAM 分类中"静态"分支，与 DRAM 并列；高速缓存 Cache 采用 SRAM（第 11–12 页内容的直接铺垫）。

---

### 知识点 6：动态 RAM（DRAM）

**定义**：场效应管 RAM（MOS RAM）的一种。基本存储电路由单管线路组成，依靠 MOS 管的栅极电容暂存信息，因此需不断刷新（充电）；价格便宜，容量大。

**理解**：信息以栅极电容上的电荷多少保存；电容电荷会经漏电流逐渐流失，故必须周期性读出并重写（刷新）才能保持数据。因果链为：单管结构使单元面积小，故集成度高、容量大、单位成本低；电容存信息使电荷泄漏，故必须刷新。容量与价格的优点和必须刷新的代价来自同一原因。

**作用**：RAM 分类中"动态"分支，与 SRAM 并列；主存储器（内存）采用 DRAM、SDRAM（第 11 页内容的铺垫）。

---

### 知识点 7：掩模 ROM

**定义**：在制作集成电路时用定做的掩模进行编程的 ROM。一旦制造完毕，存储器的内容就被固定下来，用户只能读但不能改变；若要修改内容，只能重新设计掩模。

**理解**：信息在芯片制造阶段由掩模版图决定，出厂即定型，读出可以、写入无路。修改意味着重新设计掩模并重新流片，周期长、成本高，因此只适用于内容固定、生产批量大的场合。

**作用**：ROM 分类的第一类；与 PROM 的对比点是"用户能否写"（掩模 ROM 用户完全不能写）。

---

### 知识点 8：可编程只读存储器 PROM（Programmable ROM）

**定义**：为便于用户根据自己的需要来写 ROM 而发展出来的只读存储器，用户可对它编程，但只允许一次。

**理解**：PROM 出厂时所有单元处于同一初始状态，用户通过编程设备写入一次，写入是物理不可逆过程，写后内容永久固定。一次性的原因在于编程动作改变了器件结构，无法恢复。

**作用**：ROM 分类的第二类；"用户可写但仅一次"是它区别于掩模 ROM（不可写）与 EPROM（可多次改写）的关键特征。

---

### 知识点 9：可擦除 EPROM（Erasable PROM）— 紫外线擦除

**定义**：当不仅需要 ROM 能写入信息，且在不需要这些信息时能将其擦除后再写、可多次改写，这种 ROM 就是 EPROM，擦除通过紫外线照射完成。

**理解**：EPROM 的存储单元以浮栅电荷的有无表示信息。紫外线照射使浮栅电荷泄放，整片所有单元同时恢复初始状态，之后可重新写入，因此可多次"擦除—改写"循环。擦除是物理可逆的电荷泄放过程，这是它能多次改写的原因；代价是擦除时需把芯片从系统中取下并照射一段时间。

**作用**：ROM 分类的第三类；与 E2PROM 的对比点是擦除方式（紫外线整片擦除与电擦除在线改写）。

---

### 知识点 10：电可擦除 E2PROM（Electricity Erasable PROM）

**定义**：通过一定的电流（或电压）擦除其中的信息，再重新写入，用户可对它编程；可在应用系统中在线改写，断电后信息保存。

**理解**：E2PROM 用电流或电压完成擦除，不再需要紫外线照射，因此芯片不必从系统中取下，可在应用系统中直接改写（在线改写）；信息保存在浮栅电荷上，断电后不丢失。相对 EPROM，其改进是把擦除方式从光学手段换成电学手段。

**作用**：ROM 分类的第四类；其"在线改写 + 断电保存"两个特性被 Flash Memory 继承。

---

### 知识点 11：快擦写存储器（Flash Memory）

**定义**：可在不加电的情况下长期保存信息，还能在线快速擦除重写，兼有 E2PROM 和静态 RAM 的特点，集成度和价位接近 EPROM。可在线进行快速电擦除；编程速度可达 10ns/byte，比 EPROM 和 EEPROM 快；价格已低于 DRAM，容量则接近于 DRAM。分 NAND 与 NOR 两种类型。

**理解**：Flash 组合了四项特性：断电保持（继承 E2PROM 的非易失性）、在线快速电擦写（比 EPROM 的紫外线擦除方便且快）、低价格大容量（接近 DRAM）。10ns/byte 表示每写入 1 字节数据只需 10ns 的编程时间，这是它"快"的具体量度。

**作用**：ROM 分类的第五类，当前主流的非易失存储器；NAND/NOR 的类型对比与具体应用见补充知识点总结。

---

### 知识点 12：计算机中的存储器类型

**定义**：计算机中按层次与用途，存储器分为：主存储器（内存，采用 DRAM、SDRAM）、辅助存储器（硬盘、U 盘、光盘）、高速缓存（采用 SRAM）、控制存储器（CPU 内部寄存器）。

**理解**：四种存储器的分工由"容量—速度—成本"权衡决定：控制存储器（CPU 内部寄存器）容量最小、速度最快、位于 CPU 内部；高速缓存用 SRAM，速度快、容量小，位于 CPU 与主存之间；主存用 DRAM，容量较大、速度居中；辅存容量最大、速度最慢，可脱机保存。越靠近 CPU 的级别速度越高、容量越小、单位成本越高。

**作用**：为 5.5 节 Cache 提供存储层次背景，是 Cache 概念的前置知识点。

---

### 知识点 13：高速缓存 Cache 的概念

**定义**：高速缓存（Cache）是位于 CPU 和动态存储器（DRAM）之间的小容量静态存储器（SRAM）。设置 Cache 的目的是协调 CPU（速度快）和 DRAM（速度慢）之间的速度矛盾。Cache 存在的基础认识：DRAM 容量大、速度慢、便宜；SRAM 容量小、价格太贵。

**理解**：两条事实决定 Cache 的必要性：DRAM 便宜大容量但速度慢，SRAM 速度快但太贵、容量做不大；只用两者中的任何一种都无法同时满足速度与容量要求。解决办法是在 CPU 与 DRAM 之间放置一小容量的 SRAM 作为缓冲，让 CPU 的大部分访问落在 SRAM 上。

**作用**：Cache 一节的总结性概念，给出 Cache 的物理位置（CPU 与 DRAM 之间）、器件类型（SRAM）与设置目的（协调速度矛盾）。

---

### 知识点 14：Cache 的工作原理与命中率

**定义**：被经常存取的指令和数据会自动从内存搬进 Cache，形成主存部分内容的副本；CPU 先向 Cache 读/写数据，只有当其中无所需数据或 Cache 已满，才对内存读写；空闲时 Cache 也会与内存交换数据，更新保存其中的副本。命中率：在任一时刻，CPU 能从 Cache 中可靠获取数据的几率称为命中率。

**理解**：Cache 运行分三种状态：命中（所需数据在 Cache 中，CPU 直接读写 Cache）、未命中（Cache 中无所需数据或 Cache 已满，CPU 转向内存读写）、空闲（Cache 与内存交换数据更新副本）。"自动搬进 Cache"的依据是程序运行中经常存取的数据只占内存的一小部分。命中率是 Cache 的性能指标：命中率越高，CPU 访问落在高速 SRAM 上的比例越大，系统速度越快。

**作用**：解释 Cache 为什么能加速系统；命中率是衡量 Cache 效果的核心指标。

---

### 知识点 15：Cache 的三级结构

**定义**：Cache 采用性能最好的 SRAM，全部功能由硬件实现，对程序员是透明的，用户感觉不到 Cache 的存在。（本页图片为 Cache 三级结构示意图，展示 L1/L2/L3 级 Cache 在 CPU 与主存之间的位置关系。）

**理解**："三级结构"指 Cache 按多个级别组织，越靠近 CPU 的级别速度越高、容量越小。全部功能（数据搬移、替换、一致性维护）由硬件自动完成，不依赖程序参与，因此程序员编写程序时不需要考虑 Cache 的存在，程序的运行结果与无 Cache 时一致，只是速度更快。

**作用**：说明 Cache 的实现特征（硬件化、对程序员透明），是 Cache 一节概念的收尾。

---

### 知识点 16：CPU 与存储器的接口（三总线连接）

**定义**：CPU 与存储器的接口由三总线的连接构成：地址总线的连接、数据总线的连接、控制总线的连接。（本页图为 CPU 与存储器三总线连接示意图：CPU 经地址总线、数据总线、控制总线与存储器相连。）

**理解**：一次访存需要三类信号各司其职：地址总线由 CPU 单向输出，指定访问哪一个存储单元；数据总线在 CPU 与存储器之间双向传送数据内容；控制总线由 CPU 发出读/写等操作命令与同步信号。三类信号缺一不可：没有地址不知道访问哪里，没有数据总线没有内容可传，没有控制信号不知道传送方向。

**作用**：CPU 与存储器接口的总框架；后面四个连接注意问题、位扩展与字扩展的具体连线都在这三组信号上展开。

---

### 知识点 17：存储器与 CPU 连接应注意的问题

**定义**：存储器与 CPU 连接应注意四个问题：CPU 总线的负载能力；CPU 的时序和存储器存取速度的配合；存储器的地址分配和选片；控制信号的连接。

**理解**：四个问题各自针对一类故障原因：负载能力——CPU 总线驱动能力有限，挂接芯片过多时需加总线驱动器件；时序配合——存储器的存取时间必须满足 CPU 总线周期的要求，存储器太慢时需插入等待周期；地址分配和选片——多片芯片组成本机内存时，需确定每片占据哪段地址空间并用片选信号选中；控制信号——RD、WR、M/IO、片选等控制线必须连接正确，否则读写方向与对象错误。

**作用**：存储器扩展设计的检查清单，第 17–20 页的位扩展、字扩展（对应"地址分配和选片"）及第 21 页起的地址译码方式都是其中第三、四点的展开。

### 知识点 18：存储器容量表示方式（2K×8）

**定义**：存储器容量以"单元数×每单元位数"表示，如 2K×8 代表共有 2K 个存储单元，每个存储单元存储 8 位二进制数据。

**理解**：表示式 $N\times M$ 中，$N$ 是存储单元数（字），$M$ 是每个单元的数据位数（字长）。$N$ 决定地址线条数：$2K = 2\times1024 = 2048 = 2^{11}$，需 11 根地址线；$M$ 决定数据线条数：8 根。总容量 $= N\times M = 2048\times8 = 16384$ bit = 16Kbit = 2KB。

**作用**：阅读芯片容量、计算扩展后总容量的基础，位扩展与字扩展两个概念都从该表示式的两个因子（位数与单元数）分别引出。

---

### 知识点 19：位扩展

**定义**：位扩展是指增加存储器的字长，即通过增加存储芯片的方法来实现其与数据位数宽的 CPU 的连接。例如，4 片 2716（EPROM：2K×8）可构成 4K×16bit 的存储器（见例题 1 与第 19 页连接图）。

**理解**：位扩展的操作对象是表示式 $N\times M$ 中的 $M$（位数）。做法：把 2 片 8 位芯片的地址线与控制线并接，一片接数据线 D7–D0，另一片接 D15–8，构成 2K×16 的一组（单元数 2K 不变，位数 8 变 16）；例题中再用 A11 选通两组，单元数由 2K 增至 4K，最终得 4K×16。即纯位扩展只改变位数；例题的 4K×16 是"位扩展加选组"的组合结果。

**作用**：8086CPU 容量扩展的两种方法之一，用于解决芯片数据位数小于 CPU 数据总线宽度的问题；例题 1 见例题汇总。

---

### 知识点 20：字扩展

**定义**：字扩展是指增加存储器的字的数量。如 4 片 1K×8 的存储器，可组成 4K×8 的存储器，即存储器的容量增加到原来的 4 倍（见例题 2 与第 20 页连接图）。

**理解**：字扩展的操作对象是表示式 $N\times M$ 中的 $N$（单元数）。做法：各片数据线并接、片内地址线并接（1K = $2^{10}$，需 10 根地址线 A9–A0），用高位地址经译码电路产生各片独立的片选信号 CE，使任一时刻只有一片被选中，把 4 个 1K 地址段拼成连续的 4K 地址空间。字扩展后每单元位数不变，单元数增加。

**作用**：8086CPU 容量扩展的两种方法之一，用于解决单片容量小于所需总容量的问题；例题 2 见例题汇总。

---

### 知识点 21：74LS138 译码器（复习）

**定义**：3 线—8 线译码器。当控制端 G1=1、G2A=0 和 G2B=0 时，由 3 个输入端 C、B、A 的电平决定 Y7～Y0 中哪个输出低电平。常用高位地址和存储器操作信号（如 M/IO）作控制端输入；C、B、A 与 3 根地址线相连，形成 3 位二进制编码输入。（图 5.16 为 74LS138 引脚和输出真值表。）

**理解**：三个使能端必须同时满足条件（G1 高、G2A 低、G2B 低）芯片才工作；工作后 CBA 的 3 位二进制编码 000～111 决定 Y0～Y7 中恰有一个输出低电平，其余输出高电平（输出低电平有效）。把 3 根高位地址线接 CBA，把 G1 接 +5V、G2A/G2B 接地或接存储器操作信号（如 M/IO），即可把高位地址的 8 种组合转成 8 个片选信号，用于字扩展中选通各片芯片。

**作用**：字扩展（第 20 页）与存储器地址分配（第 21 页起）所需的片选译码工具；本页为后续内容的复习铺垫。

### 知识点 22：片选与字选

**定义**：CPU 访问内存时，首先要选择存储芯片，即**片选**（Chip Select）；然后再从该芯片中依地址码选择出相应的存储单元以进行数据存取，即**字选**（Word Select）。片选由地址译码方式完成，共有三种方法：全译码法、线选法、部分译码法。

**理解**：一次内存访问的地址码由两部分组成。高位部分回答"是哪一片芯片"，低位部分回答"是这片芯片内的哪一个单元"。两部分的划分依据是芯片的片内容量：若片内有 $2^N$ 个单元，则最低 $N$ 位地址线接芯片地址端做字选，其余高位地址线用于产生片选信号。划分确定后，访问任何单元时 CPU 送出的完整地址都能唯一对应到"某片芯片的某个单元"，据此可以反推各芯片占用的地址范围。

**作用**：存储器地址分配的基础框架，后续三种译码方式的共同前置概念；掌握后能够解释"为什么同一片芯片会对应一段连续的地址区间"以及"地址重叠是如何产生的"。

---

### 知识点 23：全译码法

**定义**：在存储芯片较多时常采用的地址分配方法。将 $N$ 条低位地址线直接接到所有存储器芯片的地址输入端（$N$ 由片内存储容量决定），用于片内存储单元寻址（字选）；将 CPU 地址总线中剩下的高位地址线**全部**接往地址译码器的输入端，译码器输出作为各芯片的片选信号，分别接到芯片的片选端，实现片选。

**理解**：全译码法的构成要素是"低位全接芯片 + 高位全接译码器"。因为高位地址线全部参与译码，所以每片芯片被选中时对应的高位组合是唯一确定的；低位地址线在片内从全 0 变化到全 1，所以每片芯片占一段固定长度的连续区间；各片的译码输出互斥，故各区间首尾相接、不重叠。例如第 22 页的例子：16 根地址线（寻址空间 0000H–FFFFH），每片 8KB（$8\times1024=2^{13}$，13 根片内地址线 A12–A0），A15–A13 三根高位线接译码器，Y0–Y3 依次接 U1–U4 的片选端，得到 0000H–1FFFH、2000H–3FFFH、4000H–5FFFH、6000H–7FFFH 四个连续区间。

**作用**：三种地址译码方式中最规范的一种，直接结论是"地址空间连续，不会出现空间重叠和冲突"；是 8086 系统存储器连接（第 4 节）中地址分配的计算基础。

---

### 知识点 24：线选法

**定义**：直接将某高位地址线接往某存储芯片的片选端，当该地址线信息为 1 时即选中该存储器，然后再依低地址位对其进行片内寻址的地址分配方法。

**理解**：线选法用一根地址线代替整个译码器，每根高位线只能选通一片芯片，因此电路最简单。但由于选通只取决于一根线的状态，其余高位地址线取 0 或取 1 都不影响该芯片被选中，同一片芯片就会在地址空间中出现多个映像区间；不同芯片的选通线同时为 1 时两片芯片同时被选中，产生地址重叠与数据冲突。例：两片 2732（4K×8，片内地址线 A0–A11），第一片 CS 接 A12、第二片 CS 接 A13，第一片占用 1000H–1FFFH 与 3000H–3FFFH，第二片占用 2000H–2FFFH 与 3000H–3FFFH，重叠区间 3000H–3FFFH 内地址不可用。

**作用**：三种地址译码方式之一；结论是"线选法电路简单实用，但存在地址重叠、地址不连续问题"。掌握后能够计算任意线选连接的地址范围与重叠区域（课件明确要求会计算地址重叠区域）。

---

### 知识点 25：部分译码法

**定义**：线选法和全译码法相结合的方法。利用高位地址线进行译码产生片选信号时，只有一部分高位地址线参加译码，其余高位地址线未参加译码（不接入、不用），以对芯片进行片选。该方式也存在地址重叠的问题。

**理解**：部分译码法的构成要素是"部分高位线接译码器 + 部分高位线悬空不用"。参加译码的线保证所选芯片的基本区间互不冲突，未参加译码的线取 0 或取 1 都不影响译码结果，因此每片芯片的地址区间会在整个寻址空间中重复出现多次（映像）。例：由 1K×8 的 RAM 构成 4K×8 的 RAM，A11–A10 接 2:4 译码器产生 4 个片选，A9–A0 接各片地址端，A12–A15 未参与译码；四组芯片的基本区间为 0000–03FFH、0400–07FFH、0800–0BFFH、0C00–0FFFH，且由于 A12–A15 任意，整个 4KB 块在 64KB 空间内映像 16 次。

**作用**：三种地址译码方式之一，兼有全译码法的多片译码能力与线选法的电路简洁性，代价是地址重叠；是理解"地址译码中未参与译码的地址线导致地址多义"的关键知识点。

---

### 知识点 26：奇偶存储体的分体结构

**定义**：8086 系统存储器连接的特点。8086CPU 将 1MB（$2^{20}$ 字节）的存储空间分成两个 512KB（$2^{19}$ 字节）存储体：**偶存储体**和**奇存储体**。偶存储体存放偶数地址单元，其数据线与 CPU 的 D0~D7 相连；奇存储体存放奇数地址单元，其数据线与 CPU 的 D8~D15 相连。偶存储体由 A0=0 选通，奇存储体由 $\overline{\text{BHE}}$=0 选通；两个存储体的片内地址输入端都接 CPU 的 A1~A19（即存储体自身的 A0~A18）。

**理解**：分体结构是为了同时满足 16 位数据总线宽度与字节寻址的要求。把全部偶地址字节集中到一个存储体、全部奇地址字节集中到另一个存储体后，16 位数据线的高 8 位和低 8 位各自只连一个存储体；访问 16 位数据时两体同时被选通，访问一个字节时只选通其中一个体，不会出现一个体要同时驱动高低 8 位数据线的情形。选通信号只需要两个：A0 用于区分奇偶，$\overline{\text{BHE}}$ 用于表示高 8 位数据有效。

**作用**：8086 存储器连接的核心结构，是 A0/BHE 功能表、SRAM 连接、地址分配计算等后续内容的直接基础；也是"8086 的最小存储配置为何是两个体"的原因。

---

### 知识点 27：A0 与 BHE 的选通作用

**定义**：$\overline{\text{BHE}}$（Bus High Enable，总线高位允许）是 8086 的高 8 位数据总线（D8~D15）允许信号，低电平有效。A0 与 $\overline{\text{BHE}}$ 的组合决定访问方式，见下表：

| $\overline{\text{BHE}}$ | A0 | 功能 |
|:---:|:---:|---|
| 0 | 0 | 高低字节同时传送（奇偶地址，即 16 位传送） |
| 1 | 0 | 低位字节（偶地址，D0~D7） |
| 0 | 1 | 高位字节（奇地址，D8~D15） |
| 1 | 1 | 无效 |

**理解**：拆解四种组合的因果：$\overline{\text{BHE}}$=0 使奇存储体被选通、A0=0 使偶存储体被选通。两者同时为 0 时两个体同时选中，16 位数据一次送出，对应从偶地址开始的一个字；$\overline{\text{BHE}}$=1 且 A0=0 时只有偶存储体选中，送出低 8 位（偶地址字节）；$\overline{\text{BHE}}$=0 且 A0=1 时只有奇存储体选中，送出高 8 位（奇地址字节）；两者同时为 1 时没有存储体被选中，该组合无效。四种组合穷尽了全部可能，没有其他访问方式。

**作用**：8086 与存储器连接中控制信号设计的核心；用于判断任意总线周期传送的是字节还是字、是高字节还是低字节，并用于推导规则字与非规则字的传送过程（页面提示"还记得规则字和非规则字的概念吗？"——规则字从偶地址开始、一个总线周期完成传送，非规则字从奇地址开始、需两个总线周期）。

---

### 知识点 28：最小模式下的存储器配置

**定义**：8086 工作在最小模式（MN/MX 接 +5V）时，CPU 通过以下器件与存储器子系统连接：8284A 时钟发生器（X1、X2 接晶振，产生 CLK，并提供 READY 与 RESET 信号）；8282×3 地址锁存器（STB 由 ALE 控制，锁存分时复用的 AD15~AD0 及 A19~A16，形成 20 位地址总线 A19~A0）；74LS245×2 数据总线收发器（8 位×2 组成 16 位双向数据通道，方向由 DT/R 控制、输出允许 OE 由 DEN 控制，选用）。存储器子系统挂接在地址总线 A19~A0 与数据总线 D15~D0 上。

**理解**：该配置解决两个硬件问题。其一，8086 的地址与数据分时复用同一组引脚（AD15~AD0），地址信息只在总线周期开始时刻有效，因此需要 8282 在 ALE 有效时把地址锁存下来并保持到周期结束；其二，CPU 总线驱动能力有限且需要双向数据通路，因此数据线经 74LS245 缓冲收发，方向随读/写切换。8284A 则把晶振信号分频整形成 CPU 需要的时钟，并同步外部的复位与就绪信号。

**作用**：8086 存储器连接在硬件层面的前置配置；后续所有"8086 与存储器连接"的题目中，地址总线、数据总线、BHE 均由该配置产生，是理解连接图左半部分（CPU 侧）的依据。

### 知识点 29：8086 与存储器的控制信号连接（M/IO、RD–OE、WR–WE）

**定义**：8086 与存储器（SRAM 等）连接时，控制总线的对应关系为：CPU 的 $\overline{\text{RD}}$ 接存储芯片的 $\overline{\text{OE}}$（输出允许，读操作时有效）；CPU 的 $\overline{\text{WR}}$ 接存储芯片的 $\overline{\text{WE}}$（写允许）；M/IO 信号区分存储器访问（M/IO=1）与 I/O 访问（M/IO=0），在存储器连接中用于使能译码/片选逻辑；A0 与 $\overline{\text{BHE}}$ 分别选通偶、奇存储体。

**理解**：拆解一次读操作的控制路径：CPU 使 $\overline{\text{RD}}$=0，该信号直接送到芯片 $\overline{\text{OE}}$ 端，芯片把选中单元的数据放到数据总线，由总线收发器送回 CPU；写操作路径同理，$\overline{\text{WR}}$=0 送到 $\overline{\text{WE}}$ 端，数据被写入。M/IO 的作用是限定访问对象：译码产生片选时只有 M/IO=1（访问存储器）才允许译码输出有效，避免存储器与 I/O 端口占用同一地址段时发生冲突。

**作用**：8086 存储器连接的控制总线部分，与地址分配（第 31–32 页）并列构成完整连接的三个要素（数据线、地址线、控制线）；本章小结中列为重点掌握内容（奇偶存储器体结构，A0 和 BHE，M/IO，RD 和 OE，WR 和 WE）。

### 1. 全译码法示例地址分配表（第 22 页）

| 0000~1FFFH | U1 | 0 0 0 | 00…00 ~ 11…11 | Y0 |
| 2000~3FFFH | U2 | 0 0 1 | 同上 | Y1 |
| 4000~5FFFH | U3 | 0 1 0 | 同上 | Y2 |
| 6000~7FFFH | U4 | 0 1 1 | 同上 | Y3 |

- 图中译码器为 3–8 译码器（74LS138 类），输入端接 A15~A13，输出 Y0、Y1、Y2、Y3…；4 片 8KB 芯片各有 CE（片选）端。

### 2. 线选法细节与结论（第 23–24 页）

- 2732：4K×8 位 EPROM，片内地址线 A0~A11（$4\mathrm{K}=2^{12}$），片选端 CS。
- 连接：第一片（左）CS 接 A12，第二片（右）CS 接 A13；"1"选通（该地址线为 1 时选中对应芯片）；两片共用数据总线。
- 地址书写规则："\*" 表示可为任意值，不影响对当前片的选择（该位不参与译码）。
- 幻灯片给出的地址模式与十六进制结果：

| 芯片 | 最高地址（A15A14A13A12 A11…A0） | 最低地址 | 实际区间 |
|---|---|---|---|
| 第一块（左，A12=1 选通） | 00\*1 111111111111 | 00\*1 000000000000 | 1000H–1FFFH（A13=0）、3000H–3FFFH（A13=1） |
| 第二块（右，A13=1 选通） | 001\* 111111111111 | 001\* 100000000000 | 2000H–2FFFH（A12=0）、3000H–3FFFH（A12=1） |

- 说明：幻灯片中第二块最低地址印为 001\* 100000000000（对应 2800H），与"两片均完整使用 A0–A11"及"重叠区间为 3000H–3FFFH"的结论不符，按一致取值应为 001\* 000000000000（即 2000H）；按两种读法，重叠区间结论不变（推导见例题 4）。
- 结论原文：第一/二块的地址重叠区间为 3000H–3FFFH；由于存在冲突（两片同时向数据总线输出，数据冲突），在重复区间内的地址是不可用的。线选法电路简单实用，但存在地址重叠、地址不连续问题，需要特别注意。要求会计算地址重叠区域。

| 分组 | A15 A14 A13 A12 A11 A10 | A9–A0 范围 | 地址区间 |

| 一组 | 0 0 0 0 0 0 | 0000000000 ~ 1111111111 | 0000–03FFH |

## 解题方法汇总

### 方法 1：存储器芯片容量表示式的解读（N×M 格式）

- **适用场景**：阅读芯片容量参数、确定芯片所需地址线与数据线根数、为扩展计算做数据准备。
- **已知条件**：形如 N×M 的容量表示式（如 2K×8、1K×8）。
- **计算步骤**：
  1. 读出单元数 N 与每单元位数 M：2K×8 中 N = 2K = 2×1024 = 2048，M = 8。
  2. 地址线根数 = $\log_2 N$：2048 = $2^{11}$，需 11 根地址线。
  3. 数据线根数 = M = 8。
  4. 总容量 = N×M = 2048×8 = 16384 bit = 16Kbit = 2KB。
- **常见错误**：把 2K 当成 2000；把 2K×8 整体误读为"2K 字节"（2K×8 表示 2048 个单元、每单元 8 位，总容量才是 2KB）；用单元数代替地址线根数（两者是对数关系）。

### 方法 2：位扩展容量计算

- **适用场景**：存储器芯片的数据位数（如 8 位）小于 CPU 数据总线宽度（如 16 位）时，扩展字长以匹配 CPU。
- **已知条件**：芯片容量（2716 为 2K×8）、CPU 数据总线宽度（16 位）、芯片数量（4 片）。
- **计算步骤**：
  1. 计算构成 16 位数据宽度所需并接片数：16 ÷ 8 = 2 片（一片接 D7–0，另一片接 D15–8），这 2 片构成一组 2K×16。
  2. 计算组数：4 ÷ 2 = 2 组；区分 2 组需 1 根地址线（$2^1 = 2$），图中用 A11 经片选逻辑选组。
  3. 总容量 = 组数 × 每组容量 = 2 × 2K×16 = 4K×16。
  4. 换算与校验：4K×16 = 4×1024×16 = 65536 bit = 8KB；4 片 × 2K×8 = 4×2048×8 = 65536 bit = 8KB，两者相等，扩展前后总比特数不变。
- **常见错误**：认为位扩展改变单元数（纯位扩展只增加每单元位数，单元数由"组数"决定）；忘记并接的两片必须接同一组地址线与控制信号；混淆位扩展（扩位数 M）与字扩展（扩单元数 N）。

### 方法 3：字扩展容量计算

- **适用场景**：单片芯片容量小于所需总容量、且每单元位数已与 CPU 数据总线匹配时，扩展存储单元数量。
- **已知条件**：芯片容量（1K×8）、芯片数量（4 片）。
- **计算步骤**：
  1. 各片数据线并接、片内地址线并接；片内寻址线数 = $\log_2(1K) = \log_2 1024 = 10$ 根（A9–A0）。
  2. 计算片选信号数：4 片需 4 个片选；译码输入线数 = $\log_2 4 = 2$ 根高位地址线（$2^2 = 4$ 种组合），接译码电路，其 4 个输出分别接各片 CE，保证任一时刻只选中一片。
  3. 总单元数 = 4 × 1K = 4K，每单元仍 8 位，故总容量 = 4K×8。
  4. 容量倍数 = 4K ÷ 1K = 4，即容量增加到原来的 4 倍。
  5. 换算与校验：4K×8 = 4×1024×8 = 32768 bit = 4KB；4 片 × 1K×8 = 4×1024×8 = 32768 bit = 4KB，两者相等。
- **常见错误**：把译码选片的地址线与片内寻址的地址线混用；不给每片独立的 CE 信号，导致多片同时被选中、数据线冲突；认为字扩展会改变每单元位数（字扩展中位数不变）。

### 方法 4：74LS138 译码器作片选的使用方法（复习）

- **适用场景**：字扩展中把高位地址译码成多个片选信号（本方法为复习铺垫；地址分配计算见方法 5～7）。
- **已知条件**：3 根高位地址线（任意 3 根，如 A13、A12、A11）、存储器操作信号（如 M/IO）。
- **计算步骤**：
  1. 使能端接线：G1 接 +5V（=1），G2A、G2B 接地（=0），使芯片使能。
  2. C、B、A 依次接 3 根高位地址线，C 为最高位，形成 3 位二进制编码输入。
  3. 按 CBA 的 8 种编码 000～111 确定输出：与编码对应的那个 Y 端输出低电平（有效），其余 7 个 Y 端输出高电平。
  4. 把各 Y 输出分别接各存储器芯片的 CE 端，实现"任一时刻只选中一片"。
- **常见错误**：忽视 G2A、G2B 是低电平有效（应接 0，不能接 1）；把高电平当作有效输出（74LS138 输出低电平有效）；C、B、A 的权位接反导致片选顺序错乱。

### 方法 5：全译码法地址范围计算（由连线推地址，或由地址推连线）

- **适用场景**：芯片较多、采用全译码法的存储器系统；求各芯片地址范围，或给定地址范围设计译码器连线。
- **已知条件**：CPU 地址总线位数（如 16 位）；每片芯片容量（决定片内地址线数 $N=\log_2(\text{容量/字节})$）；高位地址线与译码器的接法。
- **计算步骤**（以第 22 页为例：16 位地址，4 片 8KB）：
  1. 求片内地址线数：$N=\log_2(8\times1024)=13$，即 A12~A0 接各片地址端。
  2. 确定译码输入：剩余高位线 A15、A14、A13 全部接译码器；译码输出 Y0~Y3 依次接 U1~U4 的 CE。
  3. 对 U1 写出完整 16 位地址模式：高位 A15A14A13=000，低位 A12~A0 从 0000000000000 到 1111111111111。
  4. 换算十六进制：最低 = 0000 0000 0000 0000B = 0000H；最高 = 0001 1111 1111 1111B = 1FFFH。
  5. U2/U3/U4 高位分别取 001/010/011，低位同 U1：得 2000H–3FFFH、4000H–5FFFH、6000H–7FFFH。
  6. 校验：每片地址数 = 1FFFH−0000H+1 = 2000H = 8192 = 8K ✓；四个区间首尾相接（1FFFH+1=2000H 等）→ 连续、无重叠 ✓。
- **常见错误**：片内地址线数算错（如把 8KB 当成 $2^3$ 而非 $2^{13}$）；二进制转十六进制时分组错位；忘记校验每片区间长度是否等于芯片容量；忽略 74LS138 输出低电平有效而接错 CE 电平。

### 方法 6：线选法地址范围与重叠区计算

- **适用场景**：片选端直接接单根高位地址线的电路；求各芯片地址范围、映像区间与重叠区间。
- **已知条件**：芯片容量（决定片内地址线数）；哪根地址线接哪片芯片的 CS；选通电平（"1"选通）。
- **计算步骤**（以第 23–24 页两片 2732 为例：4K×8，CS 分别接 A12、A13）：
  1. 求片内地址线数：$N=\log_2 4096=12$，即 A0~A11 接芯片。
  2. 第一片选中条件：A12=1；写出地址模式 00\*1 xxxx xxxx xxxx（A15A14=00，A13 为无关位 \*）。
  3. 令 \*=0：最低地址 = 0001 0000 0000 0000B = 1000H，最高 = 0001 1111 1111 1111B = 1FFFH。
  4. 令 \*=1：最低 = 0011 0000 0000 0000B = 3000H，最高 = 0011 1111 1111 1111B = 3FFFH。第一片总区间：1000H–1FFFH ∪ 3000H–3FFFH。
  5. 第二片选中条件：A13=1；模式 001\*。令 \*=0（A12=0）：2000H–2FFFH；令 \*=1（A12=1）：3000H–3FFFH。
  6. 求重叠区：两片同时选中的条件是 A12=1 且 A13=1，即地址模式 0011 xxxx xxxx xxxx → 3000H–3FFFH。
  7. 结论：3000H–3FFFH 内两片同时驱动数据总线，产生数据冲突，该区间地址不可用。
  8. 验证：重叠区间 3000H–3FFFH 与幻灯片结论一致 ✓；每片 1000H 个地址 = 4096 = 4K ✓。
- **常见错误**：漏算无关位（\* 位）取 1 时的映像区间，只写 1000H–1FFFH 与 2000H–2FFFH；把重叠区间当可用地址；选通电平搞反（本方法为"1"选通，与低电平有效的 CE 不同）。

### 方法 7：部分译码法地址范围计算

- **适用场景**：部分高位地址线参与译码、其余高位线悬空的电路；求各片地址范围并判断重叠。
- **已知条件**：芯片容量（片内地址线数）；参与译码的高位线及译码器类型（如 2:4）；未参与译码的地址线。
- **计算步骤**（以第 25–26 页 1K×8 ×4 → 4K×8 为例）：
  1. 片内地址线数：$N=\log_2 1024=10$，即 A9~A0 接各片地址端。
  2. 总容量 4K×8 需 12 根地址线：A11~A0；A11、A10 接 2:4 译码器，4 个输出分别接四组芯片 CS。
  3. 对一组（译码输入 00）：地址模式 = A15~A12（无关）×4 位 + 00 + A9~A0；取 A15~A12=0000 得最低 0000 0000 0000 0000B = 0000H，最高 0000 0011 1111 1111B = 03FFH。
  4. 二组（01）：010000000000B = 0400H ~ 011111111111B = 07FFH。
  5. 三组（10）：0800H–0BFFH（100000000000B ~ 101111111111B）。
  6. 四组（11）：0C00H–0FFFH（110000000000B ~ 111111111111B）。
  7. 重叠判断：A12~A15 未参与译码，16 种取值使四组区间整体映像 16 次（0000H–0FFFH 至 F000H–FFFFH），各映像区间之间构成重叠。
  8. 校验：每组 03FFH−0000H+1 = 400H = 1024 = 1K ✓；4 组 × 1K = 4K ✓；基本区间 0FFFH+1 = 1000H = 4096 ✓。
- **常见错误**：把未参与译码的地址线当作固定 0，忽略映像区间；校验总区间时用幻灯片印刷的 0FFFFH（应为 0FFFH）；把 2:4 译码器输入顺序 A11/A10 接反。

### 方法 8：BHE/A0 组合判断传送类型

- **适用场景**：给定 8086 总线周期的 A0 与 $\overline{\text{BHE}}$ 状态，判断传送内容；或反推。
- **已知条件**：A0 与 $\overline{\text{BHE}}$ 的值；数据线分组（偶存储体 D0~D7，奇存储体 D8~D15）。
- **计算步骤**：
  1. 查功能表：0/0→16 位（高低字节同时传送）；1/0→低 8 位（偶地址字节）；0/1→高 8 位（奇地址字节）；1/1→无效。
  2. 判断存储体：$\overline{\text{BHE}}$=0 选通奇存储体；A0=0 选通偶存储体；两条件各自独立。
  3. 判断字类型（与规则字/非规则字联系）：从偶地址开始的字 = 规则字，一次 0/0 组合完成；从奇地址开始的字 = 非规则字，先 0/1 取高字节、再 1/0 取低字节，共两个总线周期。
  4. 结果：给出传送宽度（字节/字）与数据线范围。
- **常见错误**：记反 $\overline{\text{BHE}}$ 的有效电平（0 有效）；把 1/1 当作"两体同时选中"（实际是无存储体选中）；把奇偶存储体与数据线高低的对应关系写反。

### 方法 9：8086 存储器地址分配与 74LS138 连线（给定起始地址）

- **适用场景**：给定起始地址与芯片，填写各芯片地址空间并连接译码器输出线（如第 32 页课堂作业）；或给定连线图反推地址空间（如第 31 页分析题）。
- **已知条件**：起始地址（如 9C000H）；芯片数量与容量；芯片所在存储体（偶/奇）；译码器类型（74LS138）。
- **计算步骤**（以课堂作业为例，按 M1、M2 为两片 8KB 芯片、置于偶存储体的常见布置演示）：
  1. 把起始地址写成 20 位二进制：9C000H = 1001 1100 0000 0000 0000B。
  2. 确定片内地址对应关系：偶存储体芯片的片内地址 A0~A12 接 CPU 的 A1~A13（奇存储体则同时受 $\overline{\text{BHE}}$ 控制）。
  3. 算 M1 区间：起始 9C000H，容量 8KB → 末地址 = 9C000H + 8×1024 − 1 = 9C000H + 1FFFH = 9DFFFH（偶地址范围内 9C000H、9C002H、…、9DFFEH）。
  4. 算 M2 区间：起始 = 9DFFFH + 1 = 9E000H，末地址 = 9E000H + 1FFFH = 9FFFFH。
  5. 提取片选条件：M1 的 CPU 地址中 A13=0、A19~A14 = 100111；M2 中 A13=1、其余同。74LS138 输入取 A13、A14、A15（或更高位按实际图定），M1 对应输入 110 → 接 Y6，M2 对应 111 → 接 Y7；译码器使能端由 M/IO 与 A16~A19 组合控制。
  6. 校验：M1、M2 区间长度均为 2000H = 8192 = 8K ✓；两区间连续（9DFFFH+1=9E000H）且不重叠 ✓。
- **常见错误**：忘记偶存储体芯片接的是 CPU 的 A1~A19（错把 A0 直接接芯片）；把 BHE 漏接；片选条件只看 A13~A15 而忽略 A16~A19 与 M/IO 的使能条件；区间末地址多算或少算 1（应减 1 再相加）。

### 例题 1：位扩展 — 用 4 片 2716 构成 4K×16bit 存储器（第 19 页）

**题干**：
位扩展是指增加存储器的字长，即通过增加存储芯片的方法来实现其与数据位数宽的 CPU 的连接。例如，4 片 2716（EPROM：2K×8）可构成 4K×16bit 的存储器，如下页图所示。连接图中：地址输入 A10–A0 并接至各片地址端；A11 用于选通两组芯片（接片选逻辑）；各片 OE 接读信号 RD；4 片的数据输出并接为 D15–0，其中一组提供 D7–0，另一组提供 D15–8。图注为"组合 4 个 2K×8 的存储器构成一个 4K×16 的存储器"。

**解**：

第 1 步：分析单片容量。2716 为 2K×8：单元数 2K = 2048 = $2^{11}$，需 11 根地址线（A10–A0）；每单元 8 位。

第 2 步：计算构成 16 位数据宽度所需并接片数。每片数据线 8 根，CPU 数据总线 16 位，故需 16 ÷ 8 = 2 片并接：一片接 D7–0，另一片接 D15–8。这 2 片构成一组，单元数仍为 2K，每单元 16 位，即一组 2K×16。

第 3 步：计算组数。共 4 片，4 ÷ 2 = 2 组。区分 2 组需要 1 根地址线（$2^1 = 2$），图中用 A11 经片选逻辑选通两组。

第 4 步：计算总容量。2 组 × 2K×16 = 4K×16，即 4K 个存储单元、每单元 16 位。

第 5 步：换算。4K×16 = 4 × 1024 × 16 = 65536 bit = 8KB。

第 6 步：用原始数据验证。4 片 2716 的总容量 = 4 × 2K×8 = 4 × 2048 × 8 = 65536 bit = 8KB。与第 5 步结果 65536 bit 相等，验证通过：扩展前后总比特数不变。

**答案**：4 片 2716（2K×8）可构成 4K×16bit 的存储器（共 8KB）。其中 2 片并接实现位扩展（每单元 8 位 → 16 位），再用 A11 选通两组使单元数 2K → 4K。

### 例题 2：字扩展 — 4 片 1K×8 组成 4K×8 存储器（第 20 页）

**题干**：
字扩展是指增加存储器的字的数量。如 4 片 1K×8 的存储器，可组成 4K×8 的存储器，即存储器的容量增加到原来的 4 倍。连接图中：每片 EPROM 均有 CE、OE、OUT（数据输出）和 Vcc 端；4 片的地址线与数据输出并接；各片 CE 分别接译码电路的 4 个输出（图中标 0、1 等）；各片 OE 接读信号 RD；译码电路输入端接高位地址；+5V 为电源；数据读出端为并接后的数据输出。

**解**：

第 1 步：分析单片容量。每片 1K×8 = 1024 单元 × 8 位；片内寻址需 $\log_2 1024 = 10$ 根地址线（A9–A0）。

第 2 步：数据线并接。4 片的数据输出并接，每片仍提供 8 位，字长保持 8 位不变。

第 3 步：计算片选译码。4 片需 4 个片选信号；译码输入线数 = $\log_2 4 = 2$ 根高位地址线（$2^2 = 4$ 种组合），接译码电路；译码电路 4 个输出分别接 4 片 CE，保证任一时刻只有一片被选中。

第 4 步：计算总单元数。4 × 1K = 4K 个存储单元。

第 5 步：计算总容量。4K × 8 = 4K×8。

第 6 步：计算容量倍数。4K ÷ 1K = 4，即容量增加到原来的 4 倍。

第 7 步：换算与用原始数据验证。4K×8 = 4 × 1024 × 8 = 32768 bit = 4KB；4 片 × 1K×8 = 4 × 1024 × 8 = 32768 bit = 4KB。两者相等，验证通过。

**答案**：4 片 1K×8 的存储器可组成 4K×8 的存储器（共 4KB），容量为单片的 4 倍。字扩展只增加存储单元的数量（1K → 4K），每单元位数保持 8 位不变。

### 例题 3：全译码法——4 片 8KB 芯片的地址分配（第 22 页）

**题干**：
8 位微处理器，设 CPU 寻址空间 0~FFFFH，有 16 根地址线。用 4 片 8KB 存储芯片 U1、U2、U3、U4 组成存储器，采用全译码法：A12~A0 接到所有存储器芯片的地址输入端，A15~A13 接地址译码器输入端，译码器输出 Y0、Y1、Y2、Y3 分别接 U1、U2、U3、U4 的片选端（CE）。求各芯片的地址范围。

**解**：

第 1 步：求片内地址线数。8KB = $8\times1024=8192=2^{13}$，故片内地址线数 $N=13$，即 A12~A0（共 13 根）接芯片地址端，与题设一致。
第 2 步：高位线 A15~A13（共 3 根）全部接译码器，译码输出 Y0~Y3 依次接 U1~U4 的 CE。
第 3 步：求 U1 的范围。U1 选中条件为 A15A14A13 = 000；低位 A12~A0 可任意。取低位全 0：地址 = 000 0000000000000B = 0000 0000 0000 0000B = 0000H。取低位全 1：地址 = 000 1111111111111B = 0001 1111 1111 1111B = 1FFFH。故 U1 = 0000H~1FFFH。
第 4 步：求 U2 的范围。A15A14A13 = 001。最低：001 0000000000000B = 0010 0000 0000 0000B = 2000H；最高：001 1111111111111B = 0011 1111 1111 1111B = 3FFFH。故 U2 = 2000H~3FFFH。
第 5 步：求 U3 的范围。A15A14A13 = 010。最低：0100 0000 0000 0000B = 4000H；最高：0101 1111 1111 1111B = 5FFFH。故 U3 = 4000H~5FFFH。
第 6 步：求 U4 的范围。A15A14A13 = 011。最低：0110 0000 0000 0000B = 6000H；最高：0111 1111 1111 1111B = 7FFFH。故 U4 = 6000H~7FFFH。
第 7 步：验证。每片地址数 = 1FFFH − 0000H + 1 = 2000H = 8192 = 8K ✓；总容量 = 4 × 8K = 32K，总区间 0000H~7FFFH，7FFFH + 1 = 8000H = 32768 = 32K ✓；相邻区间首尾相接（1FFFH 之后是 2000H，3FFFH 之后是 4000H，5FFFH 之后是 6000H），地址连续、无重叠 ✓，与幻灯片给出的表格完全一致。

**答案**：U1：0000H~1FFFH；U2：2000H~3FFFH；U3：4000H~5FFFH；U4：6000H~7FFFH。

### 例题 4：线选法——两片 2732 的地址范围与重叠区计算（第 23–24 页）

**题干**：
采用线选法对 2 片 2732（4K×8 EPROM，片内地址线 A0~A11）进行片选：第一片（左）的 CS 接 A12，第二片（右）的 CS 接 A13，两片的数据线并联接数据总线。"1"选通（当该地址线信息为 1 时选中该存储器）。已知各片最低、最高地址模式为：第一块（左）00\*1 111111111111 ~ 00\*1 000000000000；第二块（右）001\* 111111111111 ~ 001\* 100000000000（\* 表示可为任意值，不影响对当前片的选择）。求两片各自的地址范围及地址重叠区间。

**解**：

第 1 步：确定片内地址线数。2732 为 4K×8，4K = 4096 = $2^{12}$，片内地址线 A0~A11（12 根），对应 16 位 CPU 地址的最低 12 位 A11~A0。
第 2 步：分析第一片（CS 接 A12，A12=1 时选中）。地址模式 00\*1 表示 A15A14 = 00、A13 = \*（无关）、A12 = 1，低位 A11~A0 从全 0 到全 1。
第 3 步：令 A13 = 0，求第一片基本区间。最低地址 = 0001 0000 0000 0000B = 1000H；最高地址 = 0001 1111 1111 1111B = 1FFFH。即 1000H~1FFFH。
第 4 步：令 A13 = 1，求第一片映像区间。最低地址 = 0011 0000 0000 0000B = 3000H；最高地址 = 0011 1111 1111 1111B = 3FFFH。即 3000H~3FFFH。第一片总范围：1000H~1FFFH 与 3000H~3FFFH。
第 5 步：分析第二片（CS 接 A13，A13=1 时选中）。地址模式 001\* 表示 A15A14 = 00、A13 = 1、A12 = \*（无关），低位 A11~A0 从全 0 到全 1。
第 6 步：令 A12 = 0，求第二片基本区间。最低地址 = 0010 0000 0000 0000B = 2000H；最高地址 = 0010 1111 1111 1111B = 2FFFH。即 2000H~2FFFH。
第 7 步：令 A12 = 1，求第二片映像区间。最低地址 = 0011 0000 0000 0000B = 3000H；最高地址 = 0011 1111 1111 1111B = 3FFFH。即 3000H~3FFFH。第二片总范围：2000H~2FFFH 与 3000H~3FFFH。
第 8 步：求重叠区间。两片同时被选中的条件是 A12 = 1 且 A13 = 1，地址模式为 0011 xxxx xxxx xxxx，即 3000H~3FFFH。
第 9 步：验证。重叠区间 3000H–3FFFH 与幻灯片结论"第一/二块的地址重叠区间为 3000H–3FFFH"一致 ✓。每片地址数 = 1FFFH − 1000H + 1 = 1000H = 4096 = 4K，与 2732 容量一致 ✓。第二片区间长度 = 2FFFH − 2000H + 1 = 1000H = 4K ✓。
第 10 步：说明。幻灯片中第二块最低地址印作 001\* 100000000000（按字面为 2800H），与两片完整使用 A0~A11 的接法不符；若按字面读，第二块为 2800H~2FFFH 与 3800H~3FFFH，与幻灯片自身"重叠区间 3000H–3FFFH"的结论矛盾，故该处应为印刷错误，正确取 2000H。按任一读法，两片均被同时选中的区间均包含 3000H~3FFFH。
第 11 步：结论。在重叠区间 3000H~3FFFH 内，两个芯片会同时向数据总线输出数据，产生数据冲突，因此该区间内的地址不可用。

**答案**：第一片：1000H~1FFFH 与 3000H~3FFFH；第二片：2000H~2FFFH 与 3000H~3FFFH；地址重叠区间为 3000H~3FFFH，该区间内地址不可用。

### 例题 5：部分译码法——由 1K×8 的 RAM 构成 4K×8 的 RAM（第 25–26 页）

**题干**：
例：由 1K×8 的 RAM 构成 4K×8 的 RAM（部分译码）。使用 4 片 1K×8 RAM（每片有 CS、WE、A0~A9、D7~D0），2:4 译码器输入端接 A11~A10，4 个译码输出分别接 4 片芯片的 CS；A9~A0 接各片地址端，各片 D7~D0 并联成系统数据总线 D7~D0；CPU 侧有 M/IO、WR 信号；A12~A15 未参与译码。求四组芯片的地址区间。

**解**：

第 1 步：求片内地址线数。1K = 1024 = $2^{10}$，故每片地址端接 10 根低位地址线 A9~A0。
第 2 步：求总地址线数。4K×8 共 4K = 4096 = $2^{12}$ 个单元，需 12 根地址线 A11~A0；其中 A11~A10 接 2:4 译码器输入，产生 4 个片选信号，分别接一、二、三、四组芯片的 CS。
第 3 步：求一组（译码输入 A11A10 = 00）的区间。地址模式：A15~A12 为无关位（取 0），A11A10 = 00，A9~A0 从 0000000000 到 1111111111。最低 = 0000 0000 0000 0000B = 0000H；最高 = 0000 0011 1111 1111B = 03FFH。一组 = 0000H~03FFH。
第 4 步：求二组（A11A10 = 01）的区间。最低 = 0000 0100 0000 0000B = 0400H；最高 = 0000 0111 1111 1111B = 07FFH。二组 = 0400H~07FFH。
第 5 步：求三组（A11A10 = 10）的区间。最低 = 0000 1000 0000 0000B = 0800H；最高 = 0000 1011 1111 1111B = 0BFFH。三组 = 0800H~0BFFH。
第 6 步：求四组（A11A10 = 11）的区间。最低 = 0000 1100 0000 0000B = 0C00H；最高 = 0000 1111 1111 1111B = 0FFFH。四组 = 0C00H~0FFFH。
第 7 步：验证。每组地址数 = 03FFH − 0000H + 1 = 400H = 1024 = 1K ✓；四组共 4 × 1K = 4K，总基本区间 0000H~0FFFH，0FFFH + 1 = 1000H = 4096 = 4K ✓，与幻灯片地址表（0000–03FFH、0400–07FFH、0800–0BFFH、0C00–0FFFH）一致 ✓。
第 8 步：说明幻灯片印刷问题。幻灯片将四组区间印作 0C00–0FFFFH、总区间印作 0000–0FFFFH；A9~A0 只有 10 位，最大值为 1023 = 3FFH，0C00H + 3FFH = 0FFFH，故 0FFFFH 应为 0FFFH。
第 9 步：分析地址重叠。A12~A15 未参与译码，取 0000~1111 共 16 种值均不影响片选结果，因此基本区间 0000H~0FFFH 在 64KB 寻址空间内映像 16 次：0000H~0FFFH、1000H~1FFFH、2000H~2FFFH、……、F000H~FFFFH，各映像之间存在地址重叠，这正是部分译码法"也存在地址重叠的问题"的原因。

**答案**：一组 0000H~03FFH；二组 0400H~07FFH；三组 0800H~0BFFH；四组 0C00H~0FFFH；基本地址区间为 0000H~0FFFH；因 A12~A15 未参与译码，该 4KB 区间在 64KB 空间内映像 16 次，存在地址重叠。

### 例题 6：8086CPU 与 SRAM 的连接——分析 U1、U2 的地址空间（第 31 页）

**题干**：
8086CPU 与 SRAM 的连接（地址分配）。图中给出了 8086 与 U1、U2 两片存储芯片的连接图（芯片型号、片选接法、数据线分组等数据在图中），要求分析：U1 的地址空间：____；U2 的地址空间：____。

**解**（该题的具体数值取决于原图，以下为完整分析流程，每步对应图中应读取的要素）：

第 1 步：从图中确定 U1、U2 的片选信号来源——是译码器（74LS138）的某个输出，还是某根高位地址线直连；并确定有效电平（"1"选通还是低电平有效）。
第 2 步：从图中确定 U1、U2 的数据线接在 D0~D7（偶存储体）还是 D8~D15（奇存储体）；偶存储体由 A0=0 选通，奇存储体由 $\overline{\text{BHE}}$=0 选通。
第 3 步：按芯片容量确定片内地址线数 $N$；偶存储体芯片的片内地址端接 CPU 的 A1~A(N)，奇存储体芯片同样接 A1~A(N) 并受 $\overline{\text{BHE}}$ 控制。
第 4 步：写出选中条件对应的地址模式，标出无关位（\*）；把最低位组合换算为最低地址、最高位组合换算为最高地址（二进制 4 位一组转十六进制）。
第 5 步：若存在无关位，写出全部映像区间；判断两片区间是否重叠。
第 6 步：校验每片区间长度等于芯片容量（区间末地址 − 首地址 + 1）。

**答案**：U1、U2 的地址空间由图中片选接法与芯片容量决定，按上述第 1~6 步填入；分析要点为片选信号、数据线分组（偶/奇存储体）、A0/BHE 选通与无关位映像。

### 例题 7：课堂作业——从 9C000H 开始分配 M1、M2 并连接 74LS138 输出线（第 32 页）

**题干**：
8086CPU 与 SRAM 的连接（地址分配）。课堂作业（上交）：分配给 M1 和 M2 的地址空间从 9C000H 开始分配，请填空（M1、M2 各自的地址空间），并连接 74LS138 输出线。

**解**（题目所附连接图未随文本提取，芯片容量以图中标注为准；以下按最常见的"M1、M2 为两片 8KB SRAM、置于偶存储体"演示完整步骤，若图中容量不同，仅第 2~5 步的数值相应改变）：

第 1 步：把起始地址写成 20 位二进制。9C000H = 1001 1100 0000 0000 0000B（即 A19=1、A18=0、A17=0、A16=1、A15=1、A14=1、A13~A0 全 0）。
第 2 步：确定片内地址线数。8KB = $2^{13}$，13 根片内地址线；偶存储体芯片的片内地址 A0~A12 接 CPU 的 A1~A13。
第 3 步：计算 M1 的地址空间。起始 9C000H；末地址 = 9C000H + 8×1024 − 1 = 9C000H + 1FFFH = 9DFFFH（对应偶地址 9C000H、9C002H、…、9DFFEH）。M1 = 9C000H~9DFFFH。
第 4 步：计算 M2 的地址空间。起始 = 9DFFFH + 1 = 9E000H；末地址 = 9E000H + 1FFFH = 9FFFFH。M2 = 9E000H~9FFFFH。
第 5 步：提取片选条件。M1 区间内 A19~A14 = 100111、A13 = 0；M2 区间内 A19~A14 = 100111、A13 = 1。即两片仅由 A13 区分。
第 6 步：连接 74LS138。取译码输入 A15、A14、A13：M1 对应输入 110（A15=1、A14=1、A13=0）→ 输出 $\overline{\text{Y6}}$ 接 M1 的 CE；M2 对应输入 111（A15=1、A14=1、A13=1）→ 输出 $\overline{\text{Y7}}$ 接 M2 的 CE。译码器使能端由 M/IO（=1 时允许）与 A19~A16（要求 A19=1、A18=0、A17=0、A16=1，即 1001）组合控制。
第 7 步：验证。M1 区间长度 = 9DFFFH − 9C000H + 1 = 2000H = 8192 = 8K ✓；M2 区间长度 = 9FFFFH − 9E000H + 1 = 2000H = 8192 = 8K ✓；两区间连续（9DFFFH + 1 = 9E000H）且不重叠 ✓；起始地址 9C000H 与题给条件一致 ✓。

**答案**：M1：9C000H~9DFFFH，M2：9E000H~9FFFFH（按每片 8KB 计）；74LS138 的 $\overline{\text{Y6}}$ 接 M1、$\overline{\text{Y7}}$ 接 M2，译码输入取 A15、A14、A13，使能端由 M/IO 与 A19~A16 = 1001 控制。


按 **每片 SRAM 为 \(8K\times8\)** 的常规接法，填空和连线如下。原图未注明芯片容量，以下以此为前提。

| 图中位置（从上到下） | 填入内容 |
|---|---|
| 最上方，两片 SRAM 共用的地址线 | \(A_1～A_{13}\)，接 SRAM 的地址端 \(A_0～A_{12}\) |
| 第二条线，接上方或门 | \(A_0\) |
| 74LS138 的 \(G_1\) | \(A_{19}\) |
| 74LS138 的 \(\overline{G_{2A}}\) | \(A_{18}\) |
| 74LS138 的 \(\overline{G_{2B}}\) | \(A_{17}\) |
| 74LS138 的 \(C\) | \(A_{16}\) |
| 74LS138 的 \(B\) | \(A_{15}\) |
| 74LS138 的 \(A\) | \(A_{14}\) |
| 下方接 M1 的数据总线 | CPU 的 \(D_{15}～D_8\) |
| 最下方接 M2 的数据总线 | CPU 的 \(D_7～D_0\) |

**将 \(\overline{Y_7}\) 接到两个或门的公共输入端。** M1 是奇地址（高字节）存储体，M2 是偶地址（低字节）存储体；芯片内括号若标注容量，两者均为 \(8K\times8\)。

因为起始地址为：

\[
9C000H=\underbrace{100111}_{A_{19}～A_{14}}
\underbrace{00000000000000}_{A_{13}～A_0}
\]

其中 \(A_{19}A_{18}A_{17}=100\) 满足译码器使能条件，\(CBA=A_{16}A_{15}A_{14}=111\)，所以选中低有效输出 \(\overline{Y_7}\)。这与 [74LS138 的功能表](https://www.ti.com.cn/cn/lit/gpn/SN74LS138)一致。

两片的片选关系为：

\[
\overline{CS}_{M1}=\overline{Y_7}\lor\overline{BHE},
\qquad
\overline{CS}_{M2}=\overline{Y_7}\lor A_0
\]

分配后的地址是：

| 存储体 | 地址分配 | 容量 |
|---|---|---|
| M1，高字节 | \(9C001H,9C003H,\ldots,9FFFFH\)，步长 2 | 8 KB |
| M2，低字节 | \(9C000H,9C002H,\ldots,9FFFEH\)，步长 2 | 8 KB |

因此，两片共同覆盖 **\(9C000H～9FFFFH\)，共 16 KB**。
